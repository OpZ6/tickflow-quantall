1. 唯一一张 K 线和唯一一套 candles、时间轴、缩放、十字光标；
2. 一层主工具栏；
3. 一个统一“指标中心”；
4. 最多一行紧凑的已启用指标摘要；

6. 一套保存完整工作区的指标模板；
7. 可验证的历史补齐、隐藏预热、回放和防未来函数链路。

```text
浦发银行 | 周期 [日K] | 数据范围 [3年] | 复权 [前复权]
         指标 [已启用 6] | 画线 | 回放 | 截图 | 全屏 | 更多

已启用：MA(5,10,20)  MACD(12,26,9)  缠论  关键价位  放量突破策略  +1
```

不得继续出现两个功能重叠的管理入口、独立缠论/关键价位按钮、开启功能后新增整排参数，以及模板、图层、参数各占一排的布局。

## 4. 目标交互层级

### 4.1 主工具栏

只保留：

```text
标的 | 周期 | 数据范围 | 复权 | 指标 | 画线 | 回放 | 截图 | 全屏 | 更多
```

- 常用桌面宽度保持一行，自定义日期进入“数据范围”弹层；
- 数据范围控制请求区间，图内缩放控制视图窗口，二者不得混淆；
- 画线是交互工具，不伪装成计算指标；
- 低频操作进“更多”；按钮必须有名称、tooltip、可见焦点和 `aria-label`。

### 4.2 已启用指标摘要

- 只显示已启用指标及关键参数；
- 点击标签在指标中心打开详情；
- 支持拖动排序，溢出显示 `+N`；
- 完整参数、删除、主副图位置、高度和折叠移入详情；
- 允许隐藏摘要行。

### 4.3 唯一指标中心

点击“指标”打开唯一右侧抽屉，建议宽 420–480px：

```text
指标中心
├─ 搜索 / 仅看已启用
├─ 当前启用
├─ 主图指标：趋势、缠论、关键价位、形态、策略信号
├─ 副图指标：动量、趋势、波动、量价
├─ 市场事件
├─ 指标模板
└─ 标注工具
```

“主图/副图”是位置，“技术/结构/形态/策略/事件”是语义标签；不得因此再建立多套管理器。每项只有主开关、摘要、同抽屉详情三层。详情统一包含业务参数、样式、位置、顺序、高度、折叠、支持周期/资产、预热需求、数据状态、版本、指纹、错误原因和恢复默认。

## 5. 统一指标模型

建立类型化、版本化注册契约，至少表达：

```ts
interface ChartIndicatorDefinition {
  id: string
  version: number
  kind: 'technical' | 'structure' | 'pattern' | 'strategy' | 'event'
  placement: 'main' | 'sub'
  supportedIntervals: string[]
  calculation: 'client' | 'server' | 'repository'
  requiredFields: string[]
  warmupBars: number | ((params: Record<string, unknown>) => number)
  parameterSchema: IndicatorParameterDefinition[]
  styleSchema: IndicatorParameterDefinition[]
}

interface ChartIndicatorInstance {
  instanceId: string
  indicatorId: string
  enabled: boolean
  params: Record<string, unknown>
  style: Record<string, unknown>
  pane: { placement: 'main' | 'sub'; order: number; height?: number; collapsed?: boolean }
}
```

- 所有计算分析能力进入同一目录；
- 参数表单由 schema 生成，不在页面散写；
- 同指标多实例使用稳定 `instanceId`；
- 重复 ID、未知版本和无效参数 fail-closed；
- 单指标失败不得使整张 K 线 500/白屏；
- ECharts 只消费标准绘制结果，不承载业务算法。

### 5.1 缠论

缠论是一个主图结构指标。算法来源、包含处理、分型、笔、线段、中枢、买卖点、BSP 模式、样式、版本、输入指纹、末笔状态和预热完整性全部进入详情；开启后不得新增顶部参数行。官方对照映射失败时只禁用对照层，不替换本地 candles。

### 5.2 关键价位与形态

关键价位是一个主图结构指标，十一组子类型和样式进入详情。旧 `levels` 保持兼容读取，但前端只通过统一实例控制。

头肩顶/底、双顶/底和三角形以“形态识别”指标族呈现，明确为启发式研究标记。VCP、杯柄、高而紧旗形、启动后缩量回踩已经是正式策略，不得重建 `pattern.*` 旁路。

### 5.3 策略与事件

只有正式注册策略可成为 K 线策略指标。详情展示策略 ID/版本/参数指纹、即时预览或历史事件、事件类型、密度、条件证据、支持周期和数据状态。

即时预览仅允许声明 `chart_preview.enabled=true`、`mode=single_asset` 的策略：只计算当前股票，不做全市场扫描、不写 `strategy_signal_events`、不模拟成交、不计算横截面排名，也不得用近似形态绕过注册。

历史事件继续区分 `strategy_signal`、`backtest_fill`、`realtime_trigger`。涨停、炸板等客观事实以事件指标呈现，不与策略信号混为“买卖点”。

### 5.4 画线

水平线、趋势线和文字可与指标中心协同，但不进入计算注册表、不参与预热，继续按股票、周期和复权隔离。模板默认不复制具体股票画线数据。

## 6. 指标模板必须完整保留并升级

指标模板是一级能力，不是几个临时快捷按钮。模板至少保存：

- 指标实例集合和全部参数；
- 样式、主副图位置、顺序、高度、折叠；
- 标注密度和图例偏好；
- 可选的周期、范围和复权偏好；
- schema 版本及创建/修改时间。

模板不得保存行情、计算缓存或策略事件结果。

### 6.1 系统模板

保留并校准“基础、趋势、震荡、缠论分析、关键价位”：

- 稳定 ID，不可直接删除或覆盖；
- 可复制为自定义模板；
- 包含完整指标、参数和布局，不只切显隐；
- 系统升级不得覆盖用户自定义副本。

### 6.2 自定义模板

支持保存当前工作区、命名/重命名、复制、覆盖、删除、应用前摘要、恢复模板初始状态，并显示当前工作区是否偏离已应用模板。名称冲突、损坏和存储失败必须给出明确错误。

应用模板默认原子替换指标集合、参数、样式和布局，禁止残留旧指标或旧参数。第一阶段不必实现“合并应用”；若后续增加，必须明确重复实例和参数冲突规则。

### 6.3 旧预设迁移

将旧 `presets`、`activeIndicators`、缠论配置、关键价位开关、图层开关和副图布局迁入新模板/统一状态：

- 新增 layout schema 版本；
- 旧配置只读迁移，成功后写新版本；
- 未知指标和参数记录警告，不使整模板失效；
- 失败时回退安全默认模板并保留旧数据；
- 不静默覆盖自定义预设；
- 固定测试覆盖缺字段、重复 ID、损坏和版本升级。

## 7. 统一状态与持久化

目标状态可表达为：

```ts
interface StockChartLayoutV4 {
  version: 4
  activeTemplateId?: string
  indicators: ChartIndicatorInstance[]
  annotationDensity: 'auto' | 'aggregate' | 'detail'
  activeIndicatorSummaryVisible: boolean
  templates: ChartIndicatorTemplate[]
}
```

一个状态源驱动摘要、指标中心和图表；不维护第二套图层状态。模板跨股票复用，股票专属结果不得串股；画线仍独立隔离。行情、计算结果和事件不写 localStorage，迁移和损坏恢复必须隔离异常。

## 8. 隐藏预热与长历史

### 8.1 预热正确性

当前缠论和部分前端指标只消费裁剪后的可见行，左边界会重置或失真。目标链路：

```text
启用指标和参数 → 取最大预热需求 → 检查覆盖
→ 获取隐藏预热 + 可见区间 → 完整序列计算
→ 裁剪结果 → 只渲染请求范围
```

- 每个指标声明随参数变化的 `warmupBars`；
- 缠论需求由算法契约和收敛测试确定，不长期依赖任意常数；
- API 区分可见 rows 与隐藏分析序列；
- 响应提供总需求、实际预热、整体及逐指标完整性；
- 不完整显示“部分结果”，不得填零或伪装完整；
- 纯样式变化不请求行情，预热需求变化才进入查询维度；
- 回放预热只能来自截止日前，严禁未来 candles。

### 8.2 3/5 年和自定义范围

选择长范围时核对请求与实际覆盖，不得静默退回约一年。历史不足时显示起止缺口，并通过统一 provider 能力路由补齐当前单股原始日线和复权因子；不得触发全市场 `extend_history`，不得绑定具体供应商。补齐需有进度/失败状态、幂等写入、generation/cache 更新和精确查询失效。

数据范围与视图窗口分离：选择 3/5 年后首次适配完整范围，不再固定只显示最后约 250 根。周末/节假日起点按交易日历归一化并显示实际首日。`all` 改名“本地全部”；“上市以来”必须真实补齐后才可提供。

## 9. 状态、证据与回放

工具栏用紧凑状态展示数据完整、历史不足、补齐中、部分指标预热不足和数据源不可用；点击查看详情。每个指标区分可用、计算中、部分、不支持、缺字段、算法错误和数据源不可用，不得都渲染为空白。

后端输出与 ECharts 无关的语义，前端统一视觉映射。点击标记展示日期、类别、算法/策略版本、参数和输入指纹、条件、实际值、阈值、确认/失效时间、来源、运行批次和数据警告。

回放截断唯一 candles 序列；结构、形态、策略和事件按确认/事件/成交/触发时间过滤。切模板后在同一截止日重算；截图和导出保留当前模板、指标和回放状态。固定样本必须证明追加未来数据不会改变历史时点结果。

## 10. 性能约束

- 显隐、样式、高度、折叠不请求行情；
- 周期、复权、范围、预热或服务端参数变化才更新相应查询；
- 所有指标共享 candles，不得各请求一份 K 线；
- 模板应用一次提交状态并产生最少请求；
- 参数快速变化防抖，旧请求可取消且不得覆盖新上下文；
- 查询键覆盖所有真正影响结果的维度；
- 单指标异常隔离；大范围多副图仍可流畅缩放和移动十字光标。
