# 人气中温池：第一个历史观察实验

执行日期：2026-09-13。版本：`popularity-v1`。状态：旧口径归档，未冻结收益筛选规则。当前统一次日开盘及超短窗口见[v2报告](v2-analysis.md)。以下保留v1当时的结果与协议，全部数值见[分层与对照表](v1-results.md)。

**本轮收敛：人气暂时作为候选来源和状态标签；现有证据不足以把它升格为独立高质量池。** 中温区间有温和改善，升温、健康趋势、多源重叠、板块支持均没有形成一致的正向证据，观察有效期也没有找到可靠的固定天数。

原设想是东财股吧人气20–100名，但历史档案没有有效东财记录。本实验实际评估同花顺、雪球、百度直接榜单，不能据此宣称验证了股吧人气逻辑。宽池原计划的101–200名也没有数据。

## 数据覆盖与固定协议

共47个快照日期；剔除2026-06-22由热点列表顺序生成的151条近似排名，直接榜单有效日期46个。同花顺与雪球覆盖06-23至08-25，百度覆盖07-09至08-25，共34日。三源均只覆盖前100名；东财、财联社无有效记录。价格观察截至2026-09-11。

历史证据来自 `data/quantx/*/hot_rank_snapshot.json` 的版本化排名记录；未使用趋势池评分或复盘选股结果。近似排名的生成链已追溯到旧仓库 `_fallback_hot_snapshot`。每条记录须为A股、有效排名、新鲜且未弃用，并有目标日期收盘后 `observed_at`。来源异常和未覆盖日期不补零，榜外不当作第101名。北交所4／8／92开头代码单独归一。

各源先独立统计，同一股票同日跨源记录保留；并集另按股票／日期去重。并集排名取各源最小名次数值，仅用于独立探索视角，不能解释成统一人气尺度；并集排名变化也可能来自来源切换。

价格来自本地enriched日线，使用既有复权OHLC口径；封板状态沿用日线 `consecutive_limit_ups`。市场基线是同期本地日线中起止价格可用股票的等权收益，未重新验收历史证券全名单与退市覆盖，所以超额仅相对该本地样本成立。

- 预设未来5／10／20个交易日。交易日用全市场日线日期网格；任一观察窗缺少个股日线则标签为空，不把停牌后的第5根K线当作第5个市场交易日。
- 收盘参考：`T+h收盘 / T收盘 - 1`；次日开盘参考：`T+h收盘 / T+1开盘 - 1`。后者终点相同，实际包含h个未来交易日。两者均为价格路径标签。
- 每日先对候选等权，再对日期等权。中位数、P10、平均盈利／平均亏损单独采用成员样本口径；正收益比例按日期等权，不代表策略胜率。
- 计算最大上涨、最大下探、峰值日期及高低点先后顺序。同日高低点先后未知。上涨／下探相对T收盘，不强制截到零；最大上涨不是实现收益，下探不是峰值回撤。
- 每日账本与连续在榜事件账本分开。首日及来源断档后出现视为左截断／缺口；只有前一交易日来源有效、股票不在榜，才确认新入榜。事件仍可能重复股票及重叠未来窗口。
- 新条件比较宽池、保留组、剔除组，并附同日差值。差值区间采用10日期移动块、1,000次重采样、固定种子；仅34–46个日期，区间为探索性诊断，不代表跨年度或独立验证。
- 分档1–20／21–50／51–100，边界不重复；原设想20–100的第20名暂归入过热对照，冻结时需明确边界。

## 候选价值

三源宽池的5／10／20日固定窗均值均为负，10日均落后同期本地市场样本。次日开盘参考没有改变总体结论。20日末端7个入池日期尚未成熟，10日与20日可评估日期不同，不能将两者直接解释为同批候选的时间衰减。

百度全期均值好于同花顺、雪球，但在三源共同34日重新比较后优势明显缩小；不能根据不同覆盖期的均值确定来源优先级。并集窗口内最大上涨空间为正，但固定窗收益为负，且左尾较深，说明波动机会与候选质量必须分开。

21–100名整体略优于1–20名，细档中51–100也有改善。月份检查却显示同花顺及并集主要在7月改善，6月、8月不一致；中温差值的并集探索性区间跨零。保留中温研究方向，暂不冻结新排名门槛。

## 当前状态

**升温没有体现优势。** 只在同源相邻交易日计算排名升降；未知、首次及不连续重入保留未知。三源升温组的10日收益均未优于降温组。

**健康趋势硬门槛不成立。** 健康定义为收盘不低于MA20且MA20高于5日前；弱势为收盘低于MA20且MA20不高于5日前，其余混合，预热不足未知。健康组及中温×健康组均未改善；硬过滤还损失大量10日收益至少20%的大赢家记录。不能反向据此设计“专选弱势”，本段关联可能反映热门强势股后的均值回归。

**多源重叠没有体现加分。** 三源共同期内，并集单源、双源、三源覆盖的10日收益依次更低。来源切换、价格状态及榜单身份仍会影响比较，暂不把重叠数作为统一加分项。

**过去5日过热要用已知历史作对照。** 只有完整5日期来源覆盖才判断是否进过前20，未知不能当作未过热。在当前21–100名中，比较过去5日“未进前20”与“曾进前20”的同日结果：雪球与百度方向较好，同花顺方向相反。直接从宽池过滤的表面改善混入了最早5日未知样本和当前前20名被剔除的影响。可保留过热标签，暂不统一剔除；长期“曾经进入”无法研究。

**市场和板块没有形成统一门槛。** 市场环境按当日及此前20日的本地市场等权涨幅正／非正分层，并集在两类环境中10日超额均负。

板块支持代理使用当日档案题材成员与涨停事件：同题材其他股票至少2只涨停，排除自身贡献，多题材取最高同伴数。无题材记录标记未知，不能解释为板块不支持。该代理只覆盖并集约11%的10日有效成员；高支持与低支持组同日差值方向跨源不一致，区间跨零。本轮没有检验完整行业成分、板块趋势或行业相对强度，暂不新增板块硬条件。

## 观察有效期

并集每日规模中位数190.5、P90为209只；46日累计1,339只。百度更频繁换榜，各源不宜预设同一过期机制。规模、新入榜数与年龄详见数值表。

第1日、连续2–3日、4–5日及6日以上的10日收益并没有单调衰减。只取确认新入榜事件后，三源及并集的同期超额仍负，无法据此确定第3日或第5日强制过期。

连续时长以可见档案为边界，并非完整入池年龄；首日左截断和末端右截断仍存在。年龄分层回答“当前在榜时长对应的质量”，没有回答“退榜后还能观察多久”。

本轮有效期决定：候选来源先按每日有效榜单更新；已观测退榜与来源未知／失效分开记录。暂不设置经过收益验证的固定观察天数，也未研究退榜后的额外保留期。要解决延长观察导致的膨胀，后续需研究退榜路径及重入。

## 收敛决定

大赢家定义为10日固定窗收益至少20%，保留率采用成员记录口径，不能当作不同股票或独立机会保留率。数值表同时列出保留规模、保留／剔除收益、P10、赢家保留及同日差值；各月和全部观察周期保存在结构化结果中。未知趋势在“非弱势”规则中保留，未知过热在筛选中排除，须结合已知历史对照解释。

| 规则类别 | 本轮决定 |
| --- | --- |
| 入池硬条件 | 只固定数据有效性：真实直接来源、收盘后时点、有效排名、保留来源身份。没有新增经过验证的收益门槛。 |
| 池内优先级 | 中温、过热历史、升降温及价格状态保留为研究标签，尚未冻结统一排序。 |
| 观察失效条件 | 区分已观测退榜、来源未知／失效与历史截断；没有冻结基于收益的固定有效期。 |
| 证据不足暂不采用 | 健康趋势硬门槛、升温加分、多源重叠加分、曾入前20统一剔除、题材支持门槛。 |

下一步最能改变结论的数据是东财真实历史排名与101–200名覆盖，其次是冻结标签后增加前向观察日期。整段历史已参与探索，不能再作为独立验证，无需在这46个日期继续穷举阈值。
