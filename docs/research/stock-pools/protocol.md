# 股票池公共分析协议

适用于[股票池历史分析提纲](../../../prompt/bucket.md)中的八个候选池。本文固定公共研究方法；各池事件定义、数据覆盖、具体分档及执行口径写入对应版本的分析报告。当前统一次日开盘起算，见[人气v2报告](popularity/v2-analysis.md)；此前v1保留为旧口径档案。

## 分别回答三个问题

| 研究对象 | 问题 | 最终规则用途 |
| --- | --- | --- |
| 候选价值 | 哪些股票值得进入观察范围？ | 入池条件 |
| 当前状态 | 同一候选今天处于什么阶段？ | 池内优先级与状态标签 |
| 观察有效期 | 事件之后多久仍值得观察，何时失效？ | 过期与退出观察 |

本轮评估未来价格路径，不引入成交、仓位、止损或退出策略；入池不能解释为当天适合介入。

## 样本与两类账本

各池独立宽召回，保留池间重叠与来源身份，并包含准备研究条件的规则外对照；不能提前过滤待检验因素。固定事件定义、交易日、复权、字段单位及可得时点后再探索阈值。

- 每日成员账本：保存股票、日期、来源、事件锚点、距事件天数、可见入池年龄及当前状态，回答当天打开池的总体质量。
- 事件账本：保存一次事件的确认锚点及后续路径，连续留池不重复定义事件。首日已存在、来源缺口、事件覆盖不足及末端未结束分别保留截断状态。

报告成员数、不同股票数、确认事件数和有效日期数。多源独立视角与股票／日期去重后的并集分别统计；并集不得默认把各源排名或评分视为同一尺度。

## 固定结果标签

运行前固定1／2／3／5／10／20交易日观察窗，先报告1／2／3日超短表现，趋势池可另加40／60日诊断。窗口必须按统一市场交易日网格对齐，缺日不顺延；未成熟或缺输入标签为空。

| 标签 | 内容 |
| --- | --- |
| 固定窗收益 | 均值、中位数、正收益比例、平均盈利／亏损及左尾 |
| 同期超额 | 相对同日市场基线与同池规则外对照；明确基线覆盖 |
| 路径空间 | 最大上涨、最大下探与峰值时间；不能当作实现收益 |
| 路径顺序 | 先下探还是先上涨；同日高低点顺序未知 |
| 池特有结果 | 按事件定义补充突破保持、反包、重新封板、破锚点等 |

全部未来收益、同期市场超额与最大上涨／下探空间统一以信号日下一交易日开盘价为基准。1日为T+1开盘至T+1收盘，2日到T+2收盘，3日到T+3收盘；N日收益为 `T+N收盘 / T+1开盘 - 1`。路径空间仅使用T+1至T+N的价格。信号日价格继续用于当时的事件与状态定义，不作为未来收益起点。

技术指标与路径收益使用一致复权价格；涨跌停事件使用原始价格及对应交易日规则，或沿用明确已验收的事件字段。1日结果描述次日盘中路径，A股T+1约束下不能解释成当天可完成的一次买卖。

## 分层与规则对照

依次研究池的身份因素、当前状态、市场／板块环境。先单因素，再对有机制解释的因素做少量双因素对照，避免穷举阈值组合。

每日候选等权、日期等权为主要均值口径；分位数、盈利／亏损等采用成员口径时单独注明。先比较共同覆盖期，再比较来源或组别，避免日期构成造成假改善。缺来源、缺状态不能当作负面样本。

每个拟新增条件报告：原始规模、保留规模、保留／剔除收益与左尾、大赢家保留率、同日差值及时间稳定性。大赢家定义及保留率计数单位在运行前明确。只比较已知历史样本；规则未知组单独报告。区间估计考虑重复股票及重叠窗口，方法与参数写入版本报告。

## 热度作为跨池影响因子

后续突破、异动、趋势、分歧、炸板修复、趋势回踩及股性活跃分析，均可追加热度因子，不将其预设为入池条件或正向权重。

保留来源身份、排名区间、同源相邻日期排名变化、可见连续在榜时间、完整覆盖下的近期过热历史及跨源重叠数量。来源覆盖上限与榜内排名分开记录，跨源原始热度值不直接相加。

基础池先独立完成长历史评估，热度叠加只在共同可用日期研究。来源有效时未上榜标记为“已观测榜外”，来源缺失／失败／过期或时点不足标记未知；未知不得作为无热度组，也不得导致基础长历史样本被提前剔除。

在同池、同日及相近事件年龄、价格状态下，比较各源榜内／已观测榜外、不同排名与状态组合，检验是否提供基础形态以外的增量。板块环境、封板状态等分别控制，不能将它们自身的收益归因于人气。

因子采用与否取决于固定窗超额、左尾、机会保留和跨期稳定性；允许来源与超短／中期用途不同。当前短样本中的局部正超额仅作为待检验线索，见[人气池状态与计划](popularity/status-and-plan.md)。

## 有效期与时间验证

报告每日规模中位数、拥挤日规模、新增数量、在池年龄和事件后时间。年龄分层与退池后的残余价值分开研究；来源失效与已观测退出不能混为一类。

长历史分探索与冻结验证；参与条件选择的日期不能再作为独立验证。短样本只支持探索，无法评价的年份或环境标为未覆盖。冻结后用后续未参与选择的日期验证。

最终决定分四类：入池硬条件、池内优先级、观察失效条件、证据不足暂不采用。关联不自动成为硬门槛。

## 版本与产物

报告放 `docs/research/stock-pools/<池>/`，计算产物放 `data/research/stock-pools/<池>/<版本>/`，脚本沿用 `scripts/`。各池README记录实验索引，版本报告说明覆盖、协议、结果、决定与复现命令。

规则或标签改变使用新版本，保留旧版结果；同版本重跑须说明是否更新输入覆盖。数值文档由脚本生成时，解读文档与其分开保存。
