# 股性活跃池v1：全量历史探索

执行日期：2026-09-14。信号覆盖2016-01-04—2026-09-11，2015年仅用于预热。全部未来价格路径从**下一市场交易日开盘**起算，包含1／2／3／5／10／20日。完整历史参与探索，本轮没有独立样本外验证。

## 主要发现

“近30／60日出现过涨停”是一个过宽、衰减很快的身份。近30日活跃成员只有1日约+0.06个百分点市场超额；3／5／10／20日转为-0.02／-0.10／-0.28／-0.64。固定同日、趋势、回撤和前20日涨幅后，活跃成员相对非活跃对照的差值为+0.06／-0.06／-0.18／-0.41／-0.80个百分点（1／3／5／10／20日）。它不适合维持成一个30日或60日独立大池。

有价值的部分集中在**最近一次涨停后的第1个交易日**。该状态自身1日市场超额约+0.53个百分点；与相同状态非活跃股票匹配后仍多约+0.37个百分点，20日期块95%区间约+0.30至+0.43。2016—2026每年1日超额都为正，约+0.39至+0.73。但效应到第2日仅剩+0.05且区间跨零，第3日转负，10／20日匹配差为-0.97／-1.65。它是超短观察状态，验证有效期只有1个交易日。

涨停当日的二板及以上看似有很高中期收益，但主要来自一字涨停和早期IPO连续板。去掉一字板后，二板及以上的1／2／3／5／10／20日超额为-0.39／-0.47／-1.02／-2.30／-4.11／-6.25；2022年以来高板组10日结果也转负。不能把不可成交的一字板路径当成可用高板因子。

本轮建议取消宽泛的30／60日独立收益池，保留两层信息：把“涨停后第1日”作为待前向验证的超短事件子池；把近30／60日涨停次数、距最近涨停日作为其他候选池的活跃度标签。第2日开始不再给正向权重。

涨停使用当日日线衍生字段`consecutive_limit_ups > 0`，表示收盘封住涨停。连续封板合并为一次活动过程，间隔至少一个非涨停市场日后再封板才开启新过程；最近封板会刷新成员的涨停年龄。每日账本保留完整30／60日宽成员和频次、趋势、回撤、量能及与其他池的重叠。

非活跃对照要求完整60个市场日且窗口内无涨停，再按代码和日期稳定抽取10%。身份匹配在同日、趋势、回撤和前20日涨幅状态格中要求两侧各至少3只股票。它回答活跃身份相对相似价格状态是否有增量，不把抽样对照当成全市场收益。

北交所代码在2021-11-15前的缓存行情属于新三板历史，已从信号和市场对照剔除，防止异常低价和制度差异污染收益。价格使用前复权日线；未来窗口缺任一市场交易日行情即为空，末端未成熟标签为空。历史上市全集与退市覆盖仍未证明完整。

## 板位与可交易性伪影

涨停当日首板的10日超额约-0.67，二板约+2.75，三板以上约+7.59。这个表面阶梯不能直接解释为板位越高越有价值：一字涨停只占涨停日约10.7%，却贡献了大部分旧年份的连续上涨路径，其10日超额约+13.35；这类股票在路径起点经常无法按开盘价获得。

二板以上剔除一字板后只保留15.6%的涨停日，10日超额变为-4.11，10日大赢家仅保留15.1%。高板总体的10日超额从2016年的约+35.15逐步衰减，2022—2026每年均为负。股性活跃研究若不先拆一字板，会得到方向相反的结论。

本轮只评价价格路径，没有盘口封单和可成交性数据。涨停当日不建立任何可介入规则；“涨停后第1日”也需用冻结后的新日期检验，且后续若用于执行必须另行处理开盘涨停、停牌和成交约束。

## 观察有效期与产品用法

宽30日池每日中位数949只、60日池1,531只，无法提供聚焦。正向效应集中于涨停后第1个交易日，并在第2日基本消失。因此产品规则可收敛为：涨停当日记录事件；下一交易日收盘后生成`limit_age=1`超短候选，供再下一交易日观察；之后移出该事件子池，但保留30／60日频次和年龄标签供其他池排序。

这一用法严格区分三件事：候选价值来自近期真实封板事件；当前状态由趋势、量能、是否失守事件低点等展示；有效期只给1个未来观察日。活跃次数更多、趋势更强或成交额更高不延长有效期，也不作为入池硬过滤。

热度只在同花顺／雪球46日、百度34日共同覆盖内比较，分来源和周期不一致，中期多数更弱。缺榜单标未知，不能解释为无热度。本轮不冻结热度加分。

## 本轮收敛决定

| 用途 | 决定 |
| --- | --- |
| 入池硬条件 | 取消近30／60日宽独立池；保留`距最近涨停=1`的超短事件子池，等待前向验证 |
| 池内优先级 | 频次、新鲜度、趋势、量能、成交额排名、突破／回踩重叠只作状态标签；尚无可冻结加分 |
| 观察失效 | 第1个交易日后正向效应消失；第2日开始移出超短子池，30／60日身份不承担收益含义 |
| 证据不足／排除 | 高板收益被一字板污染；非一字高板中期显著为负。热度和跨池重叠覆盖不足或未显示增量 |
