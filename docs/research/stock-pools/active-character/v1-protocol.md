# 股性活跃池v1协议

冻结日期：2026-09-14。范围：全历史候选价格路径探索，不含成交、仓位、止损和退出策略。

## 事件与样本

- 使用本地前复权日线计算趋势与收益；涨停活动使用已有日线衍生字段`consecutive_limit_ups > 0`，表示当日收盘封住涨停。该字段用于历史一致分类，不替代监管公告或盘中开板事实。
- `.BJ`代码在北交所2021-11-15开市前的缓存行情属于新三板历史，信号和市场对照均排除；涨停当日另按`high == low`拆分一字板，防止不可成交的旧IPO连续板污染板位结论。
- 连续封板日属于一次活动过程，过程首日进入独立事件账本；最近封板日刷新“距最近涨停日”，但不重开过程。间隔至少一个非涨停交易日后再次封板，开启新过程。
- 宽成员为最近60个市场交易日内存在涨停；原始30日身份为距最近涨停0—29日。分别记录滚动30／60日涨停次数、距最近涨停日和过程年龄，不提前过滤趋势、回撤或成交额。
- 日线连续窗口缺市场日行情时，滚动频次和趋势状态标未知。非活跃对照要求完整60日且窗口内无涨停，并按股票／日期稳定哈希抽取10%，用于同日状态匹配；它不是完整非活跃全集，统计匹配时只解释组间差值。

## 因素与对照

身份层：30／60日窗口、涨停次数1／2／3次以上、事件新鲜度、连续板活动过程。当前状态层：强／基本／非趋势、是否站上MA20、MA20斜率、距事件收盘涨跌、距近20日高点回撤、量比和是否跌破事件低点。

交叉标签包括成交额前100／200、最近19日突破、趋势回踩事件和短期热度；只在各自实际覆盖日期比较。身份增量须与同日、相近趋势、回撤和前20日涨幅的非活跃抽样对照比较。

## 标签与统计

- N日收益=`T+N收盘/T+1开盘-1`，N为1／2／3／5／10／20。MFE和MAE只取T+1至T+N；窗口缺日或末端未成熟为空。
- 主结果先在每日候选内等权，再按日期等权；成员口径另报中位数、P10和平均盈利／亏损。拟条件报告规模、大赢家保留率、同日差、年度方向和20日期块区间。
- 全历史参与探索。冻结后新日期才可作为前向验证；局部结果不直接变成硬门槛。
