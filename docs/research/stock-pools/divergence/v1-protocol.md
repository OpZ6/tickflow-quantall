# 分歧池v1协议

冻结日期：2026-09-14。范围：全历史候选价格路径探索，不含成交、仓位和退出策略。

- 锚点为日线确认封板的首板或二板；一字板保留并单独标记。每个锚点展开后续1—10个市场交易日，原始事件观察账本允许锚点重叠；每日产品账本取同一股票最新的首／二板锚点。
- 宽账本保留尚未回调、回调未破低和破锚点低点组。核心分歧为当前收盘低于锚点收盘；“不破首板低点”作为待检验条件，不提前删除破低对照。
- 身份层比较首板／二板；当前状态层比较事件年龄、相对锚点回调0—5%／5—10%／10—15%／更深、量比、当日收涨跌、再封板和趋势。固定收益与当前再封板率分别报告。
- 所有收益从当前观察日T+1开盘起算，固定1／2／3／5／10／20日。涨停只使用日线收盘封板事实，无法回答盘中弱转强或尾盘介入。
- 数据边界继承股性活跃v1，含北交所开市边界。全历史参与探索，冻结后新日期才可作为前向验证。
