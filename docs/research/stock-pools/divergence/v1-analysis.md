# 分歧池v1：首板／二板后回调研究

执行日期：2026-09-14。锚点及观察覆盖2016-01-05—2026-09-11。所有未来收益从当前观察日的**下一市场交易日开盘**起算，固定1／2／3／5／10／20日。

## 结论

传统“首板／二板后回调且不破锚点低点”没有形成独立候选价值。经典组1日收益／超额约+0.31／+0.20，3日转为+0.13／-0.07，5／10／20日超额为-0.28／-0.79／-1.60。2016—2026每年10日超额都为负，约-0.40至-1.32。

不破锚点低点相对破低组的10日同日差约-0.18个百分点。回调0—10%相对更深回调的10日差约+0.16，但自身超额仍约-0.73；缩量能把10日损耗减轻约0.23，缩量组仍为-0.47。它们只能描述风险。

二板锚点宽样本10日超额表面为+0.73，主要由一字板锚点贡献。一字板锚点10日约+3.49；剔除后，二板组1／3／5／10／20日超额变为+0.31／-0.26／-0.70／-1.53／-2.57。该伪影与股性活跃池一致。

本轮建议不建立独立分歧收益池。首／二板锚点、回调深度、是否破低、事件年龄和缩量保留为股性活跃、异动等候选的当前状态标签；“不破首板低点”不再作为默认硬条件。

## 账本与规模

共识别133,563个首板／二板锚点，展开1—10日得到1,332,816条事件观察；同一股票／日期取最近锚点后，每日账本1,017,221条、5,487只股票、2,598日，日规模中位数386、P90为612。宽账本包含尚未回调、回调未破低和破低组。

宽成员1／3／5／10／20日超额约+0.13／+0.01／-0.11／-0.40／-1.01。实际低于锚点收盘的回调组为602,764条，10／20日为-0.66／-1.26；其中不破锚点低点的经典组370,289条，反而为-0.79／-1.60。宽池相对温和主要来自尚在锚点收盘上方的成员，它们不属于原思想中的分歧低吸。

首板占每日账本86.0%，二板占14.0%。事件后第1日有短期注意力，1日超额约+0.26，10日接近市场；2—3日之后迅速衰减。把事件机械保留到10日会使池规模膨胀，而没有中期证据。

当前再封板率在宽池为6.4%，回调组仅1.0%，经典不破低组1.1%。再封板和固定窗盈利是两个问题；当前再封板组的10日超额仍约-1.12，没有证明反包后继续观察更有价值。

当日下跌组下一日有约+0.36超额，但3／10日转为-0.21／-1.20，属于短期均值回归。平盘组10日接近市场；经典回调×非趋势×平盘的10日仍为负，不能据此改变池定义。量比2倍以上、强趋势、成交额前100均加重中期回吐。

## 收敛决定

| 用途 | 决定 |
| --- | --- |
| 候选价值 | 不建立独立分歧池；首／二板历史只作其他池的事件背景 |
| 当前状态 | 展示距锚点日数、回调深度、破锚点低点、缩量和是否再封板 |
| 观察有效期 | 第1日仅有短期注意力；3日后不再给正向权重，不机械保留10日 |
| 不采用 | 不破首板低点硬条件、二板优先、一字板锚点收益、当日企稳确认 |
