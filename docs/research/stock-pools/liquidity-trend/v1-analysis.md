# 流动性趋势池v1：全量历史探索

执行日期：2026-09-14。信号与成交额排名覆盖2016-01-04—2026-09-11，2015年仅用于预热。全部未来价格路径从**下一市场交易日开盘**起算，包含1／2／3／5／10／20／40／60日。完整历史参与了探索，本轮没有独立样本外验证。

## 主要发现

成交额前50／100／200提供了清晰的容量和可交易性身份，但没有形成稳定的中期价格超额。前100从次日开盘到收盘有约+0.14个百分点超额，2日接近市场，3／10／20／60日转为约-0.15／-0.87／-1.58／-2.91。前50长期相对温和，仍未跑赢市场。

在同日、趋势、回撤和前20日涨幅状态内，前200相对201—500名只在1日多约0.03个百分点，2—60日差异跨零或转负。容量身份本身没有提供形态之外的中期增量。

“均线量价排除走坏趋势”不适合作为收益过滤。原版前100中，`close > MA20 > MA60`的趋势组1日超额约+0.19，但3／10／20／60日为-0.25／-1.29／-2.30／-4.05，明显弱于被排除组。更强趋势、站上MA20／MA60、MA60上行也呈现同样的中期回吐。

建议保留成交额排名作为全局流动性约束、容量展示和候选排序因子；不单独建立一个声称有收益优势的趋势池。连续在榜可用来区分稳定容量与短期事件冲榜，避免将刚放量进入榜单的股票和长期核心成交票混为一类。

排名越靠前，1日注意力效应略强。前50相对其余前200的1／3日同日收益差约+0.04／+0.08个百分点，10／20日约+0.15／+0.16但区间跨零；其自身10／20／60日超额仍约-0.81／-1.52／-2.58。前100相对101—200也没有中期稳定增量。把门槛从100改成50不能解决收益问题。

前200与201—500名固定同日、趋势状态、回撤档和前20日涨幅档后，1日差约+0.03，区间约+0.01至+0.05；2／3／5／10／20／60日约+0.02／+0.01／0.00／-0.03／-0.12／-0.19，区间均跨零。这是容量身份是否提供价格状态外增量的主要对照，结果只支持很短的注意力关联。

首次进入前50／100／200的事件1日超额约+0.24／+0.20／+0.19，10日约-0.89／-1.04／-1.10，20日约-1.70／-1.81／-1.84。新入榜更像放量和价格事件，不能作为独立中期候选理由。

## 当前状态：追强过滤加重中期回吐

前100中，趋势身份保留45.8%的成员和57.9%的10日大赢家记录。它相对非趋势组1日改善约0.09个百分点，10／20／60日弱约0.52／0.91／1.51；块区间位于零下。强趋势只保留29.7%，10／20／60日再弱约0.73／1.30／2.31。

站上MA20、站上MA60、MA60上行都表现为1日稍强、10—60日显著更弱。前20日上涨30%以上的前200成员1日超额+0.39，3／10／20／60日转为-0.51／-2.41／-3.88／-6.94。成交额靠前叠加陡峭趋势，主要捕捉的是拥挤和加速阶段。

放量下跌是风险状态。排除“当日下跌且量比≥1.5”保留前100约90%，相对被排除组10／20／60日改善约0.37／0.77／1.78个百分点，但保留组仍落后市场约0.81／1.46／2.64。它适合作为风险标记，不足以成为正收益筛选器。

回撤少于15%没有稳定改善；在60日相对深回撤组更好，10／20日差异跨零。近期突破覆盖前200约48%，10／20／60日超额约-1.15／-2.03／-3.92。趋势回踩事件只占前100约6.4%，10／20／60日相对其他前100弱约0.58／0.83／1.06。两个既有池身份都没有拯救流动性宽池。

## 连续在榜与观察期限

前100刚入榜的10／20／60日超额约-1.04／-1.81／-3.57；连续10日以上成员改善到约-0.59／-0.96／-1.22。连续至少10日在榜只保留35.6%的前100成员和32.7%的10日大赢家记录，相对其余成员的10／20／40／60日收益改善约0.42／0.94／1.83／2.53个百分点，块区间位于零上。

这种改善是“少回吐”，仍不是正超额。其10日超额在2017、2019、2020、2025、2026为正或接近零，在2016、2018、2021—2024为负，跨年份不稳定。连续在榜应作为稳定容量标签，不能冻结为收益硬门槛。

若把前100每天都作为独立观察池，规模固定100，产品容量可控；真正问题是成员更换快，过程长度中位数只有1日。建议显示“新入榜／连续5日／连续10日”状态，并让其他池决定候选价值。没有必要把离榜股票额外保留20／40／60日；未来窗口是研究标签，不代表验证过的持有期。

## 市场、热度与原版复杂度

在全市场近20日非正环境，前200的10／20／60日绝对收益约-0.65／-1.40／-3.17，超额约-0.02／-0.01／+0.25，表现接近市场；在正环境超额约-1.17／-1.85／-3.02。固定相同价格状态后，弱环境中的前200相对201—500仅1日有约+0.05，10／20／60日约+0.17／+0.06／-0.10且区间跨零。它有弱市容量代理特征，但未证明稳定抗跌增量。

原版四源热度只能在短共同期比较：同花顺／雪球46日、百度34日。前100榜内外匹配结果跨来源不一致：百度和雪球1—2日有小幅正差，同花顺2—20日及三源10—20日多数为负；共同期太短，不能证明“四源召回＋打分”比成交额身份更有收益价值。热度继续作为来源标签，不把缺来源当作无热度。

本轮没有用当前行业成分回填历史。归档题材覆盖只有84日且并非完整行业全集，无法可靠回答长期板块轮动增量；该问题留到有逐日历史成分和强度数据后验证。

## 本轮收敛决定

| 用途 | 决定 |
| --- | --- |
| 入池硬条件 | 不建立独立收益趋势池；成交额排名保留为全局流动性／容量约束 |
| 池内优先级 | 排名档、连续在榜、新入榜、放量下跌、回撤和趋势拥挤作为状态标签 |
| 观察失效 | 排名身份按当日有效；离榜即失去容量标签，不额外机械保留20／40／60日 |
| 证据不足 | 前50优于前100、健康均线过滤、强趋势加分、连续10日提供正超额、近期突破／回踩加分、四源复杂打分值得保留 |

产品上可以保留一个“高流动性视图”，用于判断候选是否承载得住资金、排序同类股票及展示市场注意力。收益候选应由其他池产生；成交额排名作为权重或约束叠加，避免把“好交易”与“未来会上涨”混成一个结论。
