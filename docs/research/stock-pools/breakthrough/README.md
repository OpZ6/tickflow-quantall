# 突破池研究

更新日期：2026-09-13。状态：v1宽池与v2量能／次日确认探索完成，尚未冻结收益筛选规则。思想见[股票池提纲](../../../../prompt/bucket.md)，方法见[公共协议](../protocol.md)。

目标：确认60／100／250日新高的候选价值，分开研究突破后的当前状态与观察有效期，再检验量能、前置结构、板块环境及热度的增量。

## 首轮口径

- 以收盘价严格超过此前N个市场交易日的最高收盘价定义主事件，N取60／100／250，当日不进入历史阈值。最高价突破作为独立对照口径，分别计数；此前N日须有完整市场日价格。
- 宽召回覆盖当日突破及此前19个交易日内突破，保留0／1–3／4–5／6–10／11–19日事件年龄。提纲中的10／19日两种窗口作为嵌套对照，不在执行前只留下其中一组。
- 每个股票与新高窗口保留事件序列；同日满足多个窗口保留标签，每日股票并集另行去重。连续新高共用一次过程，最近新高刷新年龄；间隔至少一个非新高日后重启过程。
- 全部未来价格标签从T+1开盘起算，固定1／2／3／5／10／20日，预热不足、停牌缺日及末端未成熟保留缺失。
- 不提前过滤放量、回踩、破位、封板、市场环境或热度；保留对照后才能研究这些条件。
