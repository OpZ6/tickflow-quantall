# 突破池v2：量能过程与次日确认协议

执行前固定于2026-09-13。本轮承接v1的价格覆盖、复权、市场交易日、三种收盘新高窗口及价格标签，另存产物，不覆盖v1。

## 样本与时点

主样本为60／100／250日收盘新高的突破过程首日，各窗口独立；连续新高中的后续日不混入主样本。v1按“中间至少一日未创新高”划分新过程，它不等于长期平台首次突破。

全部收益仍从T+1开盘起算，固定1／2／3／5／10／20个市场交易日。复用v1事件标签与全市场基线；新增特征由同一截止2026-09-11的标准日线计算。2015年成交量不进入预热，严格检查市场缺日。

分开两个可得时点：

- T收盘可得：突破前量能、突破当日量能、突破幅度、上影线、前期涨幅、T日封板与市场环境。
- T+1开盘可得：次日开盘相对复权T收盘的跳空，以及相对突破位的位置。不得用于T收盘入池，不使用次日全天成交量或高低价筛选。

## 固定粗分档

| 因素 | 定义与分档 |
| --- | --- |
| 次日跳空 | T+1复权开盘／T复权收盘-1；低于-3%、-3%至-1%、-1%至1%、1%至3%、3%至5%、5%以上 |
| 突破量比 | T成交量／T前20日平均成交量；<0.8、0.8—1.5、1.5—3、≥3 |
| 前5日安静度 | T前5日均量／更早20日均量，两段不重叠；<0.8、0.8—1.2、≥1.2 |
| 前10日安静度 | T前10日均量／更早20日均量，两段不重叠；同上 |
| 前20日异常放量次数 | 对每个历史日按其此前20日均量计算量比≥2，再在T前20日计数；0、1、≥2。未知不算未放量 |
| 突破幅度 | T收盘／过程首日历史突破阈值-1；<1%、1%—3%、3%—5%、≥5% |
| 上影占比 | (T最高-T收盘)／(T最高-T最低)；≤20%、20%—50%、>50%；无振幅另列 |
| 前20／60日涨幅 | T-1收盘相对T-21／T-61收盘，排除T；<0、0—10%、10%—30%、≥30% |

边界按脚本半开区间固定；这些是解释用粗分档，不扫描最优数值。

## 分层、对照与采用标准

先单因素，再只做三条有解释的交互：突破量比×次日跳空、前5日安静度×突破量比、前20日异常放量次数×突破量比。

提前保留五个假设对照，不按结果挑最高组合：温和至放量突破后小幅高开、前期安静后放量、前期未异常放量后放量、前期安静后放量且小幅高开、较小幅度突破且收盘靠近日内高点。分别比较同日保留／剔除、保留规模、左尾、10日固定收益≥20%事件记录的保留率和年度稳定性。

主要收益与超额均日期等权，分位数及赢家保留按事件记录；相关窗口不视为独立股票机会。500次20有效日期循环块重采样用于均值超额和同日差值，不能代替独立验证或多重检验校正。少于40有效日期不生成置信区间，避免整段样本形成常量区间；循环块减少短样本中首尾日期被系统性低估的影响。跨年及2016—2020／2021—2023／2024—2026只作稳定性诊断，完整历史已参与探索。

新高身份、当前状态及次日确认的增量分别解释。相对原池改善不等于有正超额，少数组正超额也不等于已可冻结规则。封板状态保留并追加已知非封板对照，不推断开盘成交可行性。

## 首次粗表后的追加诊断

查看粗分层后，另检查前期安静×巨量突破、低开1%—3%、长上影、前期一次异常放量×温和放量。这四组明确标为事后关联诊断，不冒充预设五个假设或独立验证。前期安静在同日、相同突破量能档内追加跳空及封板状态对照；长上影对照相同跳空、量能与封板。每个状态格两侧至少各3个事件，格等权后日期等权，报告实际重叠日期及格数。

价格定义另追加T收盘是否也超过此前N日最高价，用于区分“收盘价新高”与“收盘已越过历史盘中最高”。仍保持原收盘新高宽事件不变；长上影再追加此分层控制。该区分不代表已验证真实筹码套牢压力。
