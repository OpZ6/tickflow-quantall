# 炸板修复池v1：日线全历史探索

执行日期：2026-09-14。事件覆盖2016-01-04—2026-09-11。全部未来收益从观察日的**下一市场交易日开盘**起算，固定1／2／3／5／10／20日。

## 结论

日线炸板事件只有下一日的短期反弹，不能支持1—5日修复池。事件日之后1／2／3／5／10／20日市场超额约+0.40／-0.04／-0.16／-0.60／-1.20／-2.02个百分点；10日超额在2016—2020及2022—2026均为负，2021仅+0.09。

事件后1—5日每日成员的1日超额约+0.14，2日接近市场，3／5／10／20日为-0.13／-0.36／-0.79／-1.45。首板尝试相对二板和高板损耗较小，10日仍为-0.68；二板和高板为-1.20／-1.76。

重新封板不是后续收益确认。当前已经再封板的成员1／5／10／20日超额为-0.13／-1.40／-2.68／-4.56；曾在事件后修复的成员10日为-1.89，尚未修复组为-0.64。修复率与当前价格继续观察价值方向相反。

本轮不建立独立炸板修复收益池。炸板事件只保留为1日风险／反弹观察标签；尝试板位、是否破事件低点、修复状态和量能用于其他候选池的风险展示，不给重新封板正向权重。

## 样本与边界

全市场识别74,164次日线炸板，展开事件日及后续1—5日共442,761条观察；同一股票／日期取最近事件后，每日账本333,844条、5,044只股票、2,598日，日规模中位数116、P90为195。

事件按最高价触及板块和日期对应的10%／20%／30%理论涨停价、收盘未封定义。前一市场日连续板数加一作为尝试板位。上市前20个有效交易日已排除，避免44%首日涨幅和注册制无涨跌幅期被误判；北交所开市前新三板行情也已排除。

历史ST名称和5%涨停制度不可用，因此ST炸板不在本轮覆盖内。日线无法确认触板时刻、开板次数、封单或尾盘是否可成交；这些限制不能用涨幅或换手补造事实。

## 板位、时间与状态

首板尝试占83.8%，二板10.7%，三板以上约5.5%。5日内重新封板率分别为11.4%、23.3%、33.6%，说明高板更容易出现形式上的修复；但高板在3日后回吐更大。

事件后1—3日的1日超额约+0.18，3／10日为-0.14／-0.87；4—5日为+0.08／-0.11／-0.64。较晚组只是少回吐，没有形成等待到第4日的正收益依据。

守住事件低点保留72.6%的成员，10日超额-0.93，相对破低组反而少约0.23个百分点；它不是有效硬条件。缩量只保留18.7%，10日为-0.47，相对其他量能改善约0.44，仍未跑赢市场。量比2倍以上1日有+0.28，10／20日转为-1.38／-2.34。

非趋势组比强趋势组少回吐，10日约-0.54；强趋势约-1.43。炸板后追求更强趋势、重新封板或高板位都会增加中期拥挤风险。

## 收敛决定

| 用途 | 决定 |
| --- | --- |
| 候选价值 | 不建立独立炸板修复池；事件次日仅保留1日观察标签 |
| 当前状态 | 展示首／二／高板尝试、破事件低点、是否已修复、量能和事件年龄 |
| 观察失效 | 事件后第1日即降级，第3日后取消收益权重；不机械保留5日 |
| 不采用 | 重新封板加分、不破事件低点硬条件、高板优先、缩量即有效、尾盘介入口径 |
