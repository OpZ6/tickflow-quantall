# VCP / 杯柄：选股与退出分离诊断

协议：[selection-exit-ledger-diagnostic-v1.json](selection-exit-ledger-diagnostic-v1.json)。仅使用两份冻结训练账本，逐笔确认完整 40 日标签、退出和标签末日均不晚于 2022-12-31。

## 结果

| 口径 | 宽泛 VCP | 杯柄 |
| --- | ---: | ---: |
| 事件数 | 4,396 | 98,489 |
| 信号日数 | 1,322 | 1,643 |
| 逐事件 40 日毛 Alpha | +0.231% | -0.191% |
| 信号日等权 40 日毛 Alpha | -0.575% | -0.718% |
| 逐事件实际净 Alpha | -0.723% | -1.053% |
| 信号日等权实际净 Alpha | -1.193% | -1.176% |
| 持有 bar 数中位数（含入场日） | 10 | 5 |
| 40 日 MFE ≥50% 路径数 | 246 | 4,829 |
| 上述路径兑现比例中位数 | 19.60% | 3.66% |

按日等权是先对同信号日事件取均值，再对有信号的日期取均值。它是事件聚集诊断，不是每日账户收益或消除了重叠的组合曲线；无信号日期不进入该均值。

## 机制结论

两者都未证明选股有效。VCP 的弱正逐笔均值在信号日等权后翻负，说明结果对信号密集日的加权敏感；不能将问题仅归为退出。杯柄两种权重下的选股均值均负，实际净 Alpha 在七个训练年全部为负。

退出兑现仍有研究线索，但不能据此放宽止损。杯柄信号退出的 72,859 笔，固定窗毛 Alpha +0.608%、实际净 Alpha -0.620%；止损的 22,591 笔分别为 -5.705%、-5.557%，未显示简单取消止损即可改善的证据。达到最长持有期的 3,039 笔两者都正。退出原因与大赢家标签均为事后分组，存在选择偏差，不能直接转成入场规则。

宽泛 VCP 的 4,394 笔由信号退出，其余 2 笔为路径结束。2016、2021、2022 年的实际净 Alpha 高于固定窗毛 Alpha；退出并非每年都拖累。大赢家兑现偏低只能支持进一步检查退出路径。

## 修正与下一动作

此前基线决策中“default exits destroy the selection edge”的因果表述过强，本次诊断对该解释作出修正，基线数值和未通过训练门槛的决策仍成立。

固定窗使用毛收盘收益，实际退出包含费用且持有期不同，差额不能当作纯退出效应。MFE 是事后最高价，兑现比例低也不代表能在最高价成交。

两者维持 `selection_supported=false`，未通过第一级训练门槛，不启动时间测试或参数搜索。下一动作是从现有交易路径定位信号退出后是否持续恢复、恢复前的下行风险及可在退出时识别的结构失效条件；只有形成具体机制后，才能另行预登记同候选、同入场、同成本的退出对照。本轮不登记放宽止损、延长持有或删除入场信号的实验。
