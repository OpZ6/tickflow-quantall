# 退出结构证据覆盖

本轮是定义与字段覆盖检查，不是预登记策略干预，也不授予晋级资格。

## 当前退出语义

- 宽泛 VCP：`_quants_vcp.py` 使用当日收盘低于均线且前一有效收盘不低于均线的穿越条件，默认 MA20。
- 杯柄：`_quants_legacy_patterns.py` 使用收盘低于 MA20 的持续状态。
- 两者退出均未引用入场时固定枢轴。不能把当前均线退出解释为原形态已失效，也不能直接借用另一策略的枢轴退出实现。

原始成交账本均无入场 pivot 字段。VCP 的 4,394 笔信号退出、杯柄的 72,859 笔信号退出均有 `exit_signal_date`；其中分别 230 / 25,198 笔在入场日或之前产生退出信号，没有信号日期等于入场信号日期的记录。这是需核对的入场后快速失效现象，不是 T+1 违规结论。

## VCP 重建

复用 `scripts/extract_vcp_entry_structure.py --run-id 20260909T135940874097Z`，当前检测器源码与原归档一致，全部 4,396 笔都还原为可执行入场，零不匹配。产物在该 run 的 `entry-structure-evidence.json`。

随后按 symbol、entry_signal_date、entry_date、entry_signal_id 连接成交和结构；仅在原退出信号日比较 enriched 收盘与原入场枢轴，不在退出日重新选择形态。相关源文件读取前大小/mtime 与基线引用一致。

| 退出时状态 | 笔数 | 实际净 Alpha | 固定 40 日毛 Alpha |

完整数值见 [VCP 语义覆盖](vcp/exit-pivot-semantic-coverage-v1.json)。这些是按已发生退出状态划分的描述性结果：上方组往往此前已有盈利，不能将组间差异视为取消退出的收益。固定窗与实际退出的成本和持有期也不同。

机制线索：均线失守与原枢轴失守确实不是同一事件，约 38.6% 的信号退出仍在原枢轴上方。下一动作先对这两个预定义状态复用退出后路径，确认“枢轴仍守住”的事件是否更能持续恢复及其下行风险；此后才能决定是否预登记“仅在枢轴同时失守时退出”的对照。暂不修改退出规则。

杯柄尚未重建入场枢轴。下一步复用原 `LegacyPatternStrategy` 的 420 有效 bar 输入和主形态选择，还原全部入场；必须先报告可执行状态和枢轴覆盖匹配率，不能直接套 VCP 的 260 bar 重建脚本或用退出日新形态替代旧形态。
