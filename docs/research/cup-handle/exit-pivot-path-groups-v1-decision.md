# 杯柄原枢轴与退出路径：不支持枢轴条件延迟退出

先复用原 `LegacyPatternStrategy("cup")`，按冻结数据引用、float32 矩阵输入、原多尺度/连续性选择重建全部 98,489 笔入场；全部为 executable，98,489 笔都有枢轴。源码与原 source.zip 一致，输入文件大小/mtime 与原引用一致。复现命令：`backend/.venv/Scripts/python.exe scripts/extract_cup_entry_structure.py`。原检测器使用最大 420 bar 尺度，同时保留此前历史有效性检查，未截短共享有效性判断。

将 72,859 笔信号退出按退出信号日收盘相对原入场枢轴分组，再复用 `analyze_post_exit_paths.path_labels` 计算退出日之后至旧 40 日终点的路径，不改变实际交易。

守住枢轴组没有显示更高恢复比例或更低“恢复前跌 10%”比例，均值也未更好。两组多数终点低于退出价。该差异不足以支持“保留止损、只在原枢轴失守时执行均线退出”的新实验。

决策：完成并停止本次简单枢轴条件退出的诊断分支，不围绕枢轴距离、恢复阈值或均线天数搜索。保留杯柄候选池定位与默认表示失败结论；只有独立的形态形成、需求确认或适用状态证据才恢复新研究。该诊断不否决整个杯柄思想，也未检验所有可能的退出策略。

分组只使用退出时已有的原枢轴和当日收盘，未来价格仅为标签。数值为价格路径，不是净可执行收益、Alpha 或显著性结论；独立事件存在重叠。完整逐年结果见 [analysis.json](exit-pivot-path-groups-v1-analysis.json)，输入连接键为 symbol、entry_signal_date、entry_date、entry_signal_id。

验证：重建脚本 Ruff 通过；现有迁移核心语义测试 26 passed。重建运行本身报告全量可执行匹配和枢轴覆盖，不以单个测试替代全量核对。
