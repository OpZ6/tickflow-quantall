# 策略研究现状与量化开发路线（2026-09-06）

本报告基于当前源码、本地 API、实际 Parquet 和 VCP 归档结果。属于调查与后续计划，不是实盘验收。2026-09-07 已完成生产复权因子覆盖修复，过程见 `adj-factor-repair-20260907.md`；历史证券集合、时点财务和独立前向验证仍未完成。未重新优化策略，未修改策略默认值。下文优先级是研究投入判断，不是收益排名。

## 1. 当前判断

- **可以继续量化研究，但生产数据暂不适合直接承担可靠的跨期业绩验收。** 股票日线长度已经超过十年；更紧迫的问题是复权拼接、历史股票池、财务/行业时点信息、独立测试隔离。
- **VCP 是最成熟的研究主线，还不是已验证可实盘的策略。** 最新领涨版本历史结果明显优于早期复苏版本，但规则选取使用过这些历史。需要先把研究数据与生产执行对齐，再积累冻结后的前向证据。
- **32 个可运行策略不等于 32 个独立交易优势。** 它们混合了候选筛选、简单指标、完整交易模板与高成交要求的情绪策略。全部保留可见，但研发资源集中到两条主线和少量对照。
- **后续继续基于 tickflow-quantall。** 现有矩阵回测、优化、步进优化、研究归档和 API 足以承载主要工作，无需回到外部 Quants 仓库再建一套系统。

## 2. 本次新发现：生产复权序列存在断点

生产日线已补到 2015-01-05；旧记录中的“两年数据”限制已经过时。然而，历史导入与后续本地数据的复权口径没有形成可靠连续序列。

本次只读核验了生产与 `ten-year-20160905-v1` 研究库：

| 检查 | 实测结果 | 含义 |
| --- | --- | --- |
| 生产复权事件表 | 121 行、46 个代码 | 不能支撑全市场十年复权的独立重建证明 |
| 十年研究复权事件表 | 34,605 行、5,227 个代码 | 与生产明显不同；事件表行数不等于完整性证明 |
| 2025-08-25 共同股票 | 5,292 只；原始收盘价相差 >1% 的为 0 只，复权收盘价相差 >1% 的为 1,985 只 | 差异集中在复权层 |
| 2025-08-22 → 08-25 共同股票收益 | 5,046 只中，1,885 只差异 >1 个百分点，519 只 >5 个百分点 | 不是单纯整个历史乘同一常数，跨日收益已改变 |
| 301550.SZ 在上述拼接日 | 生产复权收益 +108.27%；原始价及研究复权收益均约 -1.27% | 足以制造错误动量、RS、均线和突破信号 |
| 2025-08-25 → 2026-09-04 共同股票区间收益 | 5,284 只中，1,853 只差异 >1 个百分点 | 不能只修一个边界价格便宣告对齐 |

以上是已复现的数据缺陷；完整因子血缘和覆盖成因仍待专项修复。不能由此断言独立研究库全部正确，也不能把生产缺陷直接归因到使用独立研究库的所有历史收益。

**第一工作包应是复权与数据一致性修复。** 保留原始数据和旧研究快照，在新版本目录重建，确认价格连续性、公司行动、原始价涨跌停口径，再进行小范围对账和发布。不能直接用当前 46 个代码的因子表覆盖全市场 enriched。

既有 2026-09-04 候选对齐记录（Quants 38、TickFlow 宽池 28、交集 28）只能证明当时那次运行的候选关系。数据修正之后必须重做，不能把它当作长期价格与信号一致性的证明。

## 3. VCP 迭代现状

### 3.1 三个产物的职责

| 产物 | 当前状态 | 后续安排 |
| --- | --- | --- |
| `quants_vcp_legacy_v1`，VCP 宽泛候选池 | 当前可见；默认冻结；趋势、RS、多段收缩、枢轴、缩量、候选状态 | 保留每日宽泛筛选；数据修正不等于改变选股思路 |
| `vcp_recovery_breakout`，早期复苏突破 | 旧研究/兼容版本；不在当前 32 个默认股票策略内 | 保留失败与基准审计证据，不再作为主优化对象 |
| `vcp_leader_breakout`，领涨突破（前向观察） | 当前可见；`live_qualified=false` | 冻结对照版本；先完成生产对齐，再开展前向观察 |

宽池不是原著完整 SEPA 系统。当前核心有趋势和价格结构，但没有完整的盈利加速、行业领导力、基地阶段、渐进加仓等体系。保持核心思路一致，不追求机械还原所有原著条款。

### 3.2 最新完整版本做了什么

源码 `_quants_vcp.py` 与 `vcp_leader_breakout.py` 显示：

1. 继续使用宽泛 VCP 的形态引擎，不用均线交叉替换多段收缩。
2. 早期复苏分支：市场 MA20 宽度低于 30%，且高于五个交易日前，重点接受首次枢轴突破。
3. 强市场分支：宽度至少 70%、市场等权 63 日收益非负，排除短尺度形态，选择中长尺度 VCP。
4. 同日候选加入末段相对首段的收缩强度排序，权重 0.25。
5. 四个等额仓位、5% 初始止损；峰值盈利到 10% 后保护成本，到 20% 后允许距峰值回撤 10%；MA20 退出，最多持有 40 个交易日。
6. 完成日 K 生成信号、下一可成交日开盘执行，成本与 A 股约束在本项目引擎内模拟。

因此现在已经有退出规则，也已经调整了策略结构和仓位，并非只调 VCP 参数。平均持有时间也明显短于 40 日上限。

近年领涨版本同期研究库全市场等权收益为 +46.81%，几何超额约 +29.66%，单市场回归 beta 约 0.27、年化截距约 24.23%。这个基准使用同一研究股票集合，并剔除绝对日收益超过约 50% 的观测；不是可无成本投资的全收益指数。该脚本没有提供稳健显著性检验，也没有控制规模、动量等风格，**不能把这个截距写成已证实的 alpha**。

另有两个统计口径需要管理：引擎旧字段 `profit_factor` 实际是平均盈亏比，金额利润因子应读取研究摘要的 `monetary_profit_factor`；现有 Monte Carlo 把交易百分比重抽样后直接复利，不能代表四仓组合的真实回撤概率。其极端回撤输出应留作诊断，正式组合风险需要按日收益分块或带仓位的交易回放。

### 3.4 防过拟合状况

- 本地有 138 个 VCP JSON 文件（含配置、评价和协议，并非 138 次独立试验）、145 个运行目录；研究 API 返回 135 个完成且有结果的运行。需要建立完整试验账本，不能只保留最好结果。
- 标签研究曾有浅层模型训练 AUC 0.9707、次年 AUC 0.5381，已明确拒绝。现阶段不宜堆更复杂模型补救。
- 2024～2026 年数据已被反复观察。旧文档中的“仍封存”“最终留出”是历史阶段状态，不能作为当前声明。
- 已有前向协议计划从 2026-09-07 开始，最低 **252 个自然日且 60 笔平仓交易**。截至本次调查，行情末日为 09-04，不能因协议写着 `collecting_forward_evidence` 就声称已有前向成绩。
- 协议已有年化 15%、回撤不超过 20%、Sharpe 1、金额利润因子 1.5、正超额等门槛。这些是预设目标，不是收益承诺；达到天数或笔数也不自动证明统计可靠。
- 注册版本一致性报告证明在同一研究数据和指定覆盖配置下交易一致。其协议仍覆盖了 ST、新股等基础过滤；不等于当前页面默认配置、当前生产数据与研究收益已经全部相同。

本次数据缺陷处理完成前，应把原定前向日期视为待就绪检查的计划。若不能在首个观察日前完成，明确顺延正式验收起点，保留期间的工程观察记录；不要事后把修正数据重算出来的结果冒充当时可交易的前向表现。

生产原始日线的年末/当前末日行数为：2016年2,700、2020年4,029、2021年4,576、2023年5,256、2025年5,337、2026年5,548。2015 年最少日期仅1,303行，需要结合当日停牌与上市名册解释，不能按统一 5,500 只倒推缺口。

抽查 2015、2021、2025 拼接前后、2026 的 enriched 均没有 `net_mf_amount`。早期 enriched 只有14列，近期15列；矩阵策略可从 OHLCV 派生大量指标，列少本身不是不能回测，但输入字段与评分依赖必须逐策略核验。

### 5.2 “足够”的分层答案

1. **日频价量策略开发：长度基本够，修复质量后可推进。** 至少近五年主评价，加额外指标预热；2015年以来用于不同环境压力检查。VCP需要约260根预热，不能把预热阶段算作策略空仓业绩。
2. **严格超额和实盘资格：不够。** 缺少可信的历史可交易证券集合、ST/退市/改码、复权与基准一致性和新的独立样本。
3. **SEPA 成长/行业领导力增强：不够。** 要有公告时点财务、历史行业成员和行业相对强度。
4. **盘中情绪、打板、精确止损：不够。** 分钟可取不等于多年完整存档，五档实时可用也不等于拥有历史排队数据。

VCP目前的全市场宽度和等权收益由日线内部计算，不依赖只有80个发布日的QuantX事实表。修复日线与历史股票池后，这类可推导特征能回算；当年的新闻题材、真实资金流与行业归属不能用今天的快照同样回算。

能力 API 当前为 6/7：日线 TickFlow，因子 Tushare，实时扶摇，分钟和五档 TDX，财务 local_financial；全量分钟不可用。这是路由状态，本次未对所有外部接口做实时成功率或下载权限探测。

## 6. 策略应怎样继续优化

### 6.1 先回答“哪些候选会成功”，再决定怎么交易

以冻结宽泛池为母样本，每个 setup 记录信号日、尺度、枢轴、确认时点、结构低点、候选状态。按股票/枢轴/尺度去重；同一形态连续出现不能被当作多个独立成功案例。

保留两套标签：形态后续表现与可执行交易表现。既有“20日内先到+10%还是先到-7%”“40日内先到+20%还是先到-7%”作为连续研究基准；补充5/10/20/40交易日收益、最大有利/不利变动（MFE/MAE）、突破失败耗时和峰值利润兑现比例。标签是事后结果，永不进入信号日特征。

日 K 同日触及上下阈值无法判断路径，按保守约定或标记模糊；遇到T+1、涨停买不到、跌停卖不出，交易标签按可成交规则处理，不能将单纯触价率冒充交易胜率。开盘跳空只能用于次日执行拒单，不能提前用于前一日收盘筛选。

研究最多同时检验少数假设：

- 结构：最后一段振幅、收缩持续时间、前期涨幅、枢轴上方套牢压力、突破距失效位的距离。
- 领导力：股票RS、历史行业RS、行业内强弱；财务加速须待公告时点数据可用。
- 市场：保留冻结双状态作为对照，比较更平滑的风险分配假设，避免反复搜索30%/70%附近的小数阈值。
- 执行：首突破、下一日不过度追高、回踩确认作为独立进入方式；不能看到哪种涨得多就追溯改变分类。

严格过滤有代价：胜率可能上升，但大赢家召回和交易机会下降。因此同时看保留样本比例、成功率增量、大赢家召回、成本后每笔期望、组合资金利用率。只追求胜率或最高MFE都不是最终目标。

### 6.2 完整策略的重点

- 以结构失效位定义初始风险，对照固定5%止损；止损过窄会把正常波动当失败，跌停/跳空又能令实际亏损大于设定值。
- 仓位按账户风险与止损距离约束，再受单股上限、总敞口、行业集中度和成交额参与率限制。现有四仓25%配5%止损，单仓名义账户风险约1.25%，四仓约5%，并不是“最多只会亏5%”。
- 保留右尾：快速退出失效突破，与跟随确认后的赢家分开研究；不把统一10%止盈当作VCP最终答案。
- 研究“突破买入”与“启动后回踩买入”的收益互补，而不是叠加多个高度相关的突破策略增加名义策略数。
- 每个变更分离选股、排序、进入、退出和仓位影响，做小规模消融；禁止把多项改动一起包装成单一“改进”。

## 7. 可执行的后续阶段计划

以下是工作量估计，不是收益或日历完成承诺；外部数据权限可能影响顺序。前向证据所需时间不能靠算力压缩。

| 阶段 | 预计投入 | 交付物 | 进入下一阶段条件 |
| --- | --- | --- | --- |
| S0 数据止错 | 3～5个工作日 | 复权断点定位、因子血缘、隔离重建、跨数据版本对账、修复后的版本说明 | 已复现异常消除；原始价/复权价契约成立；关键候选复现 |
| S1 研究地基 | 1～2周 | 历史证券/基准最小集合、正式覆盖报告、试验账本、冻结协议、统一指标报告 | 年度/股票/字段覆盖清楚；能解释区间裁剪、预热与无信号 |
| S2 VCP与回踩 | 2～3周 | VCP冻结版本生产复现；真假突破标签更新；启动后回踩首版；少量机制消融 | 至少多个时间段方向一致；成本后期望与基准结果可审查；不碰新留出 |
| S3 第二梯队 | 1～2周 | 平台/60日新高基线，杯柄/旗形事件频率与增量研究 | 有足够独立事件且对基线存在增量才继续；否则保留筛选用途 |

建议初期精力分配：40% 数据与时点质量、35% VCP及回踩研究、15% 前向记录与结果展示、10% 学习和图形复核。数据底座达标后再把更多精力转向策略。

### 7.1 样本隔离制度

1. 历史已暴露清单单独登记；旧 VCP 2017～2026结果标成开发/诊断。不能重新切一次训练测试就“洗成未见”。
2. 新策略可以用按时间滚动的开发评估，但在已有历史上做家族选择同样产生研究者偏差，最终仍靠新的前向样本。
3. 对未来20/40日标签，在训练边界剔除结果窗口跨到验证期的样本；需要时增加隔离间隔。预热可以读取更早历史，训练标签不能读取更晚结果。
4. 当前 `walkforward.generate_folds` 使用自然日 `timedelta`，参数252并不等于252个交易日；尚未看到标签窗口级purge/embargo。正式研究前明确日历语义、跨折持仓及重叠OOS处理，不能把已有步进优化直接称为完整防泄漏系统。
5. 首轮每个假设预设不超过3～5个粗候选（建议预算），登记失败与停止条件。比较稳定区域，不选孤立尖峰。
6. 复用已有 `stats_v2.py` 的HAC、FDR、DSR能力；它们已存在，但尚未证明VCP完整试验谱系自动接入。试验次数与相关性未定义时，不生成看似精确的多重检验结论。
7. 冻结后的改规则、调排名或改股票池，建立新版本和新观察起点；旧版本保留作对照，旧观察不回写。

多次尝试后挑最优会放大样本内收益，普通留出也不足以消除研究过程的选择偏差，见 Bailey 等人的 [回测过拟合研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。DSR用于处理多重尝试和非正态带来的Sharpe夸大，方法见 [Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)。这些工具辅助评估，不能替代新样本。

### 7.2 每个完整策略的统一验收报告

必须同时包含：实际评价区间与预热、逐日合格股票数、输入字段覆盖、规则与数据版本、信号和成交时间、成本与不能成交情况、交易数/胜率/平均盈亏比/金额利润因子、年度收益/回撤/资金暴露、宽基和风格基准、同市场状态表现、最大赢家依赖、成本压力、参数邻域、前向偏差。

现有 `data_day_coverage` 分母来自已加载矩阵日期，分子只要求当天至少一只有效价格。即使等于100%，也不能证明独立官方交易日历和全市场个股覆盖完整。这一指标需要与真正的预期交易日和可交易证券集合并列展示。

策略分两级交付：

- **盘后指导级**：数据可信、候选逻辑可解释，给出触发价、失效条件、状态和拒绝原因；没有收益资格也可以提供观察价值，但不冒充买入建议。
- **执行候选级**：上述条件之外，还有完整进入退出、组合风险、容量约束、独立前向证据。再评估有限真实资金验证，不能因历史年化高就升级。

本阶段不为32个策略分别新增大量镜像测试。软件验证聚焦复权拼接、时点可用性、标签跨界、信号成交时序、涨跌停/T+1、资金账和生产研究一致性；盈利能力由研究与前向实验验证。
