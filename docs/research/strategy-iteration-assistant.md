# 策略迭代助手：用法

持续迭代，直到用户确认有效的多策略体系。有效 = 选出的票独立成交：大盈利小亏损（高盈亏比 + 够用胜率），扣费后平均收益为正；同时验证频率、适用环境与策略互补。不管仓位。

## 当前轮换（2026-09-13 用户纠偏）

VCP 低频且依赖环境，保留冻结参照。杯柄和放量突破·缩量回踩同时作为活跃研发线，各有基线、机制假设与全量独立对照；先杯柄一轮，再回踩一轮，然后汇总覆盖。不等待 VCP 最终验证才开发其他策略。高旗旧表示停止，新机制按 [主计划](quant-development-plan.md) 的条件评审重启。

每轮记录年/月成交数、有信号日占比、最长无信号期、当时可见环境下的频率与净收益，以及同日/同股重合、独有机会和共同亏损。提高频率须验证新增机会质量，不放宽阈值凑次数，不预设形态互补或全天候有效。每条线最多一轮定向诊断后进入规则实验或淘汰假设。恢复动作以根目录 goal.md 为准。

## 思想（保留，代码可改）

方向是右侧强势股：VCP、杯柄、高旗、放量突破、缩量回调。这是选股思想，不是冻死的检测器。结构过滤、量价、买卖点代码都可以改，只要还是这一套：强势 + 收缩/整理后的突破或回踩/企稳，卖点是回撤、止损、破均线等。

买点菜单：突破、回踩、企稳。卖点菜单：回撤、止损、破均线、利润保护。

下一轮必须换**种类**或先做路径解剖，不能把检测器里的连续字段再切一档。

## 每一轮

用 TickFlow 全量独立回测所有选出的票。相对当前基线只动一处（思想内的选股或进出）。拿到成交后做细化分析（胜率、盈亏比、平均收益、亏在哪类路径），提出下一处改进，记下来，继续。基线随留下的规则前移；扔掉则基线不动。

不要扫参网格，不要改成月末因子或均线金叉主线，不要拿资金曲线当验收。10/20 日只看路径，不强制拿满。

**也禁止无网格炼丹：** 同一本账上再收紧 `volume_ratio`、`tightness`、`dry_volume_ratio`、RS、距年高、收缩比，即使只测一个整数阈值。那不是新机制。量比 1.50、tightness 0.40 已扔；`dry_volume_ratio≤0.70` 不要做。主本冻在 179 笔，不再靠筛分把 n 收到几十笔。

新一轮要能回答：改的是哪一种买/卖，针对哪条亏损路径。答不出就先解剖，不要开 overlay。
