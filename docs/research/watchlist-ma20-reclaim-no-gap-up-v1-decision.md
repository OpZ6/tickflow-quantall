## 四句

1. **改了哪条规则：** T+1 开盘若高于信号收盘则不买、不顺延。
2. **相对哪条基线：** 同一批收回全部 T+1 都买（10 日净 +0.42%，20 日净 −0.13%）。
3. **5/10/20 日信号日等权净：** +0.15% / +0.46% / −0.28%。10 日略好，20 日差于全部 T+1。
4. **淘汰不追高开。** 保留全部 T+1 买入。不扫缺口百分比。下一枪顺序 6：同一批收回上，前两根最高价从未 +3% 则第 3 根开盘走。
