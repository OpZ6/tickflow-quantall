# VCP 领涨突破实现方向审计（2026-09-08）

## 目的

本审计不比较收益，也不寻找更优参数。它检查 `vcp_leader_breakout forward-v1` 是否把 VCP 的第一性原理完整表达成同一条交易逻辑：先导上涨与市场领导力 → 多段供给收缩 → 右侧紧枢轴 → 需求扩张突破 → 与枢轴结构一致的低风险失效位。

外部方法依据只取不依赖具体百分比的稳定概念。Minervini 官方站托管的 [Master Trader Program 复盘](https://cdn.minervini.com/static/dist/mtp-review.1f8e8633.pdf)把 VCP 描述为右侧紧缩、供需变化、精确枢轴与突破确认的组合，并将盈利/营收/利润率增长与早期市场领涨股作为完整框架的其他组成部分。公开访谈索引中 Minervini也明确强调 VCP 是供需变化的结果，而不是图形本身的原因。这里不把任何书中示例百分比移植成 A 股参数。

## 方向性缺口

### 1. 旧兼容分支把突破量混入供给收缩

`vcp_leader_breakout` 使用 `QuantsLegacyVcpStrategy`。该分支将最近 10 根（含触发日）均量除以最近 50 根均量作为 `dry_volume_ratio`，同时又要求触发日量比至少 1.25。于是突破日需求越强，供给收缩评分越容易被压低；两种不同阶段的信息被混在一起。

冻结基线 298 笔实际成交的因果重建显示：排除触发日后 43.29% 满足既有缩量定义，旧兼容值只有 31.88%；36 笔分类改变。旧值与排除触发日值的差额同突破量比相关系数为 0.739。该字段不直接决定突破资格，但参与形态质量与拥挤日排序，因此不是纯展示问题。冻结 `forward-v1` 不回写；后续研究表示必须分开 `prebreakout_supply` 与 `breakout_demand`。

### 2. 当前“枢轴”是宽收缩腿高点，不是独立的右侧紧枢轴

检测器把最后一条已选宽收缩腿的高点直接设为 pivot。实际成交的入场到末段低点风险中位数为 10.33%，赢家与非赢家均约 10%。固定 5/10/20/40 日窄幅审计也没有恢复出有效结构，说明问题不是少一个窗口阈值，而是缺少“宽基底内部再识别最终微型阻力与结构低点”的嵌套层。

### 3. 三套失效位不一致

- 形态证据的 `plan_stop_pct` 默认在 pivot 下 3%；
- 回测成交内核实际固定止损为入场价下 5%；
- 宽收缩腿的真实低点距入场中位数约 10.33%。

3%、5% 和末段低点分别来自元数据、组合规则和宽腿结构，彼此没有统一因果含义。此前“跌回宽腿枢轴即退出”已经伤害正常赢家，因此不能在三者之间再挑历史最优值。

### 4. 完整 SEPA 的非价格层仍不完整

公告时点财务的孤立变量没有稳定区分力；2026 行业快照不能倒灌历史；动态价格同行也没有通过预登记门槛。这不否定公司质量、预期修正和行业领导力，但当前不能用弱代理拼成分数。冻结策略只能称为“价格结构与市场阶段版本”，不能声称完整复制股票魔法师体系。

## 决策

1. `vcp_leader_breakout forward-v1` 保持不可变，继续作为已经启动的前向观察基准。
2. 下一研究对象是独立的 `nested final pivot` 表示层：在已经识别的宽 VCP 内，因果地寻找最后一个经后续完整日线确认的微型阻力高点，并以其后的实际最低点作为结构风险；不设置合格阈值、不产生交易。
3. 首轮只验证表示是否存在、是否显著缩短宽腿风险，以及跨年度覆盖是否稳定。表示不成立即停止；成立后才允许讨论“计划位与仓位风险如何统一”，仍不得从 3%/5%/8% 中挑值。
4. 供给收缩与突破需求拆成两个字段。旧兼容值只用于复现旧版本，不进入新表示的质量评分。
