# 宽泛 VCP：原入场枢轴失守替换均线退出

状态：已完成，以下保留为实施前计划。冻结协议见 [entry-pivot-exit-replacement-v1.json](entry-pivot-exit-replacement-v1.json)，结果及后续联合支撑实验见[退出实验决策](matched-exit-experiments-20260910-decision.md)。恢复任务以根目录 `goal.md` 为准。

问题：MA20 穿越是动态趋势条件，原入场枢轴是形态成立依据，二者并不等价。已有 1,694 笔信号退出发生在仍守住原枢轴时，足以提出替代退出假设；其后固定终点不佳不等于动态枢轴止损已被测试失败。

唯一拟议变化：对每个独立入场事件固定其入场信号日枢轴，入场后首次完成日线收盘低于该枢轴时，按原 T+1 成交规则退出，替换默认 MA20 穿越信号。不随后续新形态更新枢轴；重叠事件必须各自保留自己的枢轴，不能用一个股票级全局状态混同。

基线：`20260909T135940874097Z` 的 4,396 笔成交与已匹配的 `entry-structure-evidence.json`。复用既有独立成交模拟器、税费、滑点、停牌/涨跌停约束与训练边界。原领涨 VCP 的枢轴实验是不同入场流上的“附加退出”，其结果保留作先验风险证据，不当作本替换实验的结果。

实现前必须解决：原宽泛池没有显式最长持有设置，原运行的价格加载末端属于计算截断，不能将其伪装成策略退出。需为两个对照臂统一冻结观察边界，分别报告真实退出和期末未平仓估值，披露截断事件数；必要时在共同窗口重放原规则，不能拿新窗口结果与旧窗口均值直接相减。

随后冻结：对照臂、唯一变化、入场身份一致性、观察窗、税费和成交语义、样本与配对净超额/年度/下行/右尾门槛、按日期区块的置信区间计算方案。完成上述必要定义和边界测试后运行两臂，完整保留失败与未平仓事件，不按结果筛选。

结论范围：退出贡献与路径风险。固定候选的选股 Alpha 不因改变退出而被重新判为有效；晋级仍按方法论全部门槛，历史实验通过也不等于未暴露样本外或实盘可用。

实施结果：已复用 `simulate_independent_market_matrix` 完成 4,396 笔同入场重放，统一 40 根有效交易 bar 终点与未平仓估值；训练门槛未全部通过，停止该规则的相邻参数搜索。
