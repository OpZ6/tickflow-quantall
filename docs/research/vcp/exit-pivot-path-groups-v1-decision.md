# 原枢轴状态与退出后路径

按上一轮确定的两个退出信号日状态分组，复用 `analyze_post_exit_paths.path_labels`，仅读取原数据引用覆盖的日期并核对大小/mtime。退出日之后至原 40 日终点为观察窗。输入是基线成交、已匹配的入场结构和原路径标签；事件按 symbol、entry_signal_date、entry_date、entry_signal_id 连接。

| 指标 | 已失守枢轴 | 仍守住枢轴 |
| --- | ---: | ---: |
| 可观察事件 | 2,695 | 1,603 |
| 曾恢复退出价 | 84.45% | 85.53% |

| 终点价格变化均值 | +0.706% | +1.082% |
| 终点价格变化中位数 | -1.534% | -0.398% |
| 终点高于退出价比例 | 45.42% | 48.41% |

分组由退出信号日收盘是否不低于原入场枢轴确定，不用未来恢复分类。相比全量信号退出的 2,700 / 1,694 笔，本表分别排除 5 / 91 笔退出日不早于 40 日终点的事件，不能据此评价更长持有期。

守住枢轴组下行相对较轻，但恢复比例仅略高，终点上涨仍未过半，逐事件终点均值仅 2017、2019、2020 三年为正。它没有给出稳健的持续持有优势；组间差值也不是风险调整收益或因果退出效果。

决策：本轮不登记“只在原枢轴失守时才执行 MA 退出”。这项简单状态诊断已完成，停止继续切相邻枢轴距离或恢复阈值寻找好结果。宽泛 VCP 保留候选池，未来只有独立的结构/需求证据才恢复退出干预研究。当前转向杯柄自身的入场结构覆盖检查，不能把 VCP 分组直接迁移过去。

完整逐年数据见 [analysis.json](exit-pivot-path-groups-v1-analysis.json)。研究没有改变入场或退出，未运行替代交易策略，未申请时间测试。
