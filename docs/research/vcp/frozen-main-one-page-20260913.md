# VCP 冻结主本：一页核对单

状态：研究主本，用户尚未确认有效。以下是已经完整独立撮合的规则；当前产品买入名单尚有差异，见末表。

## 看谁、何时买

沿用冻结 `vcp_leader_breakout` 的领涨宇宙、双市场阶段、趋势与量价条件，原参数见归档 run `20260909T030431101979Z/strategy.json`。在原信号上同时要求：

1. 信号日收盘位于当日高低区间上半部。
2. 原检测器选定的主形态至少有三段收缩。先选定原主形态再检查，不能通过改检测器参数另选一个替代形态。
3. 信号收盘确认，下一市场交易日开盘按原可成交约束买入；独立记录每个信号，不按持仓数量或资金曲线筛选。

## 何时退出

- 保留原 MA20 下穿信号：本次收盘低于 MA20，前一有效收盘不低于其 MA20，下一市场交易日开盘退出。
- 持有后某次**收盘**达到实际入场价的 105%，启用新增的守成本规则；之后某次收盘**严格低于**实际入场价，次日开盘退出。收盘等于买价不触发，不拿展示用四舍五入价格比较。
- 保留原 5% 硬止损，以及原有分级保护：此前持有高点达到 +10% 后保护成本；达到 +20% 后增加距此前高点 10% 的回撤保护。它们与新增的收盘守成本共同存在。
- 保留原 40 根持有到期上限。T+1 禁止买入当天卖出；跳空可能越过保护线；不可卖出沿原撮合挂单规则处理。
- 普通日线模式中，已经预定的开盘卖出不能被当天稍后的高低价改写。开盘本身触发风控时，仍按开盘风控处理。

成本：双边佣金各 0.0003、滑点各 10bps，卖出加对应日期历史印花税。
