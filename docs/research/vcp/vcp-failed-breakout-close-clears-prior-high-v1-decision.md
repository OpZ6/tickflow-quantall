失败突破仍按解剖：持仓最高价从未到入场 +3%，净收益 ≤ 0（训练 42 笔，均亏 −5.07%）。

## 四句

1. **改了什么：** 突破买点，信号日可见。只留突破日收盘**严格高于**前一市场日最高价的单。等于昨高不算。缺前日 K 线不顺延。扔掉 39 笔未站上昨高。
2. **相对哪条基线：** 179 笔 +1.99%（上半区 ∩ 收盘 5% 守成本 ∩ ≥3 段）。
3. **胜率 / 盈亏比 / 平均净收益：** 训练 27.4% / 4.58 / +1.99% → 140 笔 27.9% / 3.99 / **+1.52%**。验证 149 笔 +1.56% → 121 笔 **+0.56%**（暴露，不是干净 OOS）。
4. **扔掉。** 训练均值低于基线，盈亏比下降。主本仍是 179 笔 +1.99%。不要再叠突破 K 线过滤（阳线、守前日低、收盘站上昨高）。杯柄不替换。下一处针对 **磨掉**（24 笔，均亏 −4.98%）只改一处回撤或止损种类。
