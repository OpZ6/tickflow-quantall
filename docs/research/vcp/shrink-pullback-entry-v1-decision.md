# 缩量回踩买：扔掉，均值翻负

协议 [shrink-pullback-entry-v1.json](shrink-pullback-entry-v1.json)。数字 [analysis](shrink-pullback-entry-v1-analysis.json)。不是已停止的守枢轴回踩规则。

## 四句

1. **改了什么：** 同一批 321 笔上半区突破信号，不买次日开盘，改为信号后 8 个交易日内首次缩量、收盘低于突破日、低点不破突破日低点，再下一开盘买，出场仍用原卖出价。
2. **相对哪条基线：** 321 笔 T+1 突破买原进出场。
3. **胜率 / 盈亏比 / 平均净收益：** 基线 26.8% / 3.94 / +1.24%；回踩成交 105 笔 **21.9% / 3.42 / −0.11%**。错过 210 笔。
4. **扔掉。** 与宽回踩一样切掉右尾。基线仍是 321 笔突破买。下一处改**企稳买**：信号后 3 日内收阳且收盘高于昨收，次日开盘买。
