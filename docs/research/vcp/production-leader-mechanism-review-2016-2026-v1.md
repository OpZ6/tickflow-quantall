# VCP 交易机制复盘（2016—2026，v1）

## 研究问题

本复盘不寻找更优参数，而是回答冻结 VCP 领涨突破基线靠什么赚钱、失败发生在哪里，以及下一步应该研究哪一种交易逻辑。当前输入为严格 T+1、使用历史股本并按退出日期执行历史卖出印花税的 run `20260908T024521089151Z`，包含 290 笔已完成交易和对应持有期日 K；旧 run `20260907T123519390606Z` 含 10 笔过期信号顺延成交，只保留历史审计链。未来 K 线仅用于成交后的 MFE/MAE 标签，不进入候选或信号生成。

机器可读结果位于 `data/research/vcp/runs/20260908T024521089151Z/trade-path-analysis.json`，生成器为 `scripts/analyze_vcp_trade_paths.py`。

## 第一性原理结论

1. **当前优势来自收益不对称，不来自高胜率。** 胜率仅 29.66%，但平均盈利 15.85%，平均非盈利 -4.07%，单笔平均收益 1.84%。因此为了提高胜率而继续收紧形态，会很容易删掉少数大赢家；此前“首次上穿”和“三段收缩”两个实验是旧执行口径下的停止记录，不作为当前精确收益对照。
2. **市场阶段是 VCP 的组成部分，不是外围参数。** 旧执行口径下移除整套阶段化设计后，候选从 837 增至 6,547、交易从 298 增至 1,183，止损占比升至 53.85%，最大回撤达到 -93.73%。但 `a_share_dual_regime` 同时控制阶段门、短周期准入和枢轴上方收盘规则，所以该结果只支持保留整套阶段化设计，不支持继续扫描市场宽度阈值，也不作为当前基线的精确收益比较。
3. **失败分成两类，不能用一个更苛刻的形态阈值处理。** 204 笔非盈利交易中，49.02% 在整个持有期从未取得 3% 的有利波动，属于突破后没有需求跟随；另有 35.78% 曾达到至少 5% 有利波动后回落至非盈利，属于利润保护或退出匹配问题。
4. **成败在早期路径上很快分化。** 止损交易首次触及 -3% 的中位数为入场后第 1 根 bar，触及 -5% 为第 2 根，持有中位数 3 根；盈利交易首次达到 +5% 的中位数为第 1.5 根，达到 +10% 为第 4.5 根，持有中位数 18 根。这支持研究“突破后的需求确认/快速失效”和“让赢家扩张”两套不同机制，而不是继续改变收缩段数。
5. **两个市场分支都保留了正期望。** 严格 T+1 基线中，早期复苏 95 笔，平均收益 2.38%、止损占比 41.05%；广泛上涨 195 笔，平均收益 1.57%、止损占比 44.10%。差异不足以支持删除任一分支，且不做分支阈值炼丹。
6. **收益集中但尚非五笔决定全部。** 前五大赢家占全部正收益 34.38%。后续要持续报告集中度，但不能因为大赢家重要就提前截断盈利，也不能凭少数样本宣称稳定 alpha。
7. **旧基线的执行入场形态曾按真实矩阵精度完整重建。** 冻结源码与 `float32` 矩阵输入边界下，旧 run 的 298/298 笔入场均可重建；T+1 修复后交易集合已变化，该覆盖数只保留为旧 run 的审计证据，不冒充当前 290 笔的完整形态覆盖。
8. **旧交易集合的静态形态字段没有把失败与赢家自然分开。** 赢家与无跟随失败的收缩段数中位数均为 3，收缩强度中位数分别为 0.564/0.579；突破前 10 日对 50 日均量比小于 1 的比例分别为 56.18%/63.73%。该结果不用于当前基线的精确效应估计，但足以约束“不因执行修复重开缩量阈值扫描”。
9. **已有失败研究不重复。** 历史 `iteration3-confirm2` 已测试两日枢轴确认并表现不佳；`candidate-label-study-v1` 也已拒绝机械经典 VCP gate 和跨年失效的学习分类器。本轮不重新包装这些方向。

## 决策

- 冻结现有 VCP 结构检测的 `min_legs=2`、`require_pivot_cross=false` 和阶段化双分支设计，不继续相邻阈值实验。
- 下一项不是调参回测，而是补齐候选级因果证据：在信号时点保存枢轴、末段低点、收缩段深度、干量比、突破量比、形态尺度和市场分支。所有字段必须只来自信号日已完成 K 线。
- 旧 run 已完成 298 笔实际成交的信号时点证据重建；严格 T+1 run 尚未重建全部 290 笔形态证据，旧覆盖不移植为新覆盖结论。
- 下一项采用方法级对照：建立“启动后缩量回踩”的同口径长基线，研究追突破与等待承接的差别。它不是 VCP 参数变体，结果需结合候选重合、早期失败、赔率、暴露和市场状态解释，不能按总收益二选一。
- 此后分别研究两个问题：无需求跟随的突破应如何定义快速失效；已经产生有利波动的仓位如何在不截断大赢家的前提下保护利润。两者不得合并成一次多参数实验。
- 在候选证据缺失前，不新增止损百分比、确认天数、宽度阈值或仓位数实验。

以下进场、退出和组合实验形成于旧的个股下一根 K 线执行口径。它们保留为“为何停止该方向”的历史方法记录，其精确收益差、交易数和赢家保留率不再视为当前基线对照；本次不重跑这些变体，避免借执行修复重启已暴露历史上的参数选择。

## 进场方法结论（2026-09-07）

通用启动回踩并未保留 VCP 形态与枢轴，不能作为有效对照。随后完成的同枢轴失败后再触发 run `20260907T135221128740Z` 将止损占比由 42.62% 降至 21.62%，但只有 74 笔成交，平均赢家由 16.45% 降至 6.85%，最好交易由 121.63% 降至 28.13%。这说明缩量重建提供了真实的二次确认信息，但等待它会错过驱动 VCP 收益的立即扩张。

因此首次突破继续承担主入场，失败后再触发只作为二次机会研究分支。进场组到此停止，不调整其窗口、枢轴带、缩量或窄幅阈值；下一项转向快速失效退出，目标是缩短无需求跟随交易的损失暴露，同时不改变赢家的分阶段利润路径。

快速失效退出 run `20260907T140039383354Z` 虽把平均亏损从 4.09% 降到 3.05%，却使 290 笔共同交易均值下降 0.34 个百分点，并使原 85 笔赢家中的 21 笔转为非盈利。枢轴下方收盘是有信息的弱势标签，但不是可靠的交易失效位，停止增加缓冲或确认参数。

按 `末段低点 = 枢轴 × (1 - 末段深度)` 还原后，298 笔实际入场到末段低点的风险中位数为 10.33%，赢家与非赢家分别为 10.10% 和 10.50%。当前 VCP 检测器捕捉的是宽收缩腿，尚未单独表达突破前紧枢轴台阶。后续研究先修正这一形态表示缺口，再讨论结构止损或仓位风险；不在现有宽腿上试 3%、5%、8% 等百分比。

严格截止到突破前一日的固定窗口台阶审计也没有形成有效区分：赢家/无跟随失败的 5 日振幅中位数为 8.24%/8.32%，10 日为 10.28%/10.35%，短窗收盘区间同样重叠；赢家的近期量比并不更低。由此停止固定窗口台阶筛选，不从 5/10/20/40 日组合中挑参数。下一机制转向突破日真实需求扩张及其相对市场领导力。

突破日价格强度变量也几乎不区分赢家与无跟随失败。只有量比呈现弱到中等关系（赢家/失败中位数 1.80/1.56，两两排序概率 0.61），且跨年不稳定。它支持“需求扩张值得观察”，不支持回看后提高量比阈值。纯技术入口变量到此停止，下一步核查公司增长与行业领导力能否以公告时点和历史成员口径进入研究。

## 公司增长与行业领导力审计（2026-09-07）

隔离财务缓存覆盖 2020Q1～2023Q3。按 `announce_date < signal_date` 的保守规则，它可为 2021-09-07～2023-12-29 的 1,258 个冻结 VCP 候选提供 97.38%～99.60% 的财务水平覆盖和 89.43%～91.65% 的单期变化覆盖，公告日前视违规为 0。审计只比较连续分布，不设阈值、不训练模型、不模拟组合。

结果不支持财务单变量过滤：营收同比、利润同比、ROE、毛利率、营收加速、利润加速、毛利率变化和 ROE 变化的整体两两排序概率均落在 0.483～0.509 附近；逐年方向还会反转。例如毛利率的赢家更高概率在 2021/2022/2023 分别为 0.565/0.416/0.531。完整证据见 `source-vcp-fundamental-growth-audit-2021-2023-v1.json` 和对应机器结果。由此停止最低增速、ROE、利润率或加速度阈值实验；这些字段只保留为候选解释证据。该结论只否定现有孤立变量门槛，不否定完整 SEPA 的公司质量、预期修正和行业领导力逻辑。

行业库存 `ext_hy_ths` 有 5,567 个唯一证券，但明确是 2026-09-07 快照且没有纳入/退出日期。对 Tushare `index_classify` 与 `index_member_all` 的最小能力探针均返回权限不足。因此当前行业标签不能倒灌 2016 年以来的候选，历史行业过滤继续禁用；在取得带日期的成员来源前，不围绕当前快照构造伪历史排名。

## 组合风险审计（2026-09-07）

冻结基线的最大回撤从 2016-10-28 延续到 2019-02-15，直到 2019-09-24 才恢复前高；有 63 笔交易与该区间重叠。这是跨市场阶段的长期路径，不是一个拥挤入场日造成的孤立事故。203 个入场日中有 66 个同时进入多只股票，共覆盖 161/298 笔交易；这些多标的批次只贡献全部负批次损益的 44.0%，低于其 54.0% 的交易占比。最差 5 笔交易只占总亏损 8.1%，亏损也不是少数异常点主导；相反，前 5 大赢家仍贡献总毛利 32.6%。

因此没有证据支持继续扫描 3/4/5 个仓位、限制同日开仓数，或按历史 14 笔最长连亏拟合降仓阶梯。这些规则会用已暴露路径选择参数，也可能在长期低迷后的恢复阶段削弱对右尾赢家的参与。四仓等权继续冻结，下一步进入追加式前向观察。机器证据见 `production-leader-portfolio-risk-audit-2016-2026-v1.json` 和 baseline run 下的 `portfolio-risk-analysis.json`。

## 个股上涨生命周期审计（2026-09-08）

按预登记口径合并三个连续开发区间并以 `symbol + scale + pivot_date` 去重，得到 2017-11-15～2026-06-30 的 3,771 个独立基底。基底前 63 日涨幅对二元突破标签的两两排序概率为 0.531，10 年中 8 年同向，但五分位成功率只在 35.7%～38.4% 间横盘，且与 40 日连续收益的 Spearman 相关为 -0.046，最高涨幅五分位的 40 日收益中位数反而最低。126 日涨幅、基底天数/深度、距年高、过去一年不同基底数和距前一基底天数同样没有同时通过年度方向与有序画像。

过去 365 日已有 0、1、2+ 个不同基底的样本成功率分别为 37.9%、36.6%、37.4%，不存在“越后期越差”的阶梯。由此停止基底次数、前期涨幅、基底年龄和距高位置的过滤方向，不把弱变量拼成生命周期分数，也不运行组合回测。机器结果见 `data/research/vcp/analysis/stock-lifecycle-2017-2026-v1.json`，决策见 `production-leader-stock-lifecycle-audit-2017-2026-v1-decision.json`。

## 动态同行需求审计（2026-09-08）

为避免用 2026 年行业快照伪造历史行业，使用信号日前 63 个交易收益识别每只候选的 20 个最高正相关同行，再只用信号日已完成数据描述同行趋势、20 日收益和阶段新高。3,771 个独立基底中 3,405 个具备完整同行组。四项同行指标的整体两两排序概率仅为 0.499～0.522，年度同向最多为 6/9 个可用年份；最高与最低年度内五分位的成功率差均不足预登记的 5 个百分点，同行趋势较强时连续 40 日收益反而没有改善。

因此动态同行只能保留为候选解释证据，不能替代带日期的行业/题材与催化事实。停止改变同行数量、相关窗口或拼接同行分数，不进入策略与组合回测。协议及决策分别见 `production-leader-dynamic-peer-confirmation-audit-2017-2026-v1.json` 和对应 `-decision.json`。

## 实现忠实度与嵌套枢轴审计（2026-09-08）

代码审计确认旧兼容分支把突破日成交量计入 `dry_volume_ratio`，使供给收缩评分被同日需求扩张反向污染。298 笔实际成交中，排除触发日后的缩量覆盖为 43.29%，旧值只有 31.88%；36 笔分类改变，差额与突破量比相关 0.739。该问题与宽腿 pivot 下 3% 的计划位、入场下 5% 的实际止损及约 10.33% 的末段低点风险共同表明，当前缺口是结构语义未统一。完整代码映射见 `production-leader-vcp-fidelity-audit-20260908.md`。

随后按预登记固定方法尝试在宽腿最后低点之后寻找由下一完整日线确认的最近局部高点。3,771 个独立基底只有 2,415 个可构造，覆盖 64.04%，2020/2021/2025 分别只有 58.5%/59.6%/57.1%；微型结构风险中位数 7.85%，相对同批宽腿风险 10.63% 只压缩到 73.9%，未达到一半。三个门槛全部失败。由此停止局部高点跨度、窗口及风险比例变体；下一步先制作结果盲化的图形案例包，核查宽候选中经典 VCP 与非经典结构的实际占比。

## 经典 VCP 结构盲审（2026-09-08）

按年份固定抽取 2018—2025 每年 3 个候选，共 24 个案例。抽样哈希不含未来结果；图中隐藏证券、日期与未来路径，只显示信号日及以前的标准化价量、宽枢轴和宽末段低点。标签完成后先以 SHA-256 冻结，再揭盲。盲审结果为经典 5、部分符合 8、非经典 11；19 个案例缺少可见的逐段收缩，13 个缺少右侧紧致，12 个主要表现为松散震荡，另有深 V 反转、尖峰后宽平台与枢轴反复泄漏。

这说明当前实现可继续作为有信息量的宽候选池，但不能把每个候选解释为经典 VCP。揭盲后的未来突破率仅作防误读记录：经典/部分/非经典分别为 40%/25%/45.5%，每组只有 5/8/11 个样本，既不能证明经典结构无效，也不能用于反推分类边界。当前问题是候选语义混合，而非某个阈值不够严格。

因此不从 24 个案例生成 gate、分数或分类器，也不重抽样。下一步只设计一个独立的经典结构表示：明确表达供给逐段收缩、右侧紧致、突破前缩量和枢轴完整性；先在新的结果盲化案例包上验收“是否识别了所声称的结构”，通过后才允许做收益诊断。现有宽池、领涨交易版和 `forward-v1` 保持冻结。协议、冻结标签与决策见 `production-leader-classic-vcp-blind-casebook-v1.json`、`data/research/vcp/casebooks/classic-vcp-blind-v1/label-freeze.json` 和对应 `-decision.json`。

独立经典结构表示随后只改变一个方法：保留原摆动点，把收缩改为不得跳过中间 pullback 的连续递减后缀，并以关系式表达枢轴完整、右侧位置和突破前供给下降。新一轮 32 个案例按年份各抽 2 个算法支持与 2 个不支持，算法判断、身份和未来结果均在人工标签冻结前隐藏。支持组经典/部分符合率为 68.75%，非经典率 31.25%；不支持组经典/部分符合率为 50%，差值只有 18.75 个百分点。预登记的 75%、25% 和 30 个百分点三个语义门槛全部失败。

因此这一拓扑表示直接停止，不修改摆动跨度、收缩容差、右侧阈值或成交量窗口。揭盲后支持组未来突破率低于不支持组也不能被解释成反向信号，更不能据此反转规则。价格形态内部的结构细化到此收口；下一研究层转向信号日前已知的催化与资金赞助证据，仍只做一个机制审计，不把弱代理拼成分数。协议、机器结果及停止决策见 `classic-structure-representation-v1.json`、`data/research/vcp/analysis/classic-structure-representation-v1.json` 和 `classic-structure-representation-v1-decision.json`。

## 主动资金赞助审计（2026-09-08）

现有 Quants 只读仓库包含 2015-01-05～2026-09-07 的 1,133.7 万条逐股日资金流，VCP 3,771 个独立基底的信号日与末段覆盖均为 99.15%。金额字段按 Tushare 契约为万元；为避免日线成交额单位问题，本审计只用 `net_mf_amount / 同行所有大小单买卖金额之和` 的无量纲比例。特征只取记录枢轴日至信号前一日的累计净流比例、净流入日占比和信号日净流比例，信号日收盘数据可供次日开盘执行使用。
