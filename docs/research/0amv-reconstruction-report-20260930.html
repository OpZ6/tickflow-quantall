01

研究主线只留三组候选

最终上线一个内核。候选模型用于比较，不是三个都变成新指数。

先拿指南针原版连续数值做对照，选出最接近的 0AMV 算法；再确定个股与板块能否沿用同一内核。现在不用在几十条指标里挑选，也不用继续堆叠“成本、主力、死筹”标签。

0AMV-R我们的还原结果
R = reconstruction，研究名称

1AMV · 个股个股扩展优先沿用胜出内核。若为状态模型：个股市值 × 模型活跃占比，亿元观察单股活跃规模及扩张、收缩；金额不是净流入

04

三组候选，分别算什么

Q=成交额；P=价格或指定价格指数；F=股本；M=P×F；S=平滑状态。所有窗口按交易日。

候选 A

平滑成交额

Sₜ = αQₜ + (1−α)Sₜ₋₁
Rₜ = Sₜ / 显示单位

算什么：近期交易规模的持续变化。

输入：口径一致的全市场成交额。

参数：α=0.1是SMA(10,1)；α=0.2是SMA(10,2)。同组比较，不另外创造指数。

用法：看规模相对此前水平扩张 / 收缩；不能判断资金净流入。

实现与边界

首值与预热区间明确固定。MA10不是SMA(10,1)。单位缩放不改变涨跌方向或百分比。成员和日期一致、初值一致时，平滑后求和与先求和再平滑可一致；实际缺日或新股会破坏这种条件。

候选 B

价量拟合

Tₜ = SMA(Q,N,m)
Xₜ = Tₜ × Pₜ / MA(Pₜ₋₁,L)
Rₜ = b + kXₜ

算什么：成交规模与价格相对位置的组合。

输入：全市场成交额及明确的价格基准。

参数：N、m、L及尺度k；b作为是否需要固定基数的独立对照。

用法：对照原版形态。b会改变涨幅和相对回撤，不能跨版本搬阈值。

实现与边界

必须先确认P来自哪个指数，不能把当前个股或880007默认当作正确价格基准。只在拟合段估计b、k，之后冻结验证。先还原收盘；用全天成交额乘OPEN得到的“开盘”是事后构造值。

候选 C

逐股活跃状态

qᵢ,ₜ = Qᵢ,ₜ / Mᵢ,ₜ
Aᵢ,ₜ = 激活与衰减递推
Vᵢ,ₜ = Mᵢ,ₜ × g(Aᵢ,ₜ)
Rₜ = Σᵢ Vᵢ,ₜ

算什么：近期交易激活的模型状态，折算为市值。

输入：逐股成交、原始价格、历史股本与市场样本。

参数：激活函数、衰减速度、占比变换。流通与自由流通口径分别对照。

用法：既对照原版市场曲线，又天然支持个股和板块。

两个保留实现的区别
网站型：a=min(h/1.1,1)
Aₜ=dAₜ₋₁+a(1−Aₜ₋₁)
V=M×A；代码d=2^(−1.25/10)

本地型：u=1−exp(−q)
Aₜ=u+d(1−u)Aₜ₋₁
V=M×A^1.15；d=2^(−1/10)

h是同股本口径的股数换手率；q是成交额 / 市值，两者不能静默混用。网站模型与本地模型的衰减、激活和幂参数不一样。这是两份完整候选，不能从各处挑数字拼接。

05

怎样从 0AMV 演进出 1AMV

先固定算法，再增加观察层。不要因为想扩展，就提前把原版定义改掉。

STEP 1
原版连续数据确定样本、单位、日期与价格身份
STEP 2
A/B/C统一对照拟合段选参数，独立验证段检验
STEP 3
冻结0AMV-R固定输入、公式、初值和算法版本
STEP 4
扩展1AMV同内核个股输出，按成员汇总板块

若候选C胜出：完整沿用同一内核

每只股票同样的激活函数、衰减和参数；个股输出V，板块输出ΣV，全市场输出ΣV。

板块活跃市值 = Σ Vᵢ
板块活跃占比 = ΣVᵢ / ΣMᵢ
可比净增 = Σ(Vᵢ,ₜ−Vᵢ,ₜ₋₁)
净增幅 = 可比净增 / ΣVᵢ,ₜ₋₁

增减及其分母必须来自同一可比成员集合。存量总值可另用当天全部有效成员，但不能把两种集合混在一个变化率里。

1AMV新增的是：个股视角、板块视角、活跃占比、历史分位、成员广度和集中度。

若候选A/B胜出：明确两条分支

同思路扩展：把成交额或价量公式用于个股，准确称为代理指标；板块按明确的聚合方法计算。

活跃占比演进：本地状态模型可继续研究，但需要独立验证。它不是“直接还原出来的个股原版”。

B含固定基数b时，不能给每只股票都加一次市场基数后再相加。市场整体公式与逐股求和也不一定等价。

不应为了让扩展方便，反过来强行宣布候选C还原成功。

推荐的最终架构：一个版本化计算内核 + 个股、板块、全市场三种汇总范围 + 少量派生读数。AMVSTK是内核视图，AMVCHG / AMVPCT / AMVBK是输出视图，避免四套算法并行维护。
06

留下的指标该怎么用

用途以观察为主。原版还原质量和风险提示有效性分别验证。

观察项它回答什么个股怎么用板块怎么用
活跃市值 · 亿元模型活跃规模有多大看自己的趋势；跨股金额排名偏向大盘股看板块规模；不能把重叠概念直接加成市场
活跃占比 · %相对盘子有多活跃比绝对金额更适合比较规模不同的股票市值加权，需同时看成员参与比例
占比变化 · 百分点模型状态在扩张还是收缩与股价方向分开看；当前高位仍可能降温按固定可比样本看变化，识别整体或局部升温
活跃日变化 · % / 亿元规模变化的幅度与金额包含价格、股本和占比影响；小基数会放大百分比同时提供可比成员数与市值覆盖率
占比历史分位 · 0—100相对于自己的过去是否异常默认250个有效交易日，含当天，并列值半计数在冻结口径和成员处理规则后，计算板块自己的历史分位
参与广度 / 集中度多数成员参与，还是少数权重推动用于理解所属板块环境占比上升家数比例、前几只成员的增量集中程度；正负增量分开统计

价格 × 活跃，组合描述

  • 上涨 + 活跃扩张：上涨伴随参与增加。
  • 上涨 + 活跃收缩：参与支持减弱，也可能是惜售。
  • 下跌 + 活跃扩张：换手、分歧或恐慌加剧。
  • 下跌 + 活跃收缩：交易冷却，需看趋势是否破坏。

颜色与提示

金额、价格和指标自身增减遵循A股红增绿减；“风险状态”单独用文字和色标，避免把红柱直接读成风险或看涨。

分位高不是自动风险，分位低不是自动机会。不要搬用网上固定涨幅、分位阈值；后续以验证结果定义风险条件。

进入QuantX时适合补充“量能与承接”中的活跃证据。先证明相比现有成交额、换手率、价格趋势的增量作用，再决定是否计入整体状态。

07

怎么真正实现你的目的

按以下顺序推进，每一步都有一个可检查的产物。

1

建立可信的原版对照表

优先获取指南针0AMV连续日线导出；记录交易日期、收盘、单位、来源与导出时间。建议覆盖不同涨跌和成交环境，并保留后续独立时段。同步核验指南针0号市值序列及对应市场范围；目前资料只提供线索。

产物：原版数据包 + 口径说明 + 缺失列表。截图只做形态辅助，不能当完整数值真值。

2

准备共同输入，先解决数据差异

A/B需要同市场成交额及明确价格基准；C需要逐股原始日线、成交额 / 股数、当日可得股本、上市退市范围和成员日期。一般流通、自由流通分别标注；缺少历史股本时只能作为当前股本回看的代理实验。

产物：可重复读取的标准输入。不得用当前股票池冒充历史全市场，不把估算成交额混成真实成交额。

3

三组候选同窗比较，按时间隔离拟合

先固定数据口径，只在前段拟合参数；用后段比较每日水平误差、日变化误差、方向一致率、拐点时差及不同阶段稳定性。相关系数仅为辅助。缩放参数在拟合段固定，不使用验证期或最后一天原版值重新校准。

产物：模型比较表 + 原版 / 候选叠图 + 独立验证结果。若三组均明显不符，结论就是仍未还原，需要继续追查定义，而不是选一个“看起来最像”的上线。

4

冻结0AMV-R，再输出1AMV与板块

固定算法、参数、初值、预热、数据版本和缺失规则。用同口径汇总验证“个股 → 板块 → 市场”。行业与概念分别看；板块变化使用同日可比成员，历史分位不使用未来成员或未来观测。

产物：0AMV-R对照结果 + 个股和板块1AMV样例 + 数据覆盖说明。随后再验证它是否比简单量能指标更能提示风险。

实现契约：只需要一个计算层

标准行情 / 历史股本 / 原版对照 / 日期与成员事实
  → AMV纯计算函数（明确算法版本、参数、初值、有效性）
  → 个股序列 → 板块与市场聚合 → 变化与历史分位
  → 对照报告 / 图表 / QuantX观察证据

个股最小输出：date, symbol, market_value, active_state,
              active_share, amv_value, amv_change, quality
聚合额外输出：member_count, comparable_count,
              market_value_coverage, membership_basis

这是拟议契约，不是项目已有API。数据按现有Provider / Market Facts分类接入，页面只消费计算结果。复现、汇总、分位和提示全部可用脚本实现，不需要LLM参与。

最后的取舍：保留A作为简单基准，B作为价量拟合候选，C作为同内核扩展的结构候选。优先补原版数值和股本口径；当前本地1AMV保留为C组试验实现，不提前把它定为指南针原版。
