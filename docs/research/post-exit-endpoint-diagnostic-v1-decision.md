# 信号退出后的 40 日终点：没有普遍恢复证据

依据[预登记诊断协议](post-exit-endpoint-diagnostic-v1.json)，一对一连接原始成交与已冻结路径标签；事件键无重复、两边集合完全一致，标签未越过 2022 年末。只取信号退出且退出日在 40 日标签末日之前的事件。

| 指标 | 宽泛 VCP | 杯柄 |
| --- | ---: | ---: |
| 纳入事件 | 4,298 | 72,859 |
| 因退出原因或日期排除 | 98 | 25,630 |
| 终点价相对退出成交价平均变化 | +0.846% | +0.519% |
| 中位数变化 | -1.048% | -1.449% |
| 终点价高于退出成交价占比 | 46.53% | 45.09% |
| 终点下跌至少 10% 占比 | 23.71% | 22.28% |
| 终点上涨至少 10% 占比 | 22.57% | 20.58% |
| 信号日等权平均变化 | +1.082% | +1.428% |

平均值略正，但多数事件的终点价格更低；两者终点下跌至少 10% 的比例都高于上涨至少 10%。宽泛 VCP 逐事件年度均值仅 2019、2020、2021 为正，杯柄为 2019–2022 四年。这不支持把“原退出过早、延长持有即可解决”作为普遍解释，也不证明任何替代退出无效。

本诊断只比较终点价格与记录成交价，不是扣费收益或市场 Alpha。原持有时间、剩余观察期不同，且成交价可能包含滑点；不得把这些均值当作新增可实现收益。终点跌幅是路径期间可能承受损失的一个观测，不能代替完整路径最低价、峰谷回撤或恢复时点。

决策：不登记统一延迟退出、取消 MA 退出或放宽止损实验；两者继续保持未通过训练门槛。下一动作是按冻结数据引用读取退出日至既有标签末日的路径，区分先回撤后恢复与持续下跌，并核对退出时可见的结构失效证据。形成可证伪机制前不修改策略。

计算复核：对协议中事件键连接后的每笔交易计算 `(1 + horizon_close_return) * entry_price / exit_price - 1`，按 `entry_year` 聚合；信号日等权先按 `entry_signal_date` 取均值，再对信号日取均值。完整结果见 [VCP](vcp/post-exit-endpoint-diagnostic-v1-analysis.json) 和[杯柄](cup-handle/post-exit-endpoint-diagnostic-v1-analysis.json)。
