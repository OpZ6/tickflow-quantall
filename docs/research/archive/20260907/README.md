# 历史研究归档（2026-09-07）

本目录代表“归档语义”：历史路线、实验结果和协议不再产生新任务。由于运行脚本和旧报告使用相对路径，VCP 的 JSON 协议暂时保留在 `docs/research/vcp/` 原路径；它们均属于不可变历史实验，不得当作当前默认策略或新的开发计划。

已归档的主要计划/结果：

- `../quant-development-roadmap-20260906.md`：32 个策略的调查和初始路线；由 `../quant-development-plan.md` 取代。
- `../vcp/first-run-20260905.md`、`training-baseline-20260905.md`、`iteration-results-20260905.md`：早期运行和结果汇总。
- `../vcp/candidate-v2-*.md/json`：候选 V2 的冻结、留出和评价证据。
- `../vcp/iteration3-*` 至 `../vcp/iteration9-*`：历史参数实验协议及其结果。
- `../vcp/five-year-*`：五年数据集和候选实验协议。
- `../vcp/*audit*`、`*parity*`、`*runbook*`：数据审计、复现和运行约束。

新的研究只允许从 [唯一主计划](../../quant-development-plan.md) 创建新的 `experiment_id` 和版本；旧实验只能复现，不能回写或重命名为新证据。
