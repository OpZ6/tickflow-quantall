# 退出后恢复与下行路径

依据 [协议](post-exit-path-diagnostic-v1.json)，使用原账本信号退出后、既有 40 日标签末日前的完整日 K；排除退出当日，避免无法判断日内高低点发生在成交前还是成交后。源文件大小和 mtime 在读取前后均与原归档引用一致，终点收盘收益逐笔与旧标签一致。源引用不是不可变内容快照。

| 指标 | 宽泛 VCP | 杯柄 |
| --- | ---: | ---: |
| 事件数 | 4,298 | 72,859 |
| 曾有后续收盘高于退出价 | 84.85% | 87.32% |
| 最低价相对退出价变化中位数 | -9.25% | -9.03% |
| 首次恢复前已跌至少 10%，或跌后从未恢复 | 19.26% | 16.10% |
| 首次跌 10% 与首次恢复落在同一根日 K | 0.047% | 0.018% |

与终点诊断结合：短暂恢复常见，但多数事件的终点价仍低于退出价。恢复事件并不稀缺，区别在于持续性和期间风险。中位最低价亏损约 9%，不能把捕捉恢复当作无成本持有；本指标是相对退出价的最低价变化，不是峰谷最大回撤。

决策：不从“曾恢复”推导取消退出或延长持有的实验。也不否决所有结构退出。下一动作限定为核对退出信号日的原形态支撑/枢轴是否已经失效，比较均线退出与形态失效的语义关系；只使用退出时可得字段，先完成定义和覆盖检查，再决定是否存在值得预登记的单一结构假设。不得按未来恢复标签筛出新入场池。

复现：仓库根目录运行 `backend/.venv/Scripts/python.exe scripts/analyze_post_exit_paths.py`。完整聚合见 [VCP](vcp/post-exit-path-diagnostic-v1-analysis.json) 与[杯柄](cup-handle/post-exit-path-diagnostic-v1-analysis.json)。同根 K 线触及的先后顺序保持未知，不并入“先跌后恢复”。
