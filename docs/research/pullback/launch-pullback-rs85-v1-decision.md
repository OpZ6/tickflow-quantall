# 回踩 ∩ RS≥85：均值仍负，扔掉

协议 [launch-pullback-rs85-v1.json](launch-pullback-rs85-v1.json)。数字 [analysis](launch-pullback-rs85-v1-analysis.json)。全量 `launch_pullback_support` 训练 32,086 笔。

## 四句

1. **改了什么：** 只留信号日 RS 分位 ≥85（与 VCP 同一 `trend_context` 口径，不开趋势模板）。
2. **相对哪条基线：** 32,086 笔全市场缩量回踩，平均净 −0.98%。
3. **胜率 / 盈亏比 / 平均净收益：** 基线 25.0% / 2.25 / −0.98%；RS≥85 的 6,036 笔 24.0% / 2.56 / **−0.82%**。仍为负。2023–2026 该账本几乎没有样本（22/7 笔），不作依据。
4. **扔掉。** 协议要求均值转正才留。领涨过滤减轻亏损但没做成正期望。回踩基线仍是 −0.98%。下一处：同一账本加 VCP 同款双阶段市场总闸。
