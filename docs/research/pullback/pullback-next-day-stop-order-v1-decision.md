# 回踩次日突破条件单：淘汰

2026-09-13。协议见 [两条线预登记](../multi-strategy-next-entry-experiments-20260913.md)，结果见 [analysis](pullback-next-day-stop-order-v1-analysis.json)。杯柄仍在独立运行，本结论只针对回踩。

完整原股票池重建产生 1,438 个候选，1,431 个次日订单，原规则完成成交 1,421 笔。与撮合修正后的原基线没有缺项、多项或收益差异；额外核对入场日/价、退出日/价、持有天数和卖出阻塞天数均一致。

唯一变化是次日越过信号日高点才买入：开盘已越过按开盘，否则按触发位模拟，保持原成本、支撑退出、6% 止损、20 日到期。766 个订单触发，其中 101 个开盘越过、665 个日内触发；另有 665 个未触发并撤销。触发订单中完成 760 笔，3 笔没有后续行情可模拟退出，3 笔为期末未按策略退出，单列且未计入完成交易均值。

虽然保留了 53.48% 的完成交易并略提高胜率，平均亏损从 5.39% 增至 6.01%，平均盈利约 14.65% 基本不变。该买点没有改善盈亏结构，净收益与日等权均未过门槛。**淘汰此表示及触发位缓冲、订单有效天数邻域，不接产品，不反向选未触发组。** 回踩基线保持原规则。

日线模型只近似触发与成交，不证明分钟排队或精确滑点。交易频率已降低且收益转负，止于训练初筛，不追加环境筛选、参数变体或验证期搜索。下一步等待杯柄本轮结论后统一汇总覆盖，再按多策略队列选择新机制。
