# 持续固定入场启动支撑退出：淘汰

协议见 [protocol](launch-fixed-support-exit-v1.json)，结果见 [analysis](launch-fixed-support-exit-v1-analysis.json)。本轮将动态支撑退出替换为入场信号日启动中位支撑的持续保护，2% 缓冲、6% 硬止损、20 日最大持有、历史费用及 T+1 均未改动。

原 1,421 笔逐笔独立重放，两臂全部在训练边界内完成。原退出日期和净收益逐笔通过校验。固定支撑改变 155 笔：68 笔早退，87 笔晚退，没有将试验限制为只提前卖出。

| 指标 | 原退出 | 固定入场支撑 |
| --- | ---: | ---: |
| 胜率 | 27.87% | 25.97% |
| 平均盈利 / 平均亏损绝对值 | 2.61 | 2.87 |
| 平均净收益 | +0.0351% | +0.0221% |
| 信号日等权实际净收益 | −0.0132% | +0.0523% |
| 正收益年份 | 3/7 | 3/7 |

盈利回吐组 388 笔均净 −6.0077%→−5.6485%；赢家组 393 笔 +14.4103%→+13.9283%。修复支撑到期后的保护空缺确实减轻部分亏损，同时失去动态支撑抬升退出的收益。总体逐笔平均净收益下降，未过预登记门槛，因此淘汰固定入场支撑替换及其缓冲邻域。等权改善不替代未通过的逐笔收益门槛，也不声称固定窗 Alpha 或验证有效。

回踩薄本仍为原 1,421 笔 +0.0351%，VCP 主本冻结。逐笔两臂成交账本在 `data/research/pullback/launch-fixed-support-exit-v1/ledger.json`，复现为 `backend/.venv/Scripts/python.exe scripts/research_pullback_fixed_support.py`。

下一处先解剖本轮 87 笔晚退：区分原动态支撑上移后的真实破位，以及新启动替换原机会后造成的提前卖出，并核对两类交易后续是否恢复或继续走弱。只有能指出性质不同的市场行为，才开下一种退出对照；不自动把固定和动态支撑取最大值，也不扫描支撑缓冲、窗口或持有天数。
