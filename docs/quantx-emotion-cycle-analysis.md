# QuantX 情绪判断 · 逐项说明书（含连板网对照）

> 用途：把「复盘页里跟情绪有关的东西」一件一件讲清楚：它算什么、画在哪、怎么读、哪里有坑。
> 然后同样拆一遍连板网 qingxu.html，最后给结论对比和改造顺序。
> 本文所有 QuantX 侧统计数字由 `backend/scripts/analyze_emotion_cycle.py` 现算，可复现；口径标注为 2026-11-28。

---

## 0. 五分钟速读

1. **我们算得出"今天多热"，算不出"这轮第几天"。** 所有指标都是当日横截面（涨停多少、封板率多高、谁在涨），没有一个回答"冰点之后第 2 天历史上会怎样"。
2. **复盘页实际只有三层东西在起作用**：三个分数（热度/短线/趋势）→ 几个判定（退潮/崩塌/亏钱/参与度）→ 一张仓位建议。而"判定"这一层几乎不直接展示，只体现在「决意区」的一句话依据和仓位分支里。
3. **6 阶段字段 `phase` 已经死了**：2026 年 89.9% 的交易日都被兜底成"修复"，最近 40 个交易日 100% 是"修复"。它只挂在 `/regime` 页，复盘页根本没用它。
4. **连板网的强项是"统计"，不是"指标"。** 它的指标（涨停、封板、晋级、高度）跟我们高度重合，差别在于它把「阶段 × 连续第 k 天」当成状态，统计历史频率（二冰、三冰、高潮第 4 天）。
5. **今天修了 3 个会直接误导判断的坑**：炸板率误报（绝对家数 → 比率）、亏钱效应风险误标（收敛被当成风险）、退潮信号显示英文键名。详见 §2.3 / §2.4 / §2.5。

## 1. 复盘页的结构（先搞清楚东西在哪）

路由上 `/quantx/:date` 会重定向到 `/quantx?date=YYYYMMDD`，也就是**统一的「QuantX 市场驾驶舱」**。
旧版单日复盘页（`QuantXReview`）已经没有路由入口，它的图表组件被驾驶舱复用。

驾驶舱从上到下：

| 位置 | 内容 | 与情绪的关系 |
|---|---|---|
| ① 顶部指标条 | 五大指数涨幅、涨跌家数、成交额、晋级率、最高板、市场热度 | 直接展示情绪结果 |
| ② 今日市场结论 | 市场脉搏（K线+CCI5）、题材主线、**风险画像** | 风险画像 = 情绪风险四维 |
| ③ 决断区 | 仓位/场景/次日动作 + 一行"依据" | 情绪判定最终影响的就是这里 |
| ④ 市场状态与历史环境 | **情绪周期与交易日历**、**情绪相图**、**状态转移矩阵**、**异常交易日历** | 情绪的本体区块 |
| ⑤ 行业轮动与资金生态 | 行业扩散、行业相关性、RPS 时钟、资金流 | 间接 |
| ⑥ 题材生命周期 | 信号矩阵、题材河流、主线瀑布 | 间接 |
| ⑦ 情绪连板 | **连板晋级阶梯**、**题材—连板梯队** | 情绪的微观结构 |
| ⑧ 流动性与拥挤 | 收益分布、涨跌背离、**拥挤密度**、洛伦兹 | 情绪的"拥挤"维度 |
| ⑨ 完整数据 / 质量血缘 | 原始表、字段契约、缓存状态 | 排查用 |

下面按"计算层 → 展示层"逐个讲。

## 2. 计算层：我们到底算了什么

### 2.1 三个分数（驱动一切结论）

| 分数 | 公式 | 区间 |
|---|---|---|
| **短线情绪** | 涨停数 0.30 + 封板率 0.25 + 跌停数 0.15 + 上涨占比 0.15 + 溢价率 0.10 + 最高板 0.05，各子项先按锚点插值到 0-100，加权后再绕 50 拉伸 ×1.7 | 0-100 |
| **趋势情绪** | 上涨占比 0.40 + 上证涨幅 0.30 + 量比（对 5 日均量）0.15 + 主力净流入 0.15，拉伸 ×1.3 | 0-100 |
| **市场热度** | 短线 ×0.5 + 趋势 ×0.5（不再拉伸） | 0-100 |

子项锚点举例（都是"输入 → 得分"的经验分位，不是线性映射）：

- 涨停数：0→5、48→15、66→35、90→50、112→65、142→85、160→95
- 封板率：40→5、58→15、68→35、75→50、81→65、84→85、90→95
- 跌停数：0→90、11.5→60、39→35、60→15（越高分越低）
- 最高板：1→10、3→30、4→50、5→70、6→85、8→95

**怎么读**：50 是"中性"，但因为是分位锚点 + 拉伸，60 以上就已经是偏强的一天。
2026-11-27 三件套全部 100（涨停 417、封板率 90.8%、涨跌 5381/182）。

**坑**：这三套锚点是 2022-2024 的分位，随市场结构变化会漂移；拉伸系数（1.7/1.3）是拍出来的，
目的是让分数不要全挤在 40-60，副作用是**极端日容易直接打满 100**，失去区分度。

### 2.2 五档 zone（把分数翻译成人话）

`<30 冰点 / 30-40 偏冷 / 40-60 正常 / 60-70 偏热 / ≥70 过热`

**坑**：这是**静态阈值**。它只说"今天多热"，不区分"从冰点刚爬起来的热"和"连续第 4 天的热"——
而这恰恰是情绪周期里最要紧的差别（见 §4.2）。

### 2.3 亏钱效应 severity（本次修复）

**算什么**：三个比率，取"或"关系分四档。

| 维度 | 公式 | 历史分位（2015-2026，2892 天） |
|---|---|---|
| 炸板率 | 炸板 /（炸板 + 涨停） | p50 30% / p90 44% |
| 跌停比 | 跌停 /（跌停 + 涨停） | p50 10% / p90 43% |
| 下跌占比 | 下跌家数 / 涨跌家数合计 | p50 52% / p90 83% |

| 档位 | 条件 |
|---|---|
| 蔓延 | 炸板率 ≥55% 或 跌停比 ≥40% 或 下跌占比 ≥85% |
| 扩散 | 炸板率 ≥45% 或 跌停比 ≥20% 或 下跌占比 ≥65% |
| 稳定 | 下跌占比 ≥55% 或 炸板率 ≥30% |
| 收敛 | 其余 |

全历史分布：收敛 32% / 稳定 24% / 扩散 29% / 蔓延 15%。

**改前**：`下跌 >3000 或 跌停 >20 或 炸板 >40 = 蔓延`。这是纯绝对家数——全历史有 **32.7%** 的交易日
被判"蔓延"，而且在 400+ 涨停的日子里，31 只炸板（炸板率 7%）就能踩线。
2026-11-27（涨停 417、封板率 90.8%、跌停 0）就是这么被判成"蔓延"的。

**改后实测**：2026-11-27 → 收敛（炸板率 9.2%、跌停比 0%、下跌占比 3.3%）；
2026-11-25（跌停 43、下跌 89%）→ 蔓延；2026-11-26（跌停 5、下跌 67%）→ 扩散。

### 2.4 崩塌前兆（3 信号，本次修复）

| 信号 | 判据（改后） | 改前 |
|---|---|---|
| 领跌含近期强势股 | 炸板率 ≥40% | 炸板 >30 只 |
| 龙头断板未修复 | 最高板 < 近 5 日前高 且 ≤3 板（前高股停牌时豁免） | 同左 |
| 尾部放量跌停 | 跌停比 ≥20% 且 下跌占比 ≥65% | 下跌 >2000 且 跌停 >10 |

三个任一触发 → `crash_triggered = true`，进而影响决断区的"走弱"分支（`热度<40 或 退潮确认 或 崩塌触发`）。
改前 2026-11-27 `crash_triggered=True`，改后 3 个信号全部"待观察"，证据行也带上了分母：
`炸板42只 / 涨停417只（炸板率9%）`。

### 2.5 退潮风险（4 信号 + verdict）

| 信号 | 判据 |
|---|---|
| 接力赚钱效应转弱 | 晋级率 <12% 或 溢价率 <0%；或 晋级率比 5 日均值低 ≥5pp 且 溢价率低 ≥1pp |
| 封板质量下滑 | 封板率 <65%；或 比 5 日均值低 ≥10pp |
| 连板高度压缩 | 最高板 ≤3；或 最高板 ≤ 前高−2 且 2 板家数 <3（前高股停牌时豁免） |
| 亏钱效应扩散 | 跌停 >20 或 下跌 >3000；或 跌停 ≥10 且 ≥ 5 日跌停中位数×2 |

0 个 → 未见退潮；1 个 → 局部转弱；2 个 → 退潮预警；3-4 个 → 退潮确认。

**本次修复**：这 4 个信号在事实表里存的是键名（`relay_payoff_weak` 等），以前直接吐给前端，
"退潮信号/风险清单"里显示的是英文下划线串。现在展示层翻译成中文（`key` 字段保留原名，方便排查）。

**坑（还没改）**：`亏钱效应扩散` 这条仍然是绝对家数（跌停>20、下跌>3000）——和炸板率是同一类问题，
只是它属于"四个信号之一"，改动会牵动退潮 verdict 和仓位建议，所以这轮没动，见 §6 P0-2。

### 2.6 参与度（4 条件）

最高板 ≥4、2 板以上 ≥3 家、首板 ≥50 家、量比 ≥0.90，另有"主线宽度 ≥8 家或占比 ≥12%"一条；
≥3 条可判定即给"参与/不参与"。2026-11-27：参与。

### 2.7 Regime 五档（状态转移矩阵用的就是它）

四个子分加权：赚钱 0.35（涨家数/均涨幅/中位涨幅/强弱差）+ 投机 0.25（涨停/封板/高度）
+ 抗跌 0.20（大跌股占比）+ 趋势 0.20（指数涨幅/MA20 上方占比），再按 70/55/45/30 切成
强势/偏强/震荡/偏弱/弱势。

**关键区别**：这是"强弱刻度"，不是"周期位置"。同一天"强势"可能在高潮期，也可能在主升第 1 天。

### 2.8 6 阶段 phase（已死，勿用）

原设计基于连板梯队：高潮=二板≥50 或 首板≥220；主升=高度≥7 且 二板≥15 且 晋级率≥0.23 …；
冰点=高度≤4 且 二板≤6 且 首板≤24；都不满足 → 修复。驱动量先 EMA(α=1/3) 平滑，切换需连续 2 日确认。

退化数据：repair 占比 2015 年 56.6% → 2022 年 80.6% → **2026 年 89.9%**，最近 40 个交易日 100%。
原因：①阈值是 2020-2024 的固定分位，市场结构变了；②EMA 把单日脉冲削成 1/3，400 家涨停打不中"高潮"；
③`state` 为弱势/偏弱时，正面阶段被强制改成修复（2026 年弱档占 45.4%）；④修复是兜底桶，不是"冰点后反抽"的语义。

## 3. 展示层：每张图/表怎么读

### 3.1 顶部指标条

五个指数涨幅、涨跌家数、成交额、晋级率（昨日涨停今日再封板比例）、最高板、市场热度。
**怎么读**：先看热度落在哪个 zone，再看晋级率和最高板是否同向——热度高但晋级率低 = 赚钱效应没扩散。

### 3.2 风险画像（四维）

四个维度各自打分并给 tone（红/黄/绿）+ 一句 headline + 相反证据：

| 维度 | 主要看什么 |
|---|---|
| 广度与尾部 | 涨跌家数、下跌占比、跌停数、平均涨跌幅、跌幅超 7% 占比 |
| 接力与封板 | 涨停数、封板率、炸板数、连板家数分布、最高板 |
| 量能与承接 | 当日成交额 vs 20 日均、前 5% 成交占比（拥挤度） |
| 指数与趋势 | 指数在 MA10/MA20 上方的个数、龙头/题材/资金/赚钱效应四个变化率 |

**怎么读**：它是"当下有没有风险"的横截面体检，不是周期位置判断。
**坑**：全部是当日横截面，与 `crash_triggered`、`loss_severity` 无关（两套东西并行计算）。

### 3.3 决断区

把热度、参与度、退潮、崩塌组合成三种场景（走强/震荡/走弱）→ 给仓位建议与次日动作，
底下那行"依据"就是 `daily_summary`：`市场热度100(过热)；短线情绪100(过热)；趋势情绪100(过热)；晋级率44.6%；溢价率5.8%；亏钱效应收敛；…`

**怎么读**：这是全页唯一给结论的地方。规则是：
`热度>70 + 参与 + 退潮未触发 → 走强（高仓位）`；`热度40-70 → 震荡`；`热度<40 或 退潮确认 或 崩塌触发 → 走弱`。

### 3.4 情绪周期与交易日历

左：5 个 KPI（市场热度/短线情绪/趋势情绪/最高板/晋级率）+ 近 20 日三条分数曲线。
右：交易日历格子，可切"总情绪/波段情绪/短线情绪"三种口径，颜色与数值对应当前口径。

**怎么读**：左图看三条线是否同向（趋势情绪抬升 + 短线情绪回落 = 主线在退潮）；
右图看连续的冷暖块，找"连续几天同色"的区段。

**坑**：日历只有 **60 个交易日**、明细表只有 **134 天**，做不了跨年统计；格子上没有"阶段"概念，只有分数深浅。

### 3.5 情绪相图（sentiment_phase）

横轴趋势情绪、纵轴短线情绪，每个点一天（近 75 日），气泡大小 = 涨停家数，最后一天红色。
四角标注：弱势修复↖ / 强势加速↗ / 弱势恶化↙ / 强势减速↘。

**怎么读**：看最近几个点往哪个角走。右上角 = 趋势与短线同时强（高潮区）。
**坑**：只有位置没有时间维度，看不出"连续第几天"；点数少时轨迹会重叠。

### 3.6 市场状态转移矩阵（state_transition）

5×5（强势/偏强/震荡/偏弱/弱势），行=今日、列=次日，格子=历史条件概率（%）。
可切"近 500 日 / 全历史"；蓝框 = 今日所在行（明日分布），橙框 = 昨日→今日刚实现的转移。

**怎么读**：先看今天这一行的分布，再看对角线（自我延续概率）。
**坑**：用的是 §2.7 的 5 档 regime，**不是**情绪阶段；"强势→强势 40%"和"高潮→高潮 33%"是两回事，
不能当成情绪周期用。

### 3.7 异常交易日历（anomaly_calendar）

对 `指数涨幅 / 上涨家数 / 涨停数 / 成交额` 四个量在**全历史**上做 z-score，取绝对值最大者作为"异常度"，
展示当年每个交易日的异常度与指数涨跌。

**怎么读**：找那些"平常日子里不平常"的点，回看当天发生了什么。
**坑**：z-score 用全历史均值方差，早年波动大时会把极端日压小。

### 3.8 连板晋级阶梯（promotion_funnel）

按板位（首板/2板/3板/…）统计**晋级到下一板的效率**，同时给当天、5 日、20 日与全样本基线。

**怎么读**：看当前板位的晋级率相对基线是高还是低；高位板晋级率暴跌 = 接力断了。
**坑**：只有全样本基线，**没有按情绪阶段分组**——而连板网的数据显示"冰点期打首板的次日晋级率
反而最高（18.5% vs 修复期 15.3%）"，这种结论现在拿不到。

### 3.9 题材—连板梯队（theme_ladder_sunburst）

旭日图：内圈题材（按涨停家数），外圈该题材下每只涨停股及板高；旁边配全量梯队表。

**怎么读**：看题材是否集中（少数题材吸走大部分涨停）以及高位板是否集中在同一题材。
**坑**：题材归类依赖当前概念成分，回看历史时会"时代错位"（页面上已有 caveat）。

### 3.10 拥挤密度（turnover_return_density）

换手率（10 档）× 收益率（9 档）的二维股票数直方图，颜色按股票数**分 6 档**（0 / 1-9 / 10-29 /
30-99 / 100-299 / 300+），红色只标 300+ 的热点格，橙带是 0% 涨跌分界。

**怎么读**：看高换手区是否伴随高收益（追高有回报）还是高换手+负收益（出货）。
**坑**：换手档位上限 100%，超过 100% 的（新股/次新）不进图；分档阈值是固定值，极端行情下最热档可能很空。

## 4. 连板网 qingxu.html：每个模块在算什么

### 4.1 顶部状态卡

一行给三件事：**当前阶段**（修复/升温/高潮/降温/退潮/冰点）、**连续第 k 天**（如"连续第 1 天"）、
**短线温度**（0-100）。并明确写"阶段可重复或跳转，不必依次轮转"。

### 4.2 同景摘要（顶栏黄条）

把"当前阶段 + 连续第 k 天 + 牛熊环境"作为检索条件，直接给：历史同景出现次数、次日上证均值、
上涨概率、以及"同环境 N 次"的子样本；后面列出最近 12 个同景日期及其次日涨跌，可点进当日复盘。
例：高潮期第 1 天、年线下方 → 96 次，次日均值 +0.12%，上涨概率 54%。

**这是它最值钱的一块**：把"今天像历史上的哪天"变成了可点击的样本列表。

### 4.3 情绪周期历史带（近 120 日）

柱状图，柱高 = 温度、柱色 = 阶段，虚线 50 度；悬停看当日读数，点柱进当日复盘。
下方还有一排阶段标签，能一眼看出"连续几个冰点"。

### 4.4 历史同景矩阵

维度：阶段 × 连续第 k 天（1/2/3/≥4），列：样本数、次日上证均值、次日上涨率、后 3 日累计、
次日温度 Δ、次日去向 top2。可按"全部/年线上/年线下"切换，样本 <3 不显示。

它的关键读数（样本期 2022-08-26 起 1018 天）：

|---|---|---|---|---|---|---|
| 冰点第1天 | 124 | +0.03% | 54% | +0.15% | +26.4° | 修复55%/冰点25% |
| 二冰 | 32 | +0.26% | 46% | +0.32% | +31.5° | 修复50%/高潮21% |
| 三冰 | 6 | +0.04% | 50% | −0.76% | +31.8° | 冰点50%/修复33% |

| 高潮≥4天 | 10 | −0.66% | 40% | −0.51% | −35.5° | 高潮50%/冰点30% |

### 4.5 阶段转移矩阵

6×6，行=今日、列=次日，纯频率。读法与我们那张 5×5 相同，但状态是**阶段**：
冰点→修复 53%、退潮→修复 34%、升温→降温 29%/退潮 28%。

### 4.6 阶段持续天数

每阶段：出现段数、平均持续、最长持续、时间占比。修复 195 段/1.2 天/3 天/22%；冰点 124 段/1.4/6/17%；
高潮 96 段/1.6/8/15%。用来回答"这个阶段还剩几天"。

### 4.7 连板晋级率（含分阶段）

先给整体路径：1进2 16.7%、2进3 33.7%、3进4 46.1%、4板以上 50.4%。
再按**信号日所处情绪阶段**分组，得到反直觉的结论：冰点期 1进2 = 18.5%（最高），修复期 15.3%（最低）。

### 4.8 口径说明块

样本期、样本数、牛熊划分方式（上证 vs 250 日年线，上方 572 天/下方 446 天）、
"历史频率不代表未来"、"不构成投资建议"。

## 5. 结论对比

### 5.1 能力对照

| 能力 | QuantX 现在 | 连板网 | 差距性质 |
|---|---|---|---|
| 当日温度 | 有（三个分数 + 五档 zone） | 有（单一温度） | 口径冗余，需统一 |
| 阶段 | 有字段但已死（89.9% 修复） | 六阶段稳定输出 | 需重做 |
| 连续第 k 天 | 无 | 核心 | **结构性缺失** |
| 同景统计 | 无 | 有（含牛熊、样本数、可点击样本） | **结构性缺失** |
| 转移矩阵 | 有，但用 5 档强弱 | 有，用 6 阶段 | 口径错位 |
| 阶段持续天数 | 无 | 有 | 易补 |
| 分阶段晋级率 | 只有全样本基线 | 有 | 易补（数据已在） |
| 判定透明度 | 退潮/崩塌/亏钱都算了，但只在"依据"一行露面 | 每个统计都标样本数 | 展示不足 |
| 样本数可见性 | 矩阵 n 只在悬停、晋级率无 n | 单元格直接标 n | 易补 |
| 绝对数 vs 比率 | 本次修了炸板率/跌停比，退潮的"亏钱"仍用绝对数 | 以高度/宽度/晋级率为主 | 还需一轮 |
| 历史深度 | 情绪明细 134 天 / regime 2892 天 | 1018 天（晋级 1665 天） | 够用，但要选对表 |

### 5.2 三条实质差异

1. **它把"第几天"当状态，我们没有。** 同样是"冰点"，第 1 天、二冰、三冰的次日温度反弹都很大
   （+26~32°），但次日去向完全不同（第1天 55% 修复 / 三冰 50% 继续冰点）。没有 k-day，这类差别无法表达。
2. **它用比率，我们大量用绝对家数。** 绝对家数随市场规模漂移，同一个阈值在 2016 年和 2026 年含义不同；
   我们这次只修了炸板率/跌停比，退潮里还有 2 条没动。
3. **它公开样本，我们把样本藏起来了。** 它每个格子都写 n=，样本 <3 直接不显示；
   我们的转移矩阵有 n 但只在悬停提示里，晋级率干脆没给 n，读者判断不了"这个 40% 是 3 个样本还是 300 个"。

### 5.3 用我们自己的历史回算（2892 天，2015 起）

用三件套锚点重算温度，阶段改用**滚动 250 日分位 + 3 日温度方向**（绕开固定阈值漂移），得到：

| 同景 | 样本 | 次日上证 | 上涨率 | 后3日 | Δ温度 | 连板网对照 |
|---|---|---|---|---|---|---|
| 冰点第1天 | 290 | +0.04% | 58% | +0.15% | +23.7° | +26.4° |
| 二冰 | 43 | +0.23% | 53% | +0.54% | +21.8° | +31.5° |
| 三冰 | 8 | +0.01% | 62% | −0.12% | +18.8° | +31.8° |
| 高潮第1天 | 391 | +0.04% | 52% | −0.01% | −17.2° | −33.1° |
| 高潮≥4天 | 18 | −0.28% | 56% | −0.69% | −18.6° | −0.51° |

**方向全部吻合**：冰点后温度平均反弹 20°+；二冰的次日收益好于冰点第 1 天；高潮持续到第 4 天后 3 日转负。
阶段分布也接近（高潮平均 1.5 天/最长 7 天 vs 它的 1.6/8）。
偏差在"升温偏多（22% vs 8%）、修复偏少（11% vs 22%）"——我们把"低位反抽第一天"也标成了升温，
这是归类标定问题，不是结构问题。

## 附录 A · 术语

| 术语 | 含义 |
|---|---|
| 炸板率 | 炸板数 /（炸板 + 涨停）。衡量打板当天的失败比例 |
| 跌停比 | 跌停数 /（跌停 + 涨停）。衡量亏钱效应的极端程度 |
| 晋级率 | 昨日涨停（或昨日 N 板）今日继续封板的比例 |
| 溢价率 | 昨日涨停股今日的平均涨幅（打板隔日收益） |
| 同景 | "同一阶段 + 连续第 k 天"的历史样本集合 |
| 冰点/二冰/三冰 | 处于冰点阶段的第 1 / 2 / 3 个连续交易日 |
| 温度 | 单一的 0-100 情绪读数；我们对应"短线情绪"（可换成混合口径） |
