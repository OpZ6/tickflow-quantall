# QuantX 单文件 HTML 导出

状态：当前可用能力。用于把一个已发布交易日的 QuantX 看板固化为可离线查看、可直接上传静态站点的单个 HTML 文件。

## 页面导出

1. 打开目标页面，例如 `http://127.0.0.1:3011/quantx/20260828`。
2. 等待图表加载完成，并选择希望分享的行业层级、日期窗口等页面状态。
3. 点击顶部的“导出 HTML”。
4. 浏览器下载 `quantx-20260828.html`。

导出文件包含当前看板 DOM、全部页面样式和已渲染图表。Canvas 图表会转为内嵌 PNG，已有图片和 CSS 资源会转为数据 URI；导出文件不含脚本，也不依赖 TickFlow API、前后端进程或本机地址。

静态文件保留的是导出瞬间的显示状态，不提供日期切换、Tab 切换、下钻、刷新或重新计算。需要分享另一种筛选状态时，应先在在线页面完成切换，再重新导出。

## 命令行导出与离线验收

前后端运行时，可从仓库根目录执行：

```powershell
python scripts/export_quantx_static.py `
  --base-url http://127.0.0.1:3011 `
  --date 20260828 `
  --output D:\exports\quantx-20260828.html
```

脚本使用 Microsoft Edge 打开页面并点击同一个导出按钮，随后在断网浏览器上下文中重新加载文件，检查：

- 页面标题和交易日元数据；
- 在线 Canvas 与离线图表图片数量一致；
- 不含脚本及 `localhost`、`127.0.0.1`、`::1` 引用；
- 桌面和移动视口没有页面级横向溢出；
- 离线页面没有控制台错误。

输出文件已存在时脚本默认拒绝覆盖；确认目标无误后可显式增加 `--force`。可用 `--screenshot <path>` 保存离线页面首屏验收图。

## 发布边界

导出的 HTML 可以直接放入 Nginx、对象存储或 GitHub Pages 等静态目录，不需要部署 TickFlow 后端。文件可能包含当前页面可见的候选股票、市场数据和分析结果；对外发布前仍应人工确认内容和授权边界。
