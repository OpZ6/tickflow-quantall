# QuantX 交互式单文件 HTML 导出

状态：当前可用能力。用于把一个已发布交易日的 QuantX 看板打包成可离线交互、可直接上传静态站点的单个 HTML 文件。旧版 Canvas 转 PNG 的静态快照模式已经移除。

## 页面导出

1. 打开目标页面，例如 `http://127.0.0.1:3011/quantx/20260828`。
2. 等待页面和高级图谱加载完成。
3. 点击顶部的“导出交互 HTML”。
4. 浏览器下载 `quantx-20260828.html`。

导出文件内嵌当前交易日的 Catalog、Review、Multiday、Advanced、完整数据表、质量血缘和百日新高成员数据，同时打包 QuantX React/ECharts 便携运行时和页面样式。文件不依赖 TickFlow API、前后端进程或本机地址，断网打开仍可重新绘制图表。

离线文件保留以下交互：

- ECharts 悬浮提示、图例和图表自带缩放；
- 5/10/20 日窗口、行业一级/二级和均线窗口切换；
- 连板晋级周期、主线、相关行业及其他看板筛选；
- 完整数据、质量血缘折叠区；
- 百日新高聚类的个股明细下钻。

离线文件固定为一个交易日，因此不提供日期切换、数据刷新、重新采集或重新计算。每次打开从看板默认筛选状态启动，但该日已打包的筛选数据均可继续切换。

## 命令行导出与离线验收

前后端运行时，可从仓库根目录执行：

```powershell
python scripts/export_quantx_static.py `
  --base-url http://127.0.0.1:3011 `
  --date 20260828 `
  --output D:\exports\quantx-20260828.html
```

脚本名为兼容既有命令仍保留 `static`，实际导出的是交互式文件。脚本使用 Microsoft Edge 打开页面并点击同一个导出按钮，随后在断网浏览器上下文中重新加载文件，检查：

- 页面标题和交易日元数据；
- 在线与离线 Canvas 图表数量一致，且未退化为图片；
- 没有本机资源引用或外部网络请求；
- ECharts 悬浮提示、窗口切换、行业筛选、连板周期、折叠区和百日新高明细下钻可用；
- 桌面和移动视口没有页面级横向溢出；
- 离线页面没有控制台错误。

输出文件已存在时脚本默认拒绝覆盖；确认目标无误后可显式增加 `--force`。可用 `--screenshot <path>` 保存离线页面首屏验收图。

## 发布边界

导出的 HTML 可以直接放入 Nginx、对象存储或 GitHub Pages 等静态目录，不需要部署 TickFlow 后端。文件包含可执行的内嵌运行时以及当前交易日完整数据（包括默认折叠和下钻内容）；只应打开可信来源生成的文件，对外发布前必须人工确认数据、候选股票和授权边界。文件内置 CSP，把资源和数据请求限制在离线运行所需范围，并明确设置 `connect-src 'none'`。
