# 图表引擎降债方案（EChartsCandlestick）

> 现状：`frontend/src/components/EChartsCandlestick.tsx` 本地 2049 行 / 上游 1222 行，
> 是相对上游偏离最大的单文件。此文说明为什么**不能机械外置**，以及三条可选路线。

## 一、当前已做

| 动作 | 结果 |
|---|---|
| 缠论纯映射外置 | 拆出 `frontend/src/custom/charts/chanlun-layer.ts`（111 行），组件里 7 行再导出 |
| 区块标记 | 该文件剩 24 个 `# >>> LOCAL-EXT` 区域，下次合并可直接定位 |

## 二、为什么剩下的不能照搬外置

组件里的本地改动不是"整块功能"，而是**逐段嵌进上游的 ECharts option 拼装逻辑**：

- 上游负责 `series` / `xAxis` / `dataZoom` 的骨架，本地在里面插条件分支
  （例：`if (chanlun.visible)` 追加笔/线段/中枢 series）
- 本地还改了指标线的计算入口（`cachedLines` 缓存、副图 `buildSeries`）
- 这些 hunk 与上游代码**逐行交错**，外置等于重写整个 option 构造器

机械方案只有一个：整文件搬到 `custom/`，上游路径留 shim 再导出。
**这条路不要走** —— 它把"合并冲突"换成"静默丢弃上游改进"：
shim 之后上游每次改这个组件都不再进入生效路径，等于永久 fork 一个 1200 行的组件，
比现在每次花 1-2 小时解冲突更贵。

## 三、三条路线对比

| 路线 | 做法 | 成本 | 长期收益 | 风险 |
|---|---|---|---|---|
| **A 现状+标记**（当前） | 保持交织，靠 LOCAL-EXT 标记定位 | 已完成 | 每次合并 1-2 小时 | 低 |
| **B 整体搬家+shim** | 文件移到 custom/，上游路径 shim | 半天 | 零冲突 | **高**：上游改进永久失效 |
| **C 增量外置+插槽**（推荐） | 继续拆"纯函数/纯配置"，新功能走扩展插槽 | 分 3 期，每期 0.5-2 天 | 冲突面逐期下降，且不丢上游改进 | 中低 |

## 四、路线 C 的分期计划

### 期 1：把"纯函数"全部搬出去（预计 0.5-1 天）

目标：组件内只剩 option 拼装，所有可单测的逻辑都在 `custom/charts/` 下。

| 候选 | 特征 | 判据 |
|---|---|---|
| `cachedLines` / `LineDef` | 指标线缓存与定义 | 入参出参都是纯数据，不碰 echarts 实例 |
| 副图 `buildSeries` 的本地分支 | 量比/成交额等副图数据 | 只要返回值是 series 配置数组即可外置 |
| tooltip `buildInfo` | 格式化函数 | 纯字符串拼装 |

做法：逐个函数迁到 `custom/charts/`，组件侧 import；每迁一个跑一次 `tsc` + `vitest`。

### 期 2：新功能一律走插槽（预计 1-2 天）

上游 v0.4.1 已提供扩展插槽机制（`frontend/src/extensions/registry.ts`，
`stock-preview.tabs` 等）。规则：

- **个股详情页新增的图表标签页** → 注册成插槽实现，不改 `pages/`
- **图表上的新图层/新标记** → 通过组件的 props（`ChartMarker` / `ChartRange` /
  `ChartPriceLine`，这些类型本地已扩展）传入，而不是在组件里加分支

### 期 3（可选）：把整块图表引擎做成可安装扩展（1-2 周）

只有在期 1、2 做完、且确认"引擎本身"（不是某个图层）需要替换时才做。
届时要解决的不是文件位置，而是**依赖注入**：引擎需要的 repo 数据、样式、
主题变量都要通过扩展上下文传入。在此之前做，等于重写。

## 五、每期的验收标准

1. `npx tsc --noEmit` 0 错
2. `npx vitest run` 全过（979 用例）
3. `npm run build` 成功，且 `_virtual_quantx-portable-runtime` chunk 正常产出
4. `backend/scripts/mark_local_ext.py` 重跑后，该文件的区块数**下降**
   （验证外置真的生效，而不是换了位置）
5. 人工过一遍个股详情页与缠论工作台（图表渲染、图层开关、tooltip）

## 六、什么时候该回头做

- 上游下次动 `EChartsCandlestick.tsx`（合并时冲突超过 30 分钟）→ 立刻做期 1
- 需要新增一个图表相关功能 → 先判断能否走插槽，不能才改组件
- 其他情况：保持 A，把时间花在能用上的功能上
