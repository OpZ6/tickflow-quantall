
# 经验
1. 逻辑：大盘 板块 个股（龙头）（情绪 + 周期 + ICT量价分析）
2. 模式：短线（涨停跌停池 / 高标）（追涨反核） + 波段（逻辑 辨识度池）（低吸埋伏）

3. 原则
  a. 只买在开盘1小时和收盘10min
  b. 仓位1层起步（0.5试探 + 0.5确认 买入就偏离预期马上停止）
  c. 空头区间（直接逆回购强制控仓）
  d. 止损 = 交易逻辑不成立（不强制设止盈止损，但是必须提前确定买卖逻辑）
1. 思想
  a. 万物皆周期（情绪周期、供需周期）
  b. 价格终合理（牵牛理论：基本面决定位置，情绪决定偏离）
  c. 顺势而为，只做跟随，不预测不假设（趋势大于一切、要下雨就不出门了）
  d. 对的时间做对的是（弱转强、买在分歧转一致、节点、预期管理）
  e. 盈亏比必须考虑（eg. 有3倍盈亏比？有30%涨幅预期吗？没有就不买）
  f. 成功 = 避免失败（所有会导致亏损的事不做就快成功了）
  g. 萨丕尔沃尔夫假设（说不清写不出来 = 没有理解）
  h. 只做核心龙头（龙头涨的更多更抗跌更容易二波更安全、去弱留强）
  i. 涨跌核心逻辑（买卖谁更急谁钱多谁人多 / 明天里面的卖不卖外面还有没有人买）
  j. 交易就是打游戏（买卖操作都公平 / 意识信息处理存在差距）
  k. 交易你的计划，计划你的交易（只做看得懂的）
1. 执行
  a. 盘前判断（外围形式 + 收盘后信息动向）
  b. 执行计划（随手记录思考 + 执行记录）
  c. 收盘复盘（盘面解读 + 跟昨日预案对比）
  d. 选票计划（规划自选 + 买卖预案 + 待验证逻辑）
  e. 周期反省（交割单复盘 + 行情大复盘）
