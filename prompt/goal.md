## 禁止炼丹

留下的三层是机制（突破日有没有需求、利润保护、VCP 至少三段）。在同一批冻结样本上再切检测器分数，就是炼丹。

**禁止当下一轮：** 把 `volume_ratio` / `tightness` / `dry_volume_ratio` / RS / `distance_high_max` / 收缩比 / 尺度罚分 再切一个更圆的数（1.50、0.40、0.70、85→90 都算）。不扫网格也算。`dry_volume_ratio≤0.70` **作废**，不要做。给回的高点/收盘守成本邻域不要再收紧。入场日收盘跌破成本、两日无需求及其天数/+3% 邻域不要再做（VCP 与杯柄都已扔）。突破阳线、守前日低点、收盘站上昨高不要再叠。杯柄 5% 守成本不要再跑。本轮起暂停 VCP。

样本再缩到几十笔不当新主本。验证翻负的收紧直接扔。

## 下一处必须是思路

只准动买点或卖点**种类**（突破 / 回踩 / 企稳；回撤 / 止损 / 破均线 / 利润保护），或先解剖当前薄本亏在哪条路径再改那一处。要能用市场行为说话：这根 K 线是什么、这笔亏在哪段，不是「分数再紧一档」。暂停 VCP 新规则实验。

**当前安排（新计划，尚未执行）：** 杯柄一轮 → 突破回踩一轮 → 跨策略覆盖汇总。两条线各自登记基线、唯一机制、完整机会集及通过/停止条件，先复用已有路径结论。杯柄从无跟随、追高或利润回吐中选择尚未检验的一种买点或卖点；回踩独立研究启动后的缩量回调、承接和企稳，不要求来自 VCP 名单，不照搬 VCP 总闸或退出参数。每条线最多一轮定向诊断后进入实际规则对照或淘汰假设。

每轮同时报告年/月成交数、有信号日占比、最长无信号交易日间隔、各市场环境的频率与净收益；汇总同日/同股重合、独有机会、VCP 无信号日新增成交及其净收益和共同亏损时期。环境定义在实验前冻结，输入只用当时可见信息；机会并集去重，保留负收益环境。增加频率必须验证新增机会质量，不靠放宽阈值凑次数。
