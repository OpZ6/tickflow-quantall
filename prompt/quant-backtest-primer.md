# 量化研究与回测实战入门

> 面向有基础交易概念、刚开始做量化研究的人。目标不是背指标名，而是能提出一个可检验的问题、做出可信回测、读懂结果，并知道离实盘还差什么。
>
> 本文把通用方法、A 股执行规则、TickFlow 项目口径和 WorkBuddy `factor-timing-research` 的 0AMV 实战经验放在一起。文中出现的具体数值门槛是项目或个案约定，不是适用于所有策略的自然定律。

## 一页先看懂

量化研究不是“找一个指标、扫一堆参数、挑收益最高的”。完整链路是：

```text
交易想法
  → 说清楚收益机制和失败方式
  → 冻结数据、股票池、时间、基准、成交和成本口径
  → 先测信号/选股，再测进场/退出，最后测组合
  → 用训练期提出规则，用未参与研究的时间检验冻结规则
  → 做成本、年份、市场状态、参数和统计不确定性检查
  → 影子运行核对信号，再决定是否进入实盘
```

每一项回测，至少要能回答六个问题：

1. **赚什么钱？** 市场上涨、选对股票、择对时间、行业暴露，还是少亏？
2. **当时能知道吗？** 信号和特征是否只用决策时已经公开的数据？
3. **当时能成交吗？** 是按下一交易日可执行价格，还是偷用了信号日收盘价？
4. **扣费后还剩多少？** 手续费、税费、滑点、涨跌停和未成交如何处理？
5. **是不是挑出来的？** 搜过多少规则、参数、年份和切片？测试数据有没有被反复看？
6. **钱会怎样走？** 收益、最大回撤、持仓时间、换手、集中度和连续亏损能否承受？

## 1. 先分清四个层次

| 名称 | 含义 | 例子 |
|---|---|---|
| **数据特征** | 描述股票或市场的原始/加工信息 | 成交额、换手率、20 日涨幅、距 60 日高点距离 |
| **因子** | 用于衡量或排序某种特征的数值 | 动量因子、低波动因子、1AMV 活跃占比 |
| **信号/规则** | 何时关注、买入、持有或退出的明确条件 | 收盘突破枢轴位，次日开盘尝试成交 |
| **策略/组合** | 把候选、信号、成交、仓位、退出和现金管理连起来 | 每日筛选候选，信号触发后按规则持有并退出 |

**指标好看 ≠ 因子有效；因子有效 ≠ 交易策略赚钱；策略回测赚钱 ≠ 实盘可执行。** 每一层都要有自己的证据。

另外要区分**事件信号**和**状态信号**：事件是“今天刚发生一次”（例如上穿）；状态是“目前处于条件成立阶段”（例如价格在均线上方）。把状态每天都当成新事件，会重复入场、虚增信号次数；把事件写成持续状态，又可能错过真正的首次触发。

## 2. 先把研究问题写清楚

好的研究问题能被结果否定。例如：

> 在同一批符合 VCP 观察条件的股票里，加入“首次放量突破确认”后，未来 10/20 个交易日的基准调整收益是否改善？改善是否跨年份、扣除成本后仍存在？

研究开始前先写下：

| 要素 | 需要写清楚 |
|---|---|
| **机制假设** | 为什么市场参与者可能制造这个机会？最可能怎样失效？ |
| **策略身份** | 做趋势突破、回踩、均值回归、事件漂移，还是仓位择时？不要拿一个身份的指标评价另一个身份。 |
| **唯一改动** | 本轮改变哪一条规则？其余条件固定。 |
| **信号时点** | 用收盘后数据、盘中数据，还是公告数据？当时能否取得？ |
| **目标收益** | 买什么、以什么价格成交、持有多久、和哪个基准比较？ |
| **失败标准** | 什么结果会让你放弃这条假设，而不是继续调参数？ |

研究假设不是结果出来后的解释。先写假设、门槛和失败动作，减少看到收益后不断改口径。

## 3. 数据与时点：可信回测的地基

### 3.1 未来函数与数据泄漏

**未来函数**是信号里用了当时尚不知道的数据。常见例子：用完整当日成交额做上午盘中的决策；用公告发布日期之后才发布的财务值回填公告前；用未来最高价判断今天的突破质量。

逐条检查：

- 日线收盘信号通常最早在**下一交易日**成交；同日收盘成交常是偷价。
- 公告数据按公告可得时间生效，不能只看财报所属季度。
- 行业、概念成分、ST 状态、上市和退市股票都可能随时间变化，要用当时版本。
- 全市场股票池不能只留下今天还活着的股票，否则会有**幸存者偏差**。
- 每个向前收益标签都要严格按全市场交易日对齐；停牌或缺行不能把下一根个股 K 线误当作下一交易日。
- 训练期末的信号、成交、持有和未来收益标签不能越过训练边界；重叠标签需要 purge/embargo。

**Point-in-time（时点数据）**就是只使用当时已发布、可获取的值。历史数据后来被补齐，不代表当时就知道它。

### 3.2 单位、复权和时间轴

- 明确金额是元、万元还是亿元；换手率是 `0.05` 还是 `5`；收益率是小数还是百分数。
- 每个字段记录来源、单位、空值含义、交易日归属和变更历史。不能用“数值小于 1 就乘 100”猜单位。
- 信号计算用什么价格、成交模拟用什么价格要写清。A 股技术信号通常使用一致的复权序列；涨跌停和成交约束应基于未复权价格及对应交易规则。
- 长历史数据要查单位断点、字段定义变化、预热期和供应商回填；交叠区逐日配对，不要分别排序后再比较。
- 递推指标有热身期；从不同起点重算，量化起点影响，不要只照抄文档里一个天数。

项目中的真实提醒：本地 `kline_daily_enriched` 曾在 2016 年底附近出现 `amount` 与 `turnover_rate` 的量纲断点。这类问题不会必然报错，却会让历史因子整体失真，所以要画按月/年分布并检查量级连续性。

### 3.3 外部指标与参考序列怎么验

拿第三方指标来校准本地算法时，相关性高不代表它就是原版真值。先检查指标应满足的物理边界，再核对来源、单位、覆盖日期和推断/回填迹象；跨来源比较必须按日期逐点配对。判断能否用固定乘数校准，可看比值的变异系数（CV）和逐年极差，不要只看 R²。若偏差随指标“水位”系统性变化，可能是饱和或非线性，而不是单纯量纲差异。

## 4. 把信号变成可交易的回测

### 4.1 交易口径五件套

每次回测都要明确：

1. **信号**：哪条数据和规则产生信号？
2. **标的**：信号对象和实际交易品种是否相同？指数信号可能用于交易 ETF，而指数本身不能直接买卖。
3. **成交**：何时提交、用什么价格、无法成交如何处理？
4. **现金**：空仓收益记 0、现金利率，还是其他约定？
5. **成本**：佣金、印花税、过户费、滑点、冲击成本和复权口径如何处理？

这些定义必须同时进入回测代码、结果报告和线上信号，不能页面说一种、引擎算另一种。

### 4.2 A 股执行约束

- **T+1**：普通股票买入后通常不能当日卖出，不能把日内高低点都当成可交易机会。
- **涨跌停与一字板**：触及涨停不等于一定能买到，触及跌停不等于一定能卖出；日线数据通常无法还原排队和盘中流动性，应保守说明近似边界。
- **停牌、无成交、退市和新股**：保留不可交易原因，不能静默删除亏损或难成交样本。
- **成本随日期变化**：税费和制度可能改变，不能拿今天的费率套全部历史。
- **仓位与资金约束**：候选平均收益不等于账户收益。组合层还要模拟同日信号竞争、资金占用、持仓重叠、成交优先级和现金。
- **容量**：小资金回测的价格影响不代表大资金也能按同样价格成交；检查成交额、换手和冲击成本。

### 4.3 选股、择时、退出、仓位要分开

- **选股质量**：信号日挑出的股票是否优于同日可投资股票？
- **入场质量**：同一候选中，触发时点是否优于其他可执行时点？
- **退出质量**：固定持有表现好、实际退出差，通常说明退出兑现有问题，不是选股无效。
- **仓位/择时**：策略何时持有、持有多少？要和同平均仓位的固定方案比较，减仓带来的回撤下降可能只是机械效果。
- **组合质量**：候选是否同时出现、相关性是否过高、回撤是否由少数时段集中造成？

一次只改变一个机制。候选规则变更时，检查新增和删掉的股票；退出规则变更时固定候选和入场；仓位变更时固定交易信号。

## 5. 收益与风险指标词典

| 指标 | 直白解释 | 读法与限制 |
|---|---|---|
| **累计收益** | 起点到终点净值涨了多少 | 受区间影响大，不能单独代表年化能力。 |
| **CAGR** | 把累计复利换算成每年增长率 | 不能说明中间是否经历巨大回撤。 |
| **基准收益** | 同期买入并持有或按约定基准计算的结果 | 基准要可投资、口径一致，并与策略回答的问题匹配。 |
| **超额 / Alpha** | 策略相对基准的表现 | “策略 CAGR − 基准 CAGR”是年化差值；正式报告要注明公式。CAR、BHAR、相对财富超额不是同一个量。未经风险因子回归的基准超额，不要叫“纯风险调整 Alpha”。 |
| **胜率** | 盈利交易占比 | 不看盈亏大小会误导；低胜率也可能靠少数大赢家盈利。 |
| **盈亏比** | 平均盈利 ÷ 平均亏损绝对值 | 与胜率一起看，并扣成本。 |
| **期望值** | 单笔平均赚/亏的预期 | 粗略为 `胜率×平均盈利 − 败率×平均亏损`；还要考虑成本、相关性和分布尾部。 |
| **Sharpe** | 单位波动对应的超额收益 | 日收益相关、偏态或厚尾时，简单年化可能失真；不要只看排名。 |
| **MDD** | 净值从高点到之后低点的最大跌幅 | 同时看回撤持续时间、恢复时间和发生在哪几年。 |
| **Calmar** | 年化收益相对最大回撤的比值 | 对样本区间和单次极端事件很敏感。 |
| **MFE / MAE** | 持仓期间最大有利/不利波动 | 用于研究退出与路径，不等同于真实可实现利润。 |
| **换手 / 持仓时间 / 暴露** | 交易频繁程度、平均持有多久、多少时间持仓 | 决定成本敏感度、策略体验和资金占用。 |
| **收益集中度** | 收益是否主要由少数股票、年份或交易贡献 | 集中度高时，平均收益和胜率会掩盖单点依赖。 |
| **置信区间** | 估计值可能落在哪个范围 | 区间很宽，说明证据不精确；交易/日期相关时，应按相关结构估计，不能把重叠交易假装成独立样本。 |
| **p 值 / 显著性** | 在某个零假设成立时，观察到这类数据有多意外 | 小 p 值不等于策略赚钱、因果成立或实盘可靠；试过很多规则时要考虑多重比较。 |
| **统计功效 / 样本量** | 有多大把握识别真实差异 | 交易次数少、年份少或只有单一行情时，结论可能只是证据不足。 |
| **仓位 / 暴露** | 账户把多少资金放在策略或标的上 | 等权、固定仓位、波动率仓位回答不同问题；仓位变化会改变收益和回撤，必须单独模拟。 |
| **容量 / 冲击成本** | 资金变大后能否按回测价成交 | 交易额、盘口和换手有限时，滑点会随规模增加；小资金回测不能直接外推大资金。 |

夏普常见计算会用年化因子 `√252`，但它依赖收益过程假设；收益存在序列相关时，年化夏普可能偏高。[Lo 对夏普比率统计性质的研究](https://alo.mit.edu/research-page/the-statistics-of-sharpe-ratios/) 也说明不能不看收益序列特性就机械比较夏普。

## 6. 因子、IC 与横截面检验

### 6.1 IC 怎么读

在每个交易日，把股票因子值排序，再与之后固定窗口收益排序比较，得到当日 **Rank IC**。然后看时间序列的 IC 均值、离散程度、正值比例、逐年表现和样本覆盖。

- **IC 均值为正**：高分股票平均更强的初步证据。
- **ICIR**：常用 `IC 均值 ÷ IC 标准差`，衡量稳定性；不同实现的年化定义需说明。
- **分组收益**：把股票按因子分成几组，看收益是否大致随分数递增。
- **收益衰减**：比较 1/3/5/10/20 日等未来窗口，找出信号的有效期限。
- **换手与成本**：一个每天剧烈换仓的因子，理论排序优势可能被交易成本吃掉。
- **高低组差**：通常只是排序诊断。A 股不能随便假定能做空低分组；不能把理论多空收益说成可执行收益。

IC 回答“因子能否排序”，不直接回答“具体买入规则能否赚钱”。它需要再经过成交、持仓和组合层测试。

### 6.2 因子重复与正交化

若两个因子高度相关，它们可能在重复表达同一个东西。可做相关矩阵、相关聚类、因子族对比，或回归/残差化来分离共同部分。

多个因子或入场/出场规则组合时，**解耦**是把各部分贡献拆开：

1. **跨轴 Spearman**：比较某种入场规则在所有退出规则下的表现排序，与另一种入场规则的排序是否相似。排序高度相似，说明该轴内方法可能同质，可先选“族”；差异大则要进一步逐项比较。
2. **加性主效应与交互残差**：先用“整体均值 + 入场主效应 + 出场主效应”估计组合表现，再比较实际表现与估计值的差。若最高收益组合主要来自异常交互项，它可能是偶然搭配，不能只报冠军收益。
3. **方差/贡献拆分**：比较入场、退出和交互各自能解释多少结果差异，决定下一轮研究精力放在哪一侧。

**残差**也有两种常见用途：从收益中回归掉市场、行业、规模等共同暴露，观察相对表现；或从因子中剔除其他因子可以解释的共同成分。残差依赖回归对象、时点和样本，不自动等于 Alpha，也不自动代表新因子。

**正交化不是自动升级**：把因子对行业、规模或市场暴露回归后取残差，可以减少已解释暴露；但残差依赖模型选择，仍需时点检验和真实策略验证。

### 6.3 可解释性审查

对一项策略，至少能用一句话说清它试图捕捉的行为机制、什么时候应当有效、最可能怎样失败。随后用消融或对照确认收益真的来自那条规则，而不是市场上涨、某一行业暴露或少数异常交易。规则代码容易解释，不代表统计证据可靠；复杂模型给出 SHAP 等解释图，也不能替代样本外验证。

## 7. IS/OOS、WF 和防过拟合

### 7.1 三种时间段

- **训练/IS**：形成机制、估计参数、筛选候选。
- **验证**：比较少量预先约定的版本，不能无限试到满意。
- **最终 OOS/留出段**：规则冻结后，只用于接受或否决；看完后再修改就失去独立性。

金融时间序列不能随机打散行做普通交叉验证：相邻日期、持仓窗口和收益标签会重叠。**Walk-forward** 应按时间用过去训练、之后测试；嵌套 WF 则在训练窗里选规则，在外层未来窗做独立评估。标签重叠时用 **purge/embargo** 清除边界污染。

本项目当前右侧波段规范把 2016–2022 用作研究冻结区间；2023 年以后的相关形态研究数据已经暴露，不能重新称为“干净样本外”。真实新 OOS 应来自规则冻结后未参与研究的日期。

### 7.2 搜索越多，冠军越可疑

每试一套因子、阈值、周期、市场切片或退出方式，都在增加“偶然挑中好结果”的机会。必须记录实验族和尝试次数，保留失败结果，控制多重比较。

有用的过拟合检查包括：

- 族级边际表现优先于单个最高格；
- IS 参数排名与 OOS 排名是否一致；
- walk-forward 是否跨多个时期有效；
- 延长历史后结论是否翻转；
- 参数曲线是平台还是尖峰；
- 逐段、逐年差值是否集中在一次行情；
- 成本提高后策略是否存活；
- 时间块 bootstrap、循环位移等零假设检验是否仍显示优势。

这些检验的实现前提不同，不能把某个 p 值当“去过拟合证明”。循环位移必须保留被检验信号/状态序列的重要结构；普通随机打乱会破坏自相关，制造过窄的零分布。

金融因子研究尤其要重视多重检验：大量尝试会让常规显著性门槛不再可靠。[Harvey、Liu、Zhu 关于因子检验与多重比较的研究](https://www.nber.org/papers/w20592) [Bailey 等关于回测过拟合概率的研究](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2326253)

**回测过拟合概率（PBO）**是估计“在许多候选规则中，样本内赢家在样本外落到中位数以下”的方法之一；CSCV 是其常见计算框架。它帮助评估搜索和选冠军造成的偏差，不能替代真实的时间顺序 OOS，也不能修复未来函数或错误成交模型。

**Bootstrap（重采样）**用于估计结果的不确定范围。重叠交易和同日信号相关时，不能把每笔交易当完全独立；要按交易、日期区块或聚类结构选择重采样单位，并说明假设。它描述样本不确定性，不会创造新的历史行情。

### 7.3 网格不是“炼丹许可证”

网格适合在**机制已确定后**观察规律和脆弱性：

- 先按机制把参数分成族，看族的均值、中位数、极差和正向占比；
- 只在有理由的族内做有限细化；
- 平台表示附近取值差异较小，尖峰表示结果对参数脆弱；
- 再做逐年/逐段归因，排除“平滑平台其实只靠一个年份”的情况；
- OOS 不用于回头挑参数。

Workbench `factor-timing-research` 中常见的 60/40 切分、WF 五段、30 笔提示线和特定成本档，是其 0AMV 实战采用的协议示例，不是每个 A 股策略都必须照抄的通用阈值。项目研究应预先设定适合目标周期、样本量和执行方式的门槛。

## 8. 控制变量、归因与“它到底贡献了什么”

### 8.1 常用对照

| 对照 | 主要回答 |
|---|---|
| 同期可投资市场基准 | 策略是否只是在牛市里跟涨？ |
| 同日/同类机会集 | 选择器是否比当时其他候选多提供了信息？ |
| 固定候选、替换入场 | 入场时点有没有贡献？ |
| 固定入场、替换退出 | 退出是否改善实际兑现？ |
| 同平均仓位固定方案 | 择时是否优于简单减仓？ |
| 反向状态/安慰剂信号 | 所谓市场状态是否真有方向信息？ |
| 保留组与跳过组 | 过滤器避开亏损，还是错过盈利？ |

基准和匹配机会集回答不同问题。对照不能用来替代真实账户模拟，也不能事后挑一个最容易战胜的基准。

### 8.2 收益来源拆解

报告要区分：

- **Beta**：跟随市场普遍上涨赚到的钱；
- **选择贡献**：同一天选到更好的股票；
- **择时贡献**：同一标的选到更好的买卖时机；
- **退出贡献**：把浮盈兑现或限制损失；
- **仓位贡献**：决定持有多少、何时空仓；
- **行业/风格暴露**：收益来自偏向某些行业、市值或波动风格。

**消融**就是暂时拿掉一条规则、与完整基线比较；**匹配控制**是在尽量相似的机会之间比较；**残差分析**则尝试扣除市场、行业等共同暴露。它们是不同工具，结论仍受样本、模型和匹配质量限制。

## 9. 市场状态与因子择时

“牛市用 A、熊市用 B”听起来合理，但状态切换规则可能只是把收益在时期之间挪动。验证前先分清：

- **规则切换**：改进场/出场规则；
- **仓位调整**：同一信号改变下注大小。

择时研究至少要：

1. 用当时可得、只看过去的指标定义市场状态，不能拿未来涨跌贴标签；
2. 先判断不同状态是否确实造成策略代价；
3. 和不加状态、固定口径、反向状态、同平均仓位方案比较；
4. 报告覆盖期与非覆盖期收益、全样本结果、MDD、交易次数和平均仓位；
5. 做标签循环位移或适当的时间序列零假设检验；
6. 冻结切换规则后再做 OOS。

若规则切换在各状态下实际选出的都是同一条固定规则，说明状态没有增量。若全样本没有改善，只是把牛市踏空换成熊市少亏，应如实称为风险偏好/回撤取舍，而不是预测能力提升。

## 10. 结果报告怎么读

一份合格报告不要只有一条净值曲线。至少应有：

1. 研究问题、机制、唯一变量、尝试范围和冻结时间；
2. 数据版本、股票池、因子时点、复权、交易日历和缺失值处理；
3. 信号、成交、退出、成本和未成交规则；
4. 策略与基准收益、明确定义的超额、MDD、Sharpe/Calmar、换手和暴露；
5. 交易数、逐笔分布、逐年/逐段、市场状态、收益集中度；
6. 训练/OOS/WF、成本压力、参数敏感性和多重检验说明；
7. 候选新增/删除及失败案例；
8. 结论等级：实现正确、机制线索、训练支持、研究支持、时间测试通过、实盘资格；
9. 数据和模型限制、下一步和停止条件。

“结果不显著”不等于证明策略无效；可能是样本不足。反过来，“回测赚钱”也不是有效证明；可能是幸存者偏差、数据泄漏、成本低估、参数搜索或单次行情造成。

## 11. 从研究到实盘：上线前清单

### 研究完成

- [ ] 规则在测试前冻结，成功/失败标准提前写明。
- [ ] 至少有一个合理的同期基准和相关匹配对照。
- [ ] 信号、成交和成本符合 A 股交易时序；未成交原因留账。
- [ ] 逐年、分段、不同市况、交易数、收益集中度和最大回撤都检查过。
- [ ] 已做样本外/滚动验证和成本压力；准确标注已暴露年份。
- [ ] 关键结论没有只靠一次极端行情或少数个股。

### 生产准备

- [ ] 生产信号与研究实现逐日一致；独立实现能互相核对。
- [ ] 数据更新、缺失、异常值、单位、交易日和复权有检查与告警。
- [ ] 先影子运行，比较真实信号、成交可行性、滑点和提醒频率。
- [ ] 版本、配置、数据快照、日志和回滚方式留档。
- [ ] 明确系统边界：日线信号是否盘中可用、是否支持自动下单、是否含资金约束。
- [ ] 设立失效条件和停止开关；实盘偏离回测假设时暂停并查原因。

回测达到训练门槛，只能说明值得继续验证。没有时间测试、成交可行性、成本与线上一致性，不应称为“实盘已验证”。

## 13. 对当前 TickFlow/QuantX 的学习路线

按实战优先级学习，而不是先学复杂模型：

1. **回测口径和交易记账**：信号日期、T+1、基准、成本、停牌/涨跌停、现金和组合净值。
2. **数据时点与偏差**：未来函数、幸存者偏差、公告时点、历史成分、复权、单位断点。
3. **策略拆解**：候选召回、选股质量、入场、退出、仓位、组合分别测试。
4. **收益与风险**：Alpha/基准、MDD、逐笔分布、逐年稳定性、成本敏感度。
5. **验证与反过拟合**：IS/OOS、walk-forward、purge/embargo、尝试次数、参数平台和单事件归因。
6. **因子研究**：Rank IC、分组收益、因子相关、暴露控制、残差、收益衰减。
7. **市场状态/因子择时**：前六项有可靠基线后再学；先研究它是否有增量，不要先加 regime 开关。
8. **生产运行**：信号重放、影子运行、监控、版本和回滚。

项目内已有可直接对照的实现规范：[因子与策略挖掘](../mining.md)、[策略研究方法论](strategy-development-methodology.md)、[策略迭代指南](../strategy-iteration.md)。当前主线是 A 股中短线右侧突破与回踩；因子排序指标可作辅助研究，但不能替代固定机会集上的前向收益、可成交性和组合层验证。
