01 / MAP

先看懂量化研究的整条链

量化不是把主观判断塞进代码，而是让每个判断可复算、可反驳、可执行。

数据价格、成交、公告
特征20 日涨幅、换手
因子排序或度量
信号何时触发
成交能否买到
策略持有、退出、仓位
组合净值与回撤
重要：一项因子有排序能力，只说明“分数高的股票之后更强一些”。它还没有证明具体买点、退出方式、交易成本和组合结果有效。
FEATURE

特征：股票有什么样子？

如成交额、波动、20 日收益、距前高距离。

FACTOR

因子：怎么量化这个特征？

如动量、低波动、活跃度。可用于排序，也可能只是研究变量。

STRATEGY

策略：何时买卖、投入多少？

把选股、触发、执行、持仓、退出、现金和成本连成规则。

EVENT / 事件

“刚刚发生了一次”

例如今天第一次上穿某个水平。适合表达触发时刻。

  • 通常关心首次触发和重复信号去重。
  • 错把状态当事件，会每天重复买入。
STATE / 状态

“现在处于条件成立阶段”

例如价格持续在均线上方。它描述当前状态，不一定是买点。

  • 状态恢复时入场，可能属于追确认。
  • 别把持续状态的每一天都计作独立信号。
02 / METHOD

一轮研究怎么走？

每个实验只解决一个问题。先写规则和失败条件，再运行回测。

写出机制为什么可能有效？最可能怎么失效？
冻结口径数据、股票池、时点、基准、成交、成本。
拆成模块候选、选股、买点、卖点、仓位分开测。
先跑基线记录所有机会和交易，别只留成功案例。
只改一件事让对照组和实验组只有一个关键差异。
检查结果超额、回撤、逐年、成本、交易数和集中度。
验证冻结规则时间滚动和未见数据只用于判定。
影子运行先核实线上信号和成交，再考虑实盘。
研究问题示例：在同一批 VCP 观察股票中，“首次放量突破确认”能否改善未来 10/20 个交易日的基准调整收益？如果扣费后不改善，或只靠某一年，就应接受失败结论。
03 / DATA

回测最容易错的地方：数据时点

金融数据错了，程序经常仍能正常运行，只会给出看似合理的错误答案。

LOOK-AHEAD

未来函数

信号用了当时还不知道的信息。收盘信号通常从下一交易日开始成交；公告值从公告可得日之后生效。

SURVIVORSHIP

幸存者偏差

只回测今天还活着的股票，漏掉退市和失败公司，会虚增历史表现。

POINT-IN-TIME

历史可见性

财务报告期不等于公告时点；历史行业、成分、ST 状态也要按当时版本。

UNITS

单位断点

金额元/万元、换手率小数/百分数的变化会让整段因子失真。按月/年查量级。

PRICE BASIS

复权口径

信号序列和成交、涨跌停判定用价要分清。不要把复权价和原始价混进同一规则。

CALENDAR

交易日对齐

停牌/缺行不能把下一条个股记录冒充下一市场交易日；所有窗口按交易日定义。

项目中的实际教训：本地日线增强表曾在 2016 年底附近出现成交额与换手率量级断点。遇到“某指标早期突然全为零/巨大”时，先查单位和来源变更，再讨论算法。
EXTERNAL DATA CHECK

第三方指标不等于原版真值

先查物理边界，再核来源、单位、覆盖日期和推断/回填迹象；跨源逐日配对。要判断固定乘数能否校准，看比值 CV 与逐年极差；偏差随数值水位改变，可能是饱和或非线性。

04 / EXECUTE

把信号变成真实能做的交易

回测是成交模拟。能在图上看见信号，不代表当时能按理想价格买到或卖掉。

T+1

买入后不能当天卖

普通 A 股买入仓位受 T+1 约束；不能拿日内高低点做不可能的往返。

LIMIT

涨跌停不保证成交

触板不代表能排上队。日线不能还原全部盘口，需保守处理并披露局限。

COST

费用与滑点

佣金、税费、滑点随规则和日期变化；还要测成本上升后的表现。

CAPACITY

资金规模

资金越大，越可能改变成交价。小资金回测不等于大资金可复制。

每次回测写清“五件套”

  • 什么数据生成信号？
  • 实际买卖的标的是什么？
  • 几点、按什么价格成交？买不到怎么办？
  • 空仓收益如何计算？
  • 成本包含哪些，历史费率是否变化？

按模块拆贡献

  • 选股：同一天选中的股票更好吗？
  • 入场：固定候选后，触发时点更好吗？
  • 退出：固定入场后，是否更好兑现？
  • 仓位：是否优于同平均仓位的固定方案？
  • 组合：资金约束、重叠持仓和回撤如何？
05 / METRICS

指标不是排行榜，要组合着读

收益回答“赚多少”，风险和路径回答“怎么赚、怎么亏、能否坚持”。

净值与回撤：终点相同，路可能完全不同

净值（A 股红涨）高点至低点 = MDD回撤谷值（A 股绿跌）
READ TOGETHER

不要只盯一个漂亮数字

  • CAGR：年化复利，不说明过程是否难熬。
  • 超额：相对同期基准；先讲清计算公式。
  • 胜率 × 盈亏比：理解赚钱靠高命中还是少数大赢家。
  • MDD + 水下时间：最大回撤和多久没回到前高。
  • 交易数 + 换手 + 成本：结果是否有足够样本、是否可执行。
  • 逐年/逐段 + 集中度：结果是否只靠一只股、一个年份或一次行情。
RETURN

收益与超额

策略净值与可投资基准比较。年化差值、累计财富比等定义不同，要写明。

累计收益 = 期末净值 / 期初净值 − 1
RISK

最大回撤 MDD

净值历史高点到之后低点的最大跌幅。越深、恢复越久，持有体验越差。

DD(t) = NAV(t) / 历史峰值(t) − 1
EXPECTANCY

单笔期望

胜率和输赢大小一起看；要按真实费用与成交计算。

胜率×平均赢 − 败率×平均亏
SHARPE

夏普

单位波动对应多少超额收益。收益相关、厚尾时，机械年化会误导。

平均超额收益 / 收益波动
PATH

MFE / MAE

持仓过程最大有利/不利波动。用来研究路径，不保证可按极值成交。

MFE = 最佳浮盈路径 · MAE = 最大浮亏
COST

换手与容量

换手高会增加费用；资金变大还会增加冲击成本和成交约束。

净收益 = 毛收益 − 费用 − 滑点
统计提醒：p 值小不等于策略可赚钱；置信区间宽说明估计不精确；交易少或只覆盖一种行情时，漂亮均值也可能不稳定。重叠交易不能假装成独立样本。
06 / FACTOR

IC：因子能否把股票排对顺序？

这是“选股排序能力”的检查，不是完整交易策略的成绩单。

同一天：因子排名 vs 后续收益排名（示意）

RANK IC

把截面排序变成数字

每个交易日，把股票按因子值排序，再与未来固定窗口收益排名做 Spearman 相关；每天算一次，再看这串 IC 的均值、波动、正值比例和逐年稳定性。

  • IC 均值为正：高分股票倾向于表现更好。
  • ICIR：常用 IC 均值 / IC 标准差；年化口径要说明。
  • 分组收益：分数越高，收益是否大致递增？
  • 收益衰减：优势能维持 1/5/10/20 天吗？
  • 成本和换手：排序优势能否覆盖频繁换仓费用？
一句话：IC 回答“排名有没有信息”，回测回答“按交易规则能不能赚钱”。高低组差异通常是排序诊断，不要把理论做空收益说成 A 股可执行收益。
DECOUPLE / 解耦

先看方法族是否同质

跨轴 Spearman：比较不同入场规则在一组退出规则下的表现排序。排序相似，可能只需选族；差异大，需逐项比较。

INTERACTION / 交互

别只盯组合冠军

用整体均值 + 入场主效应 + 出场主效应估计组合结果。实际值偏离预测的交互残差过大，最高格可能靠偶然搭配。

RESIDUAL / 残差

扣掉共同暴露后还剩什么？

可从收益或因子中回归剔除市场、行业、规模等共同部分。残差依赖模型和时点，不自动等于 Alpha。

07 / VALIDATE

IS、OOS、WF：防止“记住历史答案”

同一段历史既用来选规则又用来证明规则，会高估未来表现。

过去训练形成机制、估参数、筛候选
内层验证只在训练窗内比较候选
外层测试冻结规则后评估一次
未见未来真正前向/影子验证
记录暴露测试看过后，不再叫独立 OOS

示意图不是建议固定比例。时间窗按策略周期、样本长度和标签重叠预先设计。Walk-forward 按时间滚动；purge/embargo 用来避免训练标签与测试期重叠泄漏。

IS / OOS

训练和测试分开

样本内找规则；样本外检验已经冻结的规则。测试结果参与修改后，就成了开发数据。

WALK-FORWARD

过去训练，未来测试

滚动时间窗检验能否跨行情延续。不能随机打乱交易日做普通交叉验证。

MULTIPLE TESTS

记录试过多少次

测试越多，偶然胜出的冠军越常见。留存失败实验，控制搜索范围与多重检验。

网格分析：看平台，不追尖峰

参数附近都差不多，通常比“只有一个数最好”更可信。但平台仍可能只靠一个年份。

  • 先比较规则族的边际表现，再看参数点。
  • 检查参数曲线平滑度和逐年/逐段贡献。
  • 网格用于查脆弱性，不用于反复挑最高收益。

稳健性检查：多把尺子

没有单个检验可以宣布“去过拟合”。组合证据一起看。

  • 延长样本后结论是否翻转？
  • 提高滑点和手续费后还剩什么？
  • 收益是否集中在少数股、年份、单次行情？
  • 置换/区块重采样是否保留时间结构？
PBO / 多重检验

搜索越多，赢家越可能是偶然

回测过拟合概率（PBO）估计许多候选里，样本内赢家在样本外表现落到中位数以下的风险。CSCV 是常见计算框架；它不能替代时间顺序 OOS，也修不好数据泄漏。

BOOTSTRAP / 重采样

不确定性要保留时间结构

重叠交易、同日信号相关时，不应把每笔记录都当独立样本。按交易、日期区块或聚类选择重采样单位；结果描述不确定性，不会创造新行情。

项目边界：当前右侧波段研究规范中，2023 年之后的相关历史数据已暴露，不能重新包装成未看过的测试段。冻结规则之后的新交易日，才可提供真正的前向验证。
08 / CONTROL

控制变量与归因：到底是谁在贡献？

对照组要回答一个清楚的问题，不能事后挑最容易赢的基准。

比较方式回答的问题怎么读
同期可投资市场基准是否只是跟着牛市涨？正收益但跑输基准，不等于选股有效。
同日 / 同类机会集候选筛选是否增加信息？匹配时只用决策时可见变量。
固定候选，换入场进场触发时点是否有增量？其余条件保持一致，比较触发与未触发机会。
固定入场，换退出退出是否改善兑现？候选和买点不变，隔离卖出规则贡献。
同平均仓位固定方案择时是否优于简单减仓？减仓会机械降低回撤，需同平均暴露比较。
保留组 / 跳过组过滤器在避亏，还是错过赚钱交易？被过滤掉的交易仍赚钱，过滤器可能只是少做。
消融 / 残差模块或共同暴露贡献多少？残差依赖模型；去掉一项也要看新增和删除样本。
六种收益来源：市场 Beta、选股、入场时点、退出兑现、仓位管理、行业/风格暴露。研究要把它们拆开，避免把牛市的市场收益误认成策略 Alpha。
EXPLAINABILITY / 可解释

讲出机制，再用实验验证它

说明策略为何可能有效、何时有效、最可能如何失败；用消融和对照确认收益来自规则本身。代码规则看得懂，不代表统计证据可靠；复杂模型的解释图也不能代替样本外检验。

09 / REGIME

市场状态与因子择时：先证明有必要切换

“牛市用 A、熊市用 B”可能增加判断，也可能只是把收益从一个阶段搬到另一个阶段。

1 · 定义

只看当时可得值

用过去数据定义互斥、可重复的状态，不能用未来涨跌贴标签。

2 · 先确认代价

状态是否真影响策略？

如果原规则在所谓“问题状态”并没有明显代价，就不必加过滤开关。

3 · 反向对照

状态有方向信息吗？

比较正向、反向、固定规则和更简单的全程替代。

4 · 报全样本

分开看收益搬家

同时报状态内、状态外和全样本净变化、仓位、MDD、换手。

规则切换 ≠ 仓位调整：前者改变方向/进出场，后者改变下注大小。择时只让回撤变小，未必创造收益；仓位方案要和相同平均仓位的固定仓位比较。
10 / LIVE

回测过关，距离实盘还有一道门

研究代码、线上信号和真实成交必须处于同一口径。

SELF CHECK · 1

某过滤器让 CAGR 上升了。还要查什么？

点开答案，看看能否讲出完整理由。

检查被过滤掉的交易是否仍有正收益；比较相同机会集、成本和市场状态；确认增量不是由单一年份造成；再验证冻结规则的未来表现。
SELF CHECK · 2

Rank IC 为正，就能直接实盘吗？

区分“排序信息”和“可交易策略”。

不能。还要定义选股与成交、处理成本与 A 股约束、构建持仓组合，并验证样本外收益和回撤。IC 是因子排序诊断，不是成交记录。
11 / NOTE

每轮实验，先填这张卡

写下来，避免结果出来后忘记自己试过什么、为什么改规则。

研究问题： 机制假设 / 最可能的失败方式： 策略身份 / 目标持有周期： 唯一规则变化： 数据版本 / 股票池 / 时点字段： 训练 / 验证 / 未暴露测试区间： 信号时点 / 成交时间 / 未成交规则： 基准与超额公式： 成本与压力测试： 主指标 / 交易数门槛 / 成功失败标准： 尝试过的参数和规则数量： 新增、删除候选的表现： 结果：保留 / 淘汰 / 观察 / 前向测试
LEARNING ORDER

新手建议按这个顺序学

  1. 回测口径与 A 股交易执行。
  2. 数据时点、未来函数、幸存者偏差。
  3. 拆解选股、入场、退出、组合。
  4. 收益、基准、回撤、成本和样本量。
  5. IS/OOS、WF、参数敏感和多重检验。
  6. Rank IC、分组、因子相关和残差分析。
  7. 最后研究 regime、因子择时和生产监控。
