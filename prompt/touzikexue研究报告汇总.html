01摘要：一句话说清这个站

投资科学是一个「市场状态机 → 截面温度计 → 状态闸门回测」三层结构的量化研究站：指标页输出全市场状态（温度/估值/宽度/集中度/活跃市值/连板），热力图把温度展开到板块横截面，回测则把"活跃市值波段"状态当作策略的买入闸门。所有重计算在服务端 Python 批处理完成，前端（React SPA + ECharts + lightweight-charts）只做渲染。

05板块热力图：温度的横截面展开

热力图不是涨跌幅排行。板块温度与当日涨跌幅的截面相关仅 0.514——它是各自板块平滑后的状态量（与市场温度同构：广度+动量+活跃度的分位合成，收盘后定时批算，如当日 15:52）。

实测发现：扩散质量分与集中风险分的截面均值恰好都是 50.0 → 这两个分是横截面百分位秩（每天强制均值50），即"该板块的上涨扩散度/筹码集中度在全市省排第几"，不是绝对分。

regime 自洽性：hot 状态板块温度日均 +3.0（加速），overheated -6.65（顶部钝化回落），cold -4.2（阴跌）——状态机按"变化方向+速度"划分，热力学语义自洽。

数据源判断：行业代码 881xxx + 拼音 symbol（hymtkc）+ 热门概念/行业/概念三分法 = 同花顺板块体系。A股用流通市值，美股/港股用总市值。

8.2 全体系只有两个打分原语

核心洞察：整个指标体系的 0-100 分只有两种来源——① 时间序列滚动百分位（当日值在过去 W 日中的排名）与 ② 横截面百分位秩（当日截面中的排名，强制均值50），再叠加 EMA 平滑。理解这一点，任何指标都能自己造。

8.3 核心代码骨架（纯 Python，无依赖）

def ema(series, alpha):                 # α=0.5 即官方 'ema3'
    out, e = [], None
    for v in series:
        e = v if e is None else alpha*v + (1-alpha)*e
        out.append(e)
    return out

def roll_pct(series, window):           # 全体系的打分原语：滚动百分位
    out = [None]*len(series)
    for i, v in enumerate(series):
        if v is None: continue
        hist = [x for x in series[max(0,i-window+1):i+1] if x is not None]
        if len(hist) < max(20, window//4): continue
        out[i] = 100.0 * sum(1 for x in hist if x <= v) / len(hist)
    return out

# ---- 温度四分项（参数均为实测最优）----
trend_s         = roll_pct(right_ratio, 750)            # 右侧占比, 长窗
participation_s = roll_pct(ema(rise_ratio, 0.5), 750)   # 先EMA后百分位! 顺序不能反
liquidity_s     = roll_pct(amount / active_mv, 60)      # 换手速度, 唯一短窗!
speculation_s   = roll_pct(multi_board_count, 500)      # 多板家数

# ---- 组合（100%还原层）----
raw         = [(a+b+c+d)/4 for a,b,c,d in zip(trend_s, participation_s, liquidity_s, speculation_s)]
temperature = ema(raw, 0.5)

8.4 必须注意的实现细节（全部实测踩过坑）

  • 参与度是先 EMA 后百分位，顺序反了 corr 0.98→0.84；
  • 流动性窗口是短窗 ~60 日，错用长窗 corr 只剩 0.42；
  • EMA 冷启动直接取原值，别用 0 初始化；
  • 股息率必须用已实施分红 + 当时成分 + 未复权价，三条铁律缺一即引入偏差；
  • 集中度过热阈值用自己数据的 MA5 3年分位，不要硬抄官方参考值。

8.6 复刻后的预期差距

  • 温度绝对值差 ±2-3 分（speculation 缺股票级细节），但 regime 判定 95%+ 日期一致——实用足够；
  • 波段边界差 1-2 天（官方有未公开推断规则），影响回测闸门边际交易；

09方法论总评：值得学的与要警惕的

✓ 做得好的

  • 指标全部是状态量而非预测信号，文案反复声明"不是买卖信号"——定位诚实；
  • 阈值用滚动分位数自适应（CR3/HHI/CSD），不用固定值；
  • 股息率用已实施分红+历史成分，规避幸存者偏差；
  • 回测按开盘价+滑点+跳空穿透成交，不过度美化；
  • 每个数据点带版本号/覆盖率/完整度，可审计可复现；
  • 指标→截面→策略闸门三层共用同一底层状态，体系自洽。

✗ 局限与警惕

  • 750 日样本短，所有 IC 不足以下统计结论；
  • 10 个指标实际独立维度只有 3-4 个（趋势/广度、集中度、股债性价比）——高度同源；
  • 活跃市值口径不完全公开 + 牛市区间人工标注（作者自认"可能存在更新延迟"）；
  • 回测 OOS 未经历熊市；模型分组内排序能力存疑；
  • 公开接口暴露完整策略参数与本地文件路径（安全瑕疵）。

如果只带走一句话：这个站最有价值的不是任何单一指标的数值，而是它的体系化思路——用滚动百分位把任何原始量标准化成 0-100 的状态分、用状态分做闸门而不是做预测、用数据质量元数据保证每个数字可审计。这套骨架完全可以本地复刻，且数据源 akshare 即可覆盖。
