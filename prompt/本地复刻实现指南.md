**核心发现：整个体系的打分骨架只有两个原语——「时间序列滚动百分位」（0-100 分）和「横截面百分位秩」，再叠加 EMA 平滑。** 理解这一点，所有指标都能自己造。

## 1. 市场温度（完整配方）

```python
import math

def ema(series, alpha):
    """指数平滑。alpha=0.5 即官方 'ema3'（span=3）"""
    out, e = [], None
    for v in series:
        e = v if e is None else alpha * v + (1 - alpha) * e
        out.append(e)
    return out

def roll_pct(series, window, min_periods=None):
    """时间序列滚动百分位，0-100。这是全体系的打分原语"""
    minp = min_periods or max(20, window // 4)
    out = [None] * len(series)
    for i, v in enumerate(series):
        if v is None: continue
        hist = [x for x in series[max(0, i - window + 1): i + 1] if x is not None]
        if len(hist) < minp: continue
        out[i] = 100.0 * sum(1 for x in hist if x <= v) / len(hist)
    return out

# ---------- 四个分项（已实测锁定的输入与参数） ----------

def trend_score(right_ratio, W=750):
    """趋势分 = 右侧占比(EMA20/50多头排列个股占比) 的 ~3年滚动百分位
       实测 corr=0.946（残差来自个股级 vs 聚合代理）"""
    return roll_pct(right_ratio, W)

def participation_score(rise_ratio, W=750):
    """参与度分 = EMA3(上涨家数占比) 的 ~3年滚动百分位
       实测 corr=0.976 —— 注意先EMA后百分位"""
    return roll_pct(ema(rise_ratio, 0.5), W)

def liquidity_score(turnover_velocity, W=60):
    """流动性分 = 换手速度(全A成交额/活跃筹码市值) 的 ~60日滚动百分位
       实测 corr=0.909。没有活跃市值时可用 成交额/流通市值 近似"""
    return roll_pct(turnover_velocity, W)

def speculation_score(multi_board_count, W=500):
    """投机分 = 多板家数(2板及以上) 的 ~2年滚动百分位
       实测 corr=0.860。想拉满可加：炸板率(需盘中数据)、封成比、最高连板百分位*0.2"""
    return roll_pct(multi_board_count, W)

# ---------- 组合（100% 还原层） ----------

def market_temperature(ts_, participation, liquidity, speculation):
    n = len(ts_)
    raw = [(ts_[i] + participation[i] + liquidity[i] + speculation[i]) / 4
           for i in range(n)]                                # 四分项等权
    temperature = ema(raw, 0.5)                              # EMA(span=3) 平滑
    return raw, temperature

def regime(t):
    if t < 15:  return "冰点"
    if t < 30:  return "寒冷"
    if t < 45:  return "偏冷"
    if t < 55:  return "中性"
    if t < 70:  return "回暖"
    if t < 85:  return "炽热"
    return "过热"
```

**必须注意的实现细节**（都实测过）：
- 参与度是**先 EMA 后百分位**，顺序反了 corr 掉到 0.84；
- 流动性窗口是**短窗（~60日）**，其他分项是长窗（500-750日）——长窗错用在流动性上 corr 只有 0.42；
- 温度对 raw 做 EMA(α=0.5)，实测 RMSE 0.33 分；不做平滑与官方差 1 分以上；
- EMA 冷启动：官方前几日数据直接取 raw，别用 0 初始化。

## 2. 估值位置（~94% 还原）

```python
def valuation_score(median_pb_series, W=1250):
    """= 全A中位数PB 的 ~5年(1250交易日)滚动百分位，raw 再 EMA 平滑
       官方版本号 'pb-profit-shadow'：对亏损/微利股的PB失真有影子修正
       ——本地实现可先忽略修正，750日样本实测 corr=0.935"""
    raw = roll_pct(median_pb_series, W)
    return ema([v if v is not None else 50 for v in raw], 0.5)
```

## 3. 市场宽度（100% 可复刻）

```python
def ema_line(closes, span):
    a = 2 / (span + 1)
    out, e = [], None
    for c in closes:
        e = c if e is None else a * c + (1 - a) * e
        out.append(e)
    return out

def market_width(stock_closes):  # dict: symbol -> 收盘序列
    """右侧占比 = [close > EMA50 且 EMA20 > EMA50] 的个股占比
       trend_short=EMA20, trend_long=EMA50 为实测还原（RMSE≈指数0.3%）"""
    n = len(next(iter(stock_closes.values())))
    out = []
    for i in range(n):
        right = total = 0
        for sym, cl in stock_closes.items():
            if cl[i] is None: continue
            total += 1
            e20, e50 = ema_line(cl, 20)[i], ema_line(cl, 50)[i]
            if cl[i] > e50 and e20 > e50: right += 1
        out.append(100 * right / total if total else None)
    return out
```

## 4. 集中度 CR3 / HHI / CSD（官方公开公式，100%）

```python
import statistics

def concentration(industry_amount, stock_amount, stock_ret, stock_mv):
    """输入: dict[行业->成交额], dict[股票->成交额/收益率/流通市值]（单日截面）"""
    # 行业 CR3
    tot_amt = sum(industry_amount.values())
    top3 = sorted(industry_amount.values(), reverse=True)[:3]
    cr3 = 100 * sum(top3) / tot_amt
    # 个股 HHI（份额取百分点，结果0-10000）
    s = sum(stock_amount.values())
    hhi = sum((a / s * 100) ** 2 for a in stock_amount.values())
    # CSD 市值加权截面离散度
    w = {k: stock_mv[k] / sum(stock_mv.values()) for k in stock_mv}
    mu = sum(w[k] * stock_ret[k] for k in w)
    csd = math.sqrt(sum(w[k] * (stock_ret[k] - mu) ** 2 for k in w))
    return cr3, hhi, csd

# 过热阈值：各自 MA5 的 3年滚动分位数（CR3: 23.3/29.0, HHI: 15.2/17.3, CSD: 3.2/3.5 为官方参考值，
# 自己实现时用自己数据的3年分位，不要硬抄）
```

## 5. 活跃市值与波段（~90%）

```python
def active_wave(active_mv):
    """波段 = 活跃市值 > 自身MA10（实测命中官方波段89.5%）。
       官方另有~10%差异来自未公开的推断/调整规则"""
    ma10 = [sum(active_mv[max(0, i-9):i+1]) / (i - max(0, i-9) + 1) for i in range(len(active_mv))]
    return [1 if v > m else 0 for v, m in zip(active_mv, ma10)]
```
活跃市值本身官方口径未公开（"活跃筹码总市值"，API 带 `inference_start_date` 说明有推断成分）。**本地替代方案**：全A剔除涨跌幅在 ±1% 内的"死筹码"后的流通市值加总，或用成交额加权构造，形态上会接近。

## 6. 股债利差（100%，注意防偏差细节）

```python
def dividend_spread(index_div, bond_10y):
    """股息率 = 近365天【已实施】每股分红 / 当日【未复权】收盘价
       三条铁律：①只用已实施的（预告的不算）②用当时有效成分（防幸存者偏差）
       ③未复权价（复权会扭曲股息率）"""
    return {d: index_div[d] - bond_10y[d] for d in index_div}
```

## 8. 回测框架（规则 100% 还原，模型需自训）

```python
# ===== 每日流程（T日收盘后）=====
# 1. 状态闸门: in_wave = active_mv[t] > MA10(active_mv)[t]  （波段外不买）
# 2. 打分: LGBM回归预测 label_abs_ret（未来N日绝对收益）—— 特征/标签官方未公开，需自建
# 3. 候选: score 前5名（top_n=5, max_positions=5, 单仓≤50%）

# ===== T+1 执行 =====
# 买入: 次日开盘价 + 30bps 滑点

# ===== 持有期退出（优先级即实测频率序）=====
# a) t3_weak:   持有≤3日且走弱（跌破2%）→ 卖出   [占65%, 均收益-1.4%]
# b) max_hold:  持有15日 → 强制卖出              [占16%, 均收益+24.4%]
# c) fixed_stop: 收盘相对成本 -7% → 次日卖出      [占9%, 实际均亏-10%（跳空）]
# d) drop_trend_long: 跌破长期趋势线 → 卖出      [占7%]

# ===== 关键统计口径（官方数字已全部复算吻合）=====
# 期望/笔 = 胜率×均盈 - (1-胜率)×|均亏| ; 利润因子 = 总盈/总亏
# 净值 = capital_after_close / initial_capital（前端归一）
# 基准 nav 同起点归一，三线: 上证/中证1000/同花顺全A
```

**复刻回测的诚实清单**：按 T+1 开盘成交、计入滑点、止损次日执行（允许跳空穿透）、涨停日不买（可成交性）、波段外空仓。这五条决定了回测可信度的下限。

## 10. 与官方的已知差距（复刻后预期）

1. 温度绝对值会差 ±2-3 分（speculation 分项缺股票级细节、质量门控不同），但**状态（regime）判定 95% 以上日期一致**——对使用而言足够；
2. 波段边界会差 1-2 天（官方有未公开推断规则），影响回测闸门的边际交易；
3. 板块温度只能做到"同构"（截面相对高低正确），绝对分值对不上；
4. 750 日样本的限制：以上所有窗口参数（750/500/60 日）是拟合最优值，官方真值可能略不同，建议本地拿到更长历史后重新标定。
